## 一、排版与字阶

### 1.1 字号：49 种取值，令牌为零

**现象**：全仓 `font-size` 没有任何令牌（`var(--fs-*)` 使用 **0** 处），全是硬编码 rpx。

**证据**（怎么测的：`npm run report:type` / `npm run report:type:json`）

```
字号分布：4469 处 font-size / 49 种取值
事实字阶（≥10 次，15 档）: 16 18 20 21 22 24 26 28 30 32 34 36 40 44 48
离群字号（≤2 次，22 种）: 23×1 25×2 27×1 29×1 76 80 88 100 120 144 148 152 160 164 172 176 188 196 198 204 210 260
```

```
$ grep -rn -- 'var(--fs-' miniprogram --include=*.wxss | wc -l      → 0
$ grep -oE '^\s*--[a-z0-9-]+' miniprogram/app.wxss | wc -l          → 66（颜色/间距/圆角/字体，**无一条字号**）
$ grep -rn 'font-size: *[0-9]' miniprogram --include=*.wxss | wc -l → 4472
```

**逐值质量分布**（怎么测的：`grep -rhoE "font-size: *[0-9]+rpx" --include=*.wxss . | grep -oE "[0-9]+" | sort -n | uniq -c`）

| 档 | 值（次数） |
|---|---|
| 主力（≥180） | 22(1059) · 24(777) · 20(712) · 26(489) · 28(481) · 18(216) · 30(180) |
| 次级（26–131） | 32(131) · 40(91) · 36(86) · 34(54) · 16(51) · 44(26) · 48(26) |
| **"差 1rpx"噪音** | **21(10) · 23(1) · 25(2) · 27(1) · 29(1)** |
| 3–9 次的盲区（工具两边都不算） | **12(3) 14(8) 15(3) 38(4) 42(3) 46(3) 52(5) 56(5) 60(4) 64(6) 72(4) 168(3) = 12 种 / 51 处** |
| 装饰/几何（≥76） | 76 80 88 100 120 144 148 152 160 164 172 176 188 196 198 204 210 260 = 19 种 / 25 处 |

> **工具盲区（E7 类，属我 own 的 `report-type.mjs`）**：它把"离群"定义为**≤2 次**，把"事实字阶"定义为**≥10 次**，
> 于是 **3–9 次的 12 种 / 51 处**既不算离群也不进字阶 —— 这 51 处会**静默逃过收敛清单**。
> 我用「≥10 次为在册」这一口径重算，离群是 **34 种 / 80 处**，而不是 22 种。

**影响面**：**172 个 wxss 文件 / 4469 处**。热点：`components/UserVipCard/index.wxss` **24 种字号 / 64 处**
（144→260rpx 几乎连续，是"逐次手调"留下的年轮）、`manager/manager/index.wxss` 18 种 / 421 处、
`app.wxss` 11 种 / 19 处。

**严重度**：**P0**（它是后面所有视觉一致性的地基 —— 见 1.2）。

**建议判据**：新增棘轮 `report:type` 进 `check:admin:guards`（**需集成官改 `package.json`**），
判据 = 「非令牌字号 0 处 + 令牌外取值 0 种」，基线文件按现有棘轮范式（`dialog-ratchet-baseline.json`）。

**现象**：`AppModal` / `AppToast` 是本轮"视觉统一"的**唯一入口组件**，但它们的字号也是硬编码，

```
AppToast/index.wxss  font-size: 20rpx / 34rpx / 24rpx
report:type:json → {"file":"miniprogram/components/AppModal/index.wxss","count":4,"distinct":4,"orphanValues":2}
```

**影响面**：2 个组件 / 7 处 —— **但语义影响是全局的**：这两个组件是 124 个页面弹窗与提示的母版，
新页面会照抄它们。

**严重度**：**P0**（它证明"先做令牌、再逐页铺"的顺序不能反 —— 没有令牌，每一批新组件都会固化一批新噪音）。
