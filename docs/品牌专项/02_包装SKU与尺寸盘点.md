## 3. 命名规则（包装信息层联动，沿用 VI v2.0）

- 标品：**系列名 + 产品类型 + 规格**，例：「蓝 · 玻璃罩 · M」＝蓝闪蝶系列中号玻璃罩；「奇 · 相框 · S」＝甲虫/非蝶类小号相框。系列名：「蓝」「翠」「彩」「奇」。
- 集合框：**山林·集 / 海岸·集 / 四季·集**（不用「集合框」「标本画」等通用名）。
- 展陈线：每件高端标本**独立名字**（角色名/意象名，非物种名）。

## 4. 包装现状基准（VI v2.0 第 8 章已定，本专项在其上做「尺寸化」）

| 件 | 已定规范 |
|----|----------|
| 品牌卡片 | 90 × 54mm；350 克棉纸/自然纹理特种纸、无涂布；正面印章+品牌名+slogan 单色印刷（自然绿，可凹印）；背面 SKU 专属：中文物种名 13pt 品牌绿 + 拉丁名 9pt 大地棕斜体 + 产地 + 一句话冷知识（四色） |
| 内包装 | 天地盖盒；灰板裱糊特种纸（树皮/石材触感纹理）；盒面仅 logo + 产品名；暖灰/亚麻色；内衬深墨绿绒布或 EVA；开箱「外素内美」 |
| 外包装 | 牛皮纸手提袋 + 印章 logo + slogan，棉绳/麻绳提手；瓦楞纸快递箱 + 品牌胶带（NATURE'S CREATIONS）+ 可降解缓冲；箱内品牌卡片 |
| 陈列价签 | 与品牌卡片同材质；印章 logo + 产品名 + 价格 |
| 品类纹理 | 每品类一个自然纹理抽象图案（昆虫=羽翼鳞片排列、矿物=晶体断面、植物=年轮/叶脉、海洋=螺旋/水波纹），用于品类标签与分类图标 |
| 最小尺寸 | 标准版印章直径 ≥12mm；纯图形版 ≥8mm |
