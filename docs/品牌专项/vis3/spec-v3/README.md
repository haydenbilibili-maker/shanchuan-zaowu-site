## 归档的两个坑（都踩过）

1. **别用 `unzip` 命令看这个包的文件名** —— `unzip -l` 显示出来是乱码
   （`00 զ����.png`），看着像 GBK 文件名，于是"顺手加个 `-O GBK`"反而**解出乱码文件名**。
   实测：zip 里的名字就是 **UTF-8**（只是没置 EFS 标志位），`unzip` 按 CP437 猜错了；
   **用 Python `zipfile` 读出来的就是正确中文名**。归档脚本见本目录说明末尾。
2. **有两个文件内容完全相同**：`组件 · Logo 方案.png` 与 `组件 · 山海印.png`
   （sha256 均 `7e8b275c5d01`，32 KB）—— 原件如此，未做去重（保真优先）。

## 复现（解包校验）

```bash
python3 - <<'PY'
import zipfile, os, hashlib
z = zipfile.ZipFile(os.path.expanduser('~/Downloads/山海造物 VIS 3.0-png.zip'))
for i in sorted(z.infolist(), key=lambda x: x.filename):
    d = z.read(i.filename)
    print(f'{len(d)/1024:7.0f} KB  {hashlib.sha256(d).hexdigest()[:12]}  {i.filename}')
PY
```

归档时的 sha256 前 12 位（用于日后校验原件是否被替换）见本目录 `_manifest.json`。
