### 1.2 架构特征

- **无前端路由**：`App.vue`（4,932 行）用 `currentTab` + `defineAsyncComponent` 懒加载组件，`modulesRegistry.js` 维护模块元数据。改造菜单需同时动 `App.vue` 与注册表——与 `AGENTS.md` 描述一致。
- **数据层双通道**：管理类写操作经 Cloudflare Pages Function `/api/cloud-fn` 服务端代理（`functions/api/cloud-fn.js` 用腾讯云 API 密钥 Invoke 云函数，避开浏览器匿名 callFunction）；其余读取走 `@cloudbase/js-sdk` 匿名会话。
- **构建链路**：`npm run build` → `scripts/build-admin.mjs`（清空 `public/admin/assets` 后 `vite build -w admin`）→ `astro build` → `dist/`，由 GitHub Actions 部署 Cloudflare Pages。
- **能力边界文档诚实**：`PLATFORM_CAPABILITIES.md:52` 明确写了「管理端登录实现为单一口令 + localStorage 标记的前端门禁，**不是** OAuth/SAML/多因素」，`§9` 也标注了 InventoryAI/采购管理等为演示、勿当 WMS——**风险在于这类"演示边界"被部署到了与真实业务数据同一个线上环境**。

### P0 · 高危（建议今天到本周内处理）

#### P0-1 运维密钥 `ADMIN_OPS_KEY` 已进入公开构建产物

- **证据**
  - 已提交（`HEAD`）产物中命中 2 个文件：`public/admin/assets/index-BxCDW-W1.js`、`public/admin/assets/ProductConceptGenerator-BogjiTdD.js`；当前未提交的新版产物同样命中 2 个。

- **影响**：小程序侧 `cloudfunctions/manageStaff/staffGuard.js:527` 规定——**只要 `adminOpsKey` 与云函数环境变量一致，直接判定为 `super_admin`（全量权限）**。也就是说，拿到这串密钥的人可以冒充超管：改商品与价格、发货与退款、改会员等级与积分规则、改内容与配置、管理员工与超管 ACL。**这条同时架空了小程序侧刚完成的 RBAC 加固**（详见 §3）。
- **修复**：① 立即轮换 `ADMIN_OPS_KEY`（云函数环境变量 + Cloudflare Pages 环境变量同步）；② 删除客户端 14 处 `adminOpsKey` 注入——这些函数（`managerShipOrder`/`refundOrder`/`manageStoredValue`/`manageProducts`/`getShippingRules`/…）都已在 `/api/cloud-fn` 代理白名单内，代理会在服务端补上密钥，删掉客户端传参不影响功能；③ 不再让构建环境注入该变量。

#### P0-2 ERP 登录口令是前端明文默认值 `admin888`

- **证据**：`App.vue:1471-1472` — `const ADMIN_SECRET = import.meta.env.VITE_ADMIN_PASSWORD || 'admin888'`；实际 `.env` / `.env.local` **未配置** `VITE_ADMIN_PASSWORD`，线上走默认值。已提交产物 `public/admin/assets/index-BxCDW-W1.js` 中可直接搜到 `admin888`（当前未提交产物同样命中 1 个文件）。登录态是 `localStorage` 标记（`App.vue:1837` 明文比对）。
- **影响**：口令公开等于登录门槛为零；配合 P0-1 的密钥，攻击链完整。注意该口令与小程序工作台 UI 口令现网约定值相同，一处泄露两处受影响。
- **修复**：ERP 登录改服务端校验（经 `/api/cloud-fn` 或 Pages Function 校验口令/签发短时票据），前端只保存会话票据；同时更换口令，且**不要**与小程序工作台口令同值。

#### P0-3 匿名登录 + `auth != null` 规则 = 公网可读写管理数据

- **证据**
  - `admin/src/cloud.js:12,17,99-104` — 前端硬编码环境 ID 并调用 `auth.signInAnonymously()`，**任何人**打开站点即可获得匿名会话；环境 ID 同样能在产物里搜到（5 处命中）。
  - `cloudbase/rules/` 中**没有任何一份规则区分匿名与真实用户**（`loginType` 零命中）。管理侧集合普遍是 `read: "auth != null"`、`write: "auth != null"`：
    | 集合 | read | write |
    |------|------|-------|
    | `finance_records`（财务流水） | `auth != null` | `false`（已收严） |
    | `finance_settings`（财务设置） | `auth != null` | `auth != null` |
    | `admin_users` / `admin_roles` / `admin_operation_logs` | `auth != null` | `auth != null` |
    | `content_pieces` 等内容工厂集合 | `auth != null` | `auth != null` |
    | `member_levels` / `points_rules` / `marketing_rules_config` | `auth != null` | `auth != null` |
    | `shipping_rules` / `member_welcome_gift` | `true`（全员可读） | `auth != null` |
- **影响**：匿名访客可读取财务流水与财务设置、管理员名单与角色、运营操作日志、内容与营销规则；并可**写入**其中大部分集合（改积分等级、营销规则、内容、管理员名单）。这不需要任何口令，只需打开 `/admin` 在控制台里执行 SDK 调用。
- **修复**：① 规则中排除匿名（例如 `auth.loginType != 'ANONYMOUS'`），最稳妥是管理集合一律 `false`，全部读写走服务端代理；② 管理数据与小程序 C 端数据**分环境或分集合**，避免一个匿名开放的环境承载全量业务；③ 审计现有数据是否已被未授权修改（比对 `admin_operation_logs` 与业务数据的写入时间）。

#### P0-4 AI 厂商密钥随前端包发布

- **证据**：`admin/src/utils/aiHelper.js:37,42,890` — 密钥取自 `import.meta.env.VITE_DEEPSEEK_API_KEY` 并在浏览器中 `Authorization: Bearer ${key}` **直连 `api.deepseek.com`**（代理模式仅开发环境 `vite.config.js` 生效）；CI 明确注入密钥（`.github/workflows/deploy-pages.yml:20-25` 的 `VITE_DEEPSEEK_API_KEY`、`VITE_BAILIAN_API_KEY`），产物中可搜到 `api.deepseek.com`（当前产物 3 个文件命中）。

## 3. 与小程序侧的联动影响（本轮重点）

小程序侧刚完成的安全加固（云端口令 `manageStaff.verifyUiGate` + `staffGuard` 角色模型 + 客户端写操作全部收回云函数）**在服务端是成立的**；但 `staffGuard.js` 把「`adminOpsKey` 匹配」直接判定为 `super_admin`，而这个密钥已经在 ERP 的公开产物里。结论：

- 攻击者不必碰小程序包，只要从 ERP 的 JS 里取出密钥，就能以超管身份调用小程序侧全部管理云函数（发货、退款、改价、改权限、发全员推送）。
- 因此**修复必须成套**：轮换密钥 → 客户端不再持有 → 小程序侧同时评估是否保留这条「口令即超管」的旁路（建议改为仅在服务端代理通道内生效，例如校验来源 IP/签名而不是纯字符串比对）。

## 附录 · 审计口径

- 密钥检查：从本地 `.env` / `.env.local` 读取变量值后在**已入库产物**（`git grep ... HEAD`）与**当前产物**（`grep -r`）中检索命中文件，全程只输出文件名与脱敏前缀，未在报告中记录任何密钥明文。
- 匿名可读性判定：规则中 `auth != null` 对匿名登录同样成立（CloudBase 匿名会话属于已登录态）；`cloudbase/rules/` 中 `loginType` 零命中，故判定无匿名隔离。
- 组件引用统计：合并静态 `import ... from '*.vue'` 与动态 `import('*.vue')` 两种写法后比对 `src/components/**/*.vue`。
- 构建产物体积：`public/admin/assets` 实测；未计 CDN 压缩收益。
