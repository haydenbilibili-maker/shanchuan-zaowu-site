### 1.1 ⚠️ 一个必须更正的前提（否则下面会误读）

**`test-product-theme-name` 的自检不是"当前红点"，而是"已经红过、且这条待收编改动正好在修它"。**
实测（worktree 内，先取 HEAD 版本再放回）：

```
$ git show HEAD:miniprogram/scripts/test-product-theme-name.mjs > <该文件>
$ node miniprogram/scripts/test-product-theme-name.mjs --selftest
  ✗ 锚点不唯一（命中 0 次）：详情页退回只显示标准名
  ✗ 自检失败：1 项                       (exit 1)
$ node miniprogram/scripts/test-product-theme-name.mjs          # 守卫本体
  ✓ 主题名（双层命名）：25 项通过                                (exit 0)
```

**关键**：守卫本体在 HEAD 上**是绿的**（它不跑注入），**只有 `--selftest` 红**。
它在 HEAD 上属"守卫证明不了自己会失败"（错题本 E7/E16），会**计入 `run-guards.mjs` 的 problems**
→ `check:admin:selftest` 红 → CI 的 `guards-can-fail` job 被挡。
**结论：是**，`test-product-theme-name.mjs` 的改动**就是**"详情页退回只显示标准名"这条自检锚点的失效修复
（详情页已把题记挪到标准名之后，锚点没跟）。**低风险高价值，已按 A 类提交**（sha `37f6b72`）。
