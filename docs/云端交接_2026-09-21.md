  1. `test-gift-note-variants` 的"不得有水印"锚点 `indexOf` 返回 −1 → 切片成空串 → **恒真**；
  2. `check-wall-qr` 的热启动兜底判据是**整文件级**正则 → 删掉某个入口的兜底判不出来；
  3. `check-gift-sticker-layout` 的 ⑤b/⑤d 仍按 `footerTop` 复算，而 painter 从 `qrLift` 起画
     → 算的是"不存在的那一行"。
  **规律：负向断言必须看"去注释"的源码；几何判据必须跟实现取同一个算式；判据要能被注入证伪。**
