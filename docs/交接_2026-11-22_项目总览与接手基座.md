## 2. 这个项目是什么

**山海造物** = 「线上内容 + 线下门店 + 标本藏品」业务线。本仓库是**唯一代码主库**（`shanchuan-admin` 只读归档，不改）。

- **商业模式**：标本藏品零售 + 门店 + 内容 IP（双 IP：`GRAVITY` 沉静 / `LIGHTNESS` 明亮）。
- **阶段**：先跑通单店模型，再按「店铺管理 → 员工薪酬 → 加盟商管理」做连锁化（PRD 已备，未开工）。
- **数字化形态**：**三端一底座** —— 不做独立后端，业务逻辑落在前端 + 云函数 + 云库。

| 端 | 技术 | 规模（实测） | 部署 |
|---|---|---|---|
| 官网 `src/` | Astro 5 + Tailwind v3 + TS，v0.4 双主题 | 27 个 .astro 页面 | Cloudflare Pages（push main 自动构建） |
| ERP `admin/` | Vue 3 + Element Plus + rolldown-vite，SPA 无路由 | **91 个模块** / 7 个域、104 个组件 + 22 个 AI 场景组件、`App.vue` 5,621 行 | 同上，产物 `dist/admin/` |
