## 1. 字阶令牌 `--fs-*`

### 1.1 令牌定义（写进 `miniprogram/app.wxss` 的 `page { }` 块，与 `--font-*` 并列）

```css
/* 字阶（C7 契约）：14 档；命名即尺寸，**不允许出现不在册的 rpx 字号** */
--fs-16: 16rpx;  --fs-18: 18rpx;  --fs-20: 20rpx;  --fs-22: 22rpx;
--fs-24: 24rpx;  --fs-26: 26rpx;  --fs-28: 28rpx;  --fs-30: 30rpx;
--fs-32: 32rpx;  --fs-34: 34rpx;  --fs-36: 36rpx;  --fs-40: 40rpx;
--fs-44: 44rpx;  --fs-48: 48rpx;
```

**为什么是"命名即尺寸"而不是 `--fs-xs/sm/md`**：
① 迁移是**机械可验证**的（`23rpx → var(--fs-22)` 不需要再讨论语义）；
② 名字里带尺寸，「差 1rpx 噪音」在 code review 时肉眼可见；
③ 语义别名可以后续叠加（`--fs-body: var(--fs-28)`），但**基础档只许这一套**。
（施工总纲 W1 原文建议 `18/20/22/…/64`；我按**实测质量分布**调整：保留 16 与 34 两档 ——
16rpx 51 处、34rpx 54 处都远超"离群"阈值，砍掉它们会造成**非受控的视觉变化**。）

### 1.2 为什么是这 14 档（实测依据）

怎么测的：`cd miniprogram && grep -rhoE "font-size: *[0-9]+rpx" --include=*.wxss . | grep -oE "[0-9]+" | sort -n | uniq -c`

| 档 | 取值 | 实测质量 |
|---|---|---|
| 主力 7 档 | 20(712) · 22(1059) · 24(777) · 26(489) · 28(481) · 18(216) · 30(180) | ≥180 次 |
| 次级 7 档 | 32(131) · 40(91) · 36(86) · 34(54) · 16(51) · 44(26) · 48(26) | 26–131 次 |
| **在册小计** | **14 种 / 4379 处** | |
| **离尺度（要改值）** | **12 种 / 44 处** | 见 §1.3 |
| **装饰档（不改值，移出 `font-size` 语义）** | **23 种 / 46 处** | 见 §1.4 |
| 合计 | **49 种 / 4469 处** | 4379 + 44 + 46 = 4469 ✅ |

| `23rpx` | `var(--fs-22)` | 1 | 就近 |

| `27rpx` | `var(--fs-26)` | 1 | 就近（**在 AppModal**） |
| `29rpx` | `var(--fs-28)` | 1 | 就近（**在 AppModal**） |

### 1.4 装饰档（23 种 / 46 处）：**本波次不改值，但必须移出 `font-size` 语义**

实测 ≥56rpx 的 23 种取值（56 60 64 72 76 80 88 100 120 144 148 152 160 164 168 172 176 188 196 198 204 210 260）
几乎全部出现在**一个组件**：`components/UserVipCard/index.wxss`（离群 12 种 / 64 处）——
它们是**封缄/信封的几何尺寸**（圆章直径、渐变环直径），不是排版字号。

**规范**：
1. 这些值**不属于 `--fs-*`**；它们是图形尺寸，应改为组件的 `--seal-*` / `--size-*` 几何变量，
   由 `width/height` 统一控制，而不是靠"字号撑开"。
2. **禁止**把它们压成"展示字阶"（例如 144→168）—— 那是 **E8 的陷阱**：没有真机就压缩装饰几何，
   必然出"圆章超出卡片"这类只有肉眼能发现的问题。**本波次明确不做**，留待有真机验收窗口时按组件逐个做。

### 1.5 守卫与自检（C7 对字阶的机器判据）

| 判据 | 落点 | 现状 |
|---|---|---|
| **A1** `app.wxss` 必须定义全部 14 条 `--fs-*` 令牌 | `check:toast-style`（**已在链上**） | ✅ **本波次落地** |
| **A2** `AppModal` / `AppToast` 的字号**必须**是 `var(--fs-*)`，且不得引用不在册的令牌 | `check:toast-style`（**已在链上**） | ✅ **本波次落地** |
| **A3** 非令牌 `font-size` **总量单调下降**（基线 = 4469 处 / 49 种） | `report:type` 加 `--baseline` 棘轮 | ⏳ **需集成官把 `report:type:strict` 加进 `check:admin:guards`**（`package.json` 冻结） |
| **A4** 新增文件不得引入非令牌字号 | 同上 | ⏳ 同上 |

**必须同时修掉的判据缺陷（E7，属我 own 的 `report-type.mjs`）**：
- 现在「离群」= **出现 ≤2 次**，「事实字阶」= **≥10 次** → **3–9 次的 12 种 / 51 处两边都不算**，会静默逃过收敛清单。
  判据应改为**按在册令牌白名单判定**（不在 14 档里就是离群），而不是按出现次数。
- `--strict` 现在的阈值 `TYPE_ORPHAN_MAX=22` **恰好等于当前实测值**（22 > 22 = false）→ 恒绿；
  且它数**种类**不数**处数** → 同一个离群值再加 500 处也不会红。**既不能失败，就证明不了任何事。**

### 2.2 【P0 处置口径】低对比正文：**调值，不提升层级**

**先给结论，再给理由。**

**结论**：
| 表面 | 令牌 | 现值 | 现值对比度 | **建议新值** | 新值对比度 |
|---|---|---|---|---|---|
| ERP | `--light-text-tertiary`（`admin/src/styles/design-tokens.css:66`） | `#9b968d` | **2.81:1** on `#fafaf5`（用在 **147 处 / 17 文件**） | **`#726c62`** | **4.97:1** on `#fafaf5` · 5.20:1 on `#fff` · **4.69:1** on `#f5f3ed` ✅ |
| 小程序 | `--color-text-muted`（`app.wxss:36`） | `#6B6560` | **2.72:1** on `#262320`（用在 **582 处 / 84 文件**） | **`#948e83`** | **4.80:1**（最坏面 `#262320`）· 5.45:1 on `#1A1814` ✅ |
| ERP | `--light-text-disabled` | `#c5c2bb` | 1.70:1 | **不动** | 禁用态文本 WCAG 明确豁免，改了反而看起来"可点" |

**为什么"调值"而不是"把正文提升到 `--light-text-secondary`"**：
1. **层级会塌**。`--light-text-secondary #6b665d` 是 5.44:1，语义是"次要正文"；
   而 `--light-text-tertiary` 承载的是**辅助标签**（时间戳、ID、单位、提示）。
   把 147 处辅助文字全部提成 secondary，等于**取消这一级** —— 视觉上"每个字都在喊"。
2. **调值的代价更小且可验证**：只改 1 行令牌、0 处布局变化、`check:brand-contrast` 可以直接钉住
   （新增断言「`--light-text-*` 全部 ≥4.5:1 on 全部 `--light-bg-*`，`disabled` 除外」）。
3. **两边都能满足**：新值仍明显浅于 secondary（`#726c62` vs `#6b665d`），层级保留。

**`#999` / `#888` / `#a09a90` 等字面量的口径**（`report:colors` 报 674 处 / 64 色）：
- ⚠️ **绝对不要按 `#999999` 做 find-replace** —— 审计说的 `#999` 是**3 位简写**：
  `grep -c '#999999' admin/src` = **0**，`grep -ciE '#999([^0-9a-f]|$)' admin/src` = **168 / 39 文件**。
  按 6 位找会**一处都改不到**（AGENTS「禁止 find-replace」的活体案例）。
- **按语义回流**：辅助标签 → `var(--light-text-tertiary)`；次要正文 → `var(--light-text-secondary)`；
  纯装饰/图标 → 允许留在字面量并登记进 `color-residue-baseline.json`。
- **必须先浏览器实测**：`npm run report:colors -- --verify '<选择器>' --module <id>`
  （报告自己声明"仍是静态判定"；本仓已被"静态分析≠事实"坑过 3 次）。
- 674 这个数字**目前没有任何断言**（`report:colors:strict` 只在**残留种类变多**时失败，`report-color-residue.mjs:641`）
  → 契约要求新增 A6 断言。

## 3. 层级规范 L1 / L2 / L3

### 3.1 定义（沿用详情页已定稿的语义，不改）

| 层级 | 是什么 | 手法 | 金色 |
|---|---|---|---|
| **L1 主视觉** | 一屏只有 **1–3 个**元素 | 最大字号 + 品牌金 + 最强对比 | ✅ **允许品牌亮金** |
| **L2 支撑** | 承接 L1 的信息 | 中字号 + `--color-text-body` / `--light-text-primary` | ❌ 不得用品牌亮金 |
| **L3 弱化** | 学名 / 角标 / 单位 / 时间戳 | 小字号 + `--color-text-muted` / `--light-text-tertiary` + `opacity<1` | ❌ 不得用品牌亮金 |

金色一旦通胀，页面就没有重点（`check-detail-visual-tiers` 的原始判据）。

### 3.2 "推广到其它页"的判据形状

现状：`check-detail-visual-tiers.mjs` 把路径写成**两个常量**（`WXSS`/`WXML`，单页）→ 推广必须**改成表驱动**。

```js

const PAGES = [
  { id: 'detail',  wxss: 'miniprogram/subpackages/feature/detail/index.wxss',  wxml: '...',
    l1: ['.num', '.gift-cta'], noGold: ['.gift-scene-chip', '.latin-sub', '.service-item'],
    weaken: ['.latin-sub'], divider: 'card-divider' },
  // 推广时每加一页，追加一条；每条都要先由产品负责人回答「哪 1–3 个是 L1」
]
```

**推广判据（每条都必须机器可判）**：
1. **规范注释还在**（L1/L2/L3 三段 + 「L1 之外不得出现品牌亮金」原句 + 指回守卫名）；
2. **`l1` 选择器命中品牌金**（证明 L1 真的用了金）；
3. **`noGold` 选择器一个都不含品牌金**（证明金色收敛）；
4. **至少一个 L3 选择器有弱化手法**（`opacity<1` 或次要色）；
5. **L1 元素数 ≤3**（"一屏只有一个重点"的可数化身）。

**明确不做**：不由我单方面决定"某一页哪三个元素是 L1" —— 那是产品决策。
我的职责是**把判据形状冻死**，产品负责人每页给一次答案，我加一行。

**推广顺序（与施工总纲 W4 一致）**：藏品库列表 → 礼赠 hub & 编排 → 我的 → 订单。

### 4.2 `closable` 语义（**当前完全缺失**）

实测 `components/AppModal/index.wxml`：mask 无 `bindtap`、`catchtap="noop"` 在牌面上、`index.js` properties 无 `closable`、
**牌面也没有关闭按钮** → **AppModal 目前不能通过点遮罩关闭**。

**契约（新增属性，默认值取"安全侧"）**：

| `closable` | mask 点击 | 右上角 × | 适用 |
|---|---|---|---|
| `false`（**默认**） | 不关（无 `bindtap`） | 无 | **危险操作**（删除 / 退款 / 补履约）、必读告知 |
| `'mask'` | 关闭 = 等价 `cancel` | 无 | 一般确认 |
| `'button'` | 不关 | 有 | 长文案（权益说明 / 举证要求），用户需要主动关 |
| `'both'` | 关闭 | 有 | 纯提示（`showCancel:false` 的通知类） |

**硬规则**：①`danger:true` 的弹窗**必须** `closable:false`；
②`closable` 关闭一律**结算为 `{confirm:false, cancel:true}`**（与"取消"同形，不留悬挂 Promise）；
③`wx:if` 卸载语义不变（`settle()` 必须同时清 `_resolve`）。

### 4.3 危险色分级

**契约（3 档，值与实测对比度都在 §2.1）**：

| 档 | 令牌 | 值 | 用在哪 |
