# 山海造物 · 品牌专项：包装设计 × Logo 终版定稿 工作流

> 版本 v1.0 · 2026-08-10 · 独立专项（优先级：最高，是后续所有产出的地基）
> 性质：内部底稿，仅供创始团队评估方向
> 上游资产：`01_品牌核心/_最新版/`（VI 手册 v2.0/v2.02、品牌书、品牌物料系统·Print、山海造物志-视觉规范 v0.1）、`改名记录/山海造物·品牌改名执行包 v0.1.md`、`12_治理与战略/` 各治理文档

---

## 1. 专项背景与必要性

1. **改名后 logo 未重新定稿**：品牌已从「山川造物」更名「山海造物」（因原中文商标被第三方注册），但：
   - VI 手册 v2.0 的主标志「山川印章」仍搭配旧名「山川造物 / 把山川带回家」；
   - 公众号侧（山海造物志 v0.1）用的是「单字山印章」方案；
   - 官网 favicon 目前是乱码占位符（非正式 logo）。
   → 存在至少三个 logo 概念并行，急需收敛为一个终版。
2. **包装是品牌触感的核心载体**：VI 手册已定义「外素内美」开箱哲学，但包装规范只覆盖「品牌卡片 / 天地盖内盒 / 手提袋+快递箱」三类通用件，**没有按尺寸逐款设计**——这正是本专项要补齐的部分。
3. **logo 规范是地基**：官网、ERP、小程序、内容物料、门店、包装的所有后续工作都应以终版 logo 为准，规范不落，处处返工。

## 2. 能力边界（谁负责什么）

| 角色 | 职责 |
|------|------|
| 创始人（李贺 / 廉澍） | 审美决策、方向拍板、终版定稿（**logo 定稿是人的决策**） |
| 专业设计师（建议引入） | 终稿视觉打磨、包装刀版、印刷工艺、打样跟进 |
| 商标/法务 | 「山海造物」商标查重与注册（吸取「山川造物」被占教训） |
| 印厂/材料商 | 打样、量产、材料验证 |
| AI 协作者（当前能力） | 品牌资产盘点审计、规格文档化、矢量稿（SVG）制作、设计示意/mockup、规范表、代码 token 落地（ERP/官网/小程序）、品牌审查清单、版本管理 |

**AI 能做到**：把「概念」变成「可执行规格 + 可审查清单 + 候选矢量稿 + 各端落地」；**AI 不能替代**：终版审美拍板、商标法律结论、印刷实物验证。

## 3. 工作流阶段设计

### Phase 0 · Logo 终版定稿（前置阻塞项，必须最先完成）

| 步骤 | 内容 | 产出 | 负责 |
|------|------|------|------|
| 0.1 盘点收敛 | 盘点现有概念：① 山川印章（VI v2.0 几何山+河）② 单字山印章（山海造物志）③ 既有 logo.jpg ④ favicon 占位；对照改名执行包约束（山海造物 / Nature's Creations / 把山海带回家 / Bring Nature Home） | 概念对照表 | 创始人 + AI |
| 0.2 方向决策 | 收敛为 1 个主方向（印章 / 字标 / 组合），出 2–3 个候选稿 | 候选稿（SVG） | 创始人拍板 |
| 0.3 技术定稿 | 四版本：标准版 / 纯图形版 / 反白版 / 单色版；定安全区、最小尺寸、色彩、字体、禁止用法 | 《品牌logo规范 v1.0》+ SVG/PNG 源文件包 | AI 起草 + 设计师精修 |
| 0.4 商标查重 | 「山海造物」商标查重与注册推进 | 查重结论 | 法务/代理 |
| 0.5 全触点替换 | favicon、ERP/官网 token、小程序、水印、文档模板同步换用终版 | 全触点统一 | AI 落地 |

**验收标准**：logo 在 16px favicon、30px 头像、名片、快递箱胶带四种极端场景下均清晰可辨；规范文档是唯一基准。

### Phase 1 · 包装尺寸矩阵（不同尺寸包装的单独设计）

| 步骤 | 内容 | 产出 | 负责 |
|------|------|------|------|
| 1.1 SKU 盘点 | 按产品线盘点：昆虫罩、相框、首饰、种子罩、香薰、集合框、展陈线高端（含现有规格/数量/售价带） | SKU 清单 | 创始人 + AI |
| 1.2 尺寸矩阵设计 | 建「品类 × 规格（S/M/L/XL）」矩阵，每格定义：盒型（尺寸、结构）、内衬、品牌卡片、工艺、用材 | 《包装尺寸矩阵 v1.0》 | AI 起草 + 设计师校验 |
| 1.3 尺寸化规格页 | 在 VI 包装规范基础上（品牌卡片 90×54mm、天地盖、外袋/箱、凹印工艺），为每个尺寸输出单独规格页 | 每尺寸一页规格 | AI 起草 |
| 1.4 命名联动 | 标品命名规则（系列+类型+规格）、集合框命名（山林·集/海岸·集/四季·集）、展陈线独立命名统一进包装信息层 | 命名与包装对照表 | AI + 创始人 |

**设计基准（沿用 VI v2.0 已定内容）**：微暖白 #FAFAF5 底；自然绿 #2D6A4F 主色；品类色（昆虫 #52B788 / 矿物 #7B68AE / 植物 #6DA34D / 海洋化石 #5B8FB9）；品牌卡片正面印章+品牌名+slogan（单色印刷、可凹印）、背面 SKU 三层文案（物种名 13pt 品牌绿 / 拉丁名 9pt 大地棕斜体 / 产地 / 一句话冷知识）；开箱「外素内美」。

### Phase 2 · 设计落地与验证

| 步骤 | 内容 | 产出 | 负责 |
|------|------|------|------|
| 2.1 设计稿 | 每个尺寸输出设计稿（AI 出 SVG/示意 mockup；终稿视觉交设计师） | 全尺寸设计稿 | AI + 设计师 |
| 2.2 打样验证 | 印厂打样 + 开箱体验实测（对照「外素内美」标准与停留/仪式感目标） | 打样通过件 | 设计师 + 印厂 |
| 2.3 成本核算 | 纸材、工艺、批量成本与定价/毛利联动（回填启动成本模型） | 成本表 | 创始人 + AI |

### Phase 3 · 规范固化与全端合规

| 步骤 | 内容 | 产出 | 负责 |
|------|------|------|------|
| 3.1 Token 对齐 | ERP `design-tokens.css`、官网 `tailwind.config.mjs` 对齐终版色值/字族（含品牌绿 #2D6A4F 等 VI 色系） | 代码 token 更新 | AI |
| 3.2 全触点替换 | favicon、水印、文档模板、包装源文件统一为终版 | 全触点统一 | AI + 设计师 |
| 3.3 审查清单 | 《品牌审查清单》：每个新物料上线前过 logo/色彩/字体/文案/禁止用法五关 | 审查清单 | AI 起草 |
| 3.4 版本管理 | 改名执行包执行状态回写；规范文档纳入 `12_治理与战略` 文档体系 | 版本台账 | AI |

## 4. 依赖与并行策略

```
Phase 0  Logo 定稿 ──► 阻塞 Phase 1 的视觉稿与 Phase 3 的全端替换
              │
Phase 1.1/1.2  SKU 盘点与尺寸矩阵草案 ◄── 可立即并行（不依赖定稿 logo）
              │
Phase 1.4/2.x  命名联动、设计稿、打样 ◄── 依赖定稿 logo
```

- **可立即启动**：1.1 SKU 盘点、1.2 尺寸矩阵草案、规范文档骨架（0.1 盘点也马上能做）。
- **必须等待定稿**：所有含 logo 的视觉稿、favicon/水印替换、印刷打样。

## 7. 下一步（我的建议）

1. **先做 0.1 + 1.1**：盘点现有 logo 概念与 SKU 清单（ERP 可导出藏品档案），当天可出结果；
2. **出 2–3 个 logo 候选 SVG**（沿用印章语言 + 新名「山海造物」），供创始人对比拍板；
3. 拍板后 48 小时内完成《品牌logo规范 v1.0》与 favicon/token 替换；
4. 包装矩阵按拍板优先级逐尺寸推进，首个尺寸打样。
