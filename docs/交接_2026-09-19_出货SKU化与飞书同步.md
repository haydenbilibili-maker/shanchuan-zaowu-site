## 1. 今天做完的事（都已上云、已验证）

### 1.1 出货单工作流 SKU 化（蓝图 §16–17）

- **价目表落地**：飞书交叉核对（亲手读 API，非手抄）→ 材料 **105 行** / 包装 **11 行**，
  走 ERP 模块 81 的「批量粘贴导入」或 `provision-studio-settlement.cjs --import` 导入。
  导入块由 **`scripts/gen-price-book-doc.mjs`** 生成（可重跑；改价改里面的 `PRICE_FIX`/`MAT_NEW`/`PKG_MAP`）。
- **出货 SKU 目录**：`studio_shipment_skus`（材料×等级×包装×尺寸×是否造景）。
  **SKU 不持有价格** —— 价格在出货时按当时价目表算并**快照**进单据（裁决 26）。
  - 小程序：`subpackages/extra/shipment-sku/`（超管工作台 → 出货开单）
  - ERP：模块 **83**「出货 SKU 目录」（`admin/src/components/StudioSkus.vue`）
- **造景成本**（裁决 33–36）：SKU 上勾「造景」+ 填成本（元/件）；**独立第四桶**，
  计入单据总额、**从毛利扣**、**不进手工费基数**；「有无造景」进唯一键、**金额不进键**。
- **顺手修掉一个钱相关的静默 bug**：引擎里**尺寸**缺失会报红，但**等级**缺失原先会**静默按默认等级算钱** ——
  已改成同尺寸一样报红（`test:studio-pricing` C8/C9 钉住）。

### 1.2 飞书同步搬到**服务端**（蓝图 §18）

**根因**：飞书的读取与字段映射原先**只存在于 ERP 前端**，云函数一个飞书凭据都没有
→ 仪表盘会一直是老数据，除非有人正好打开 ERP 点一下。

- 新增云函数 **`syncFeishuData`**（仅超管）：`status` / `pull` / `config.get|save`。
  三条约束：**不重写写库逻辑**（复用既有 `upsertFromFeishu`）、**不重写映射**
  （优先读 ERP 已保存的 `configs/feishu_bitable`）、**不直接写业务集合**。
- 小程序超管工作台新增「**飞书同步**」入口（`subpackages/extra/feishu-sync/`）。
- **自动同步默认关**（timer 每天 03:30，页面上有开关）。
- 实测：`pull rawInventory` 把原材料库存从 **0 → 205**（与飞书一致，两路交叉验证）。

## 3. 今天发生过一次数据事故（已修完，但你要知道）

`syncFeishuData` 的"表选错"保护用了**比例判据**，边界漏判 → 把飞书「库存管理」的
**205 行原材料/工具/包材写进了 `studio_inventory`（成品库存）**。

- **已清理干净**：新增 `manageStudioInventory.removeFeishuSynced`（仅超管，
  删除条件写死：有 `feishuRecordId` + `sourceLabel=飞书成品库存` + **无 `snapshotId`**），
  循环删 **205 条** → 台账回到 **47 行 / 0 条 feishuRecordId**，与动手前读数**一致**。
- **已加两道闸**：① 每个同步目标声明**签名列**（缺一即拒同步）；
  ② `status`/`pull` 前做**列名体检**并把 `missingColumns` 显式报出，`pull` 时裁掉不存在的列
  （否则空值会覆盖库里的好数据）。
- **裁决 37（产品负责人）**：**成品库存的真源是小程序里的人工盘点，飞书同步不得写它** ——
  已从 `TARGETS` 移除 `inventory`。

## 4. 今晚开工前请先知道

### 4.1 门禁与命令

```bash
node scripts/run-guards.mjs              # 全部守卫（当前 104 条，必须全绿）
node scripts/run-guards.mjs --domain settlement   # 只跑本域 + cross（开发内循环）
npm run check:miniprogram-sync           # 双仓是否一致（开发者工具编译的是**开发仓**）
```

- **不要用 `npm run check:admin`**：沙箱写不了 `~/.npm/_logs`。
- **`npm run check:admin:selftest` 必须在隔离 worktree 里跑**（它会注入并还原源码，共享工作区会覆盖别人的在写内容）。
