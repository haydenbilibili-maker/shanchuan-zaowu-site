## W1 · 字号与排版统一
- **目标**：把「49 种字号」收敛到一套**令牌级字阶**（建议 18/20/22/24/26/28/30/32/36/40/44/48/56/64），
  消除 22 种孤立值（差 1rpx 噪音）。
- **手段**：
  1. 新增**只报告不改动**的 `npm run report:type`（范式同既有 `report:colors`）：按文件/选择器列出字号分布与「离群值」；
  2. 定义 `--fs-*` 令牌（写进 `app.wxss`，与 `--font-*` 并列）；
  3. 按**页面批次**替换硬编码（一次一页，替换后跑该页相关守卫）；
- **可验收证据**：`report:type` 前后对比（`49 → ≤14` 种取值、孤立值 `22 → 0`）；
  新增**棘轮守卫**（新代码不得引入非令牌字号；硬编码总量单调下降）。
- **风险**：字号改动会牵动**行高与容器高度** → 必须真机扫一眼重点页（E8）。

## W2 · 弹窗与提示统一（量级最大）
- **目标**：全站 `wx.showToast` / `wx.showModal` 收敛到 `AppToast` / `AppModal`（或明确的豁免项）。
- **手段**：
  1. `npm run report:dialog`（只报告）：按页面统计原生调用数 + 现状截图清单；
  2. **棘轮先上**：新增守卫禁止**新增**原生调用（守住不再增长），再按页面批次迁移；
  3. 迁移顺序：**高频页优先**（详情 / 礼赠编排 / 我的 / 订单 / 履约看板）；
- **可验收证据**：原生调用数 `1834 →` 逐批下降（每次提交附数字）；棘轮守卫拦截新增；
  弹窗文案过 `check-modal-text`（已存在）、样式过 `check-modal-style`（已存在）；
- **豁免**：确有必要的系统级提示（如 `wx.showToast` 的无障碍/性能特例）→ 列入白名单并写明理由。

## W3 · 文案一致性
- **目标**：一份**术语表** + 守卫，让全站用词统一。
- **术语表（首批）**：**受礼人**（禁用「收礼人」）、**礼笺**、**藏品**、**标本师**、**孤品**、**装裱**、**博物级**；
- **手段**：`npm run check:copy-terms`（守卫，含 `--selftest`）：扫描 wxml/js 中**禁用词**并报文件行；
- **已完成**：本批已把 8 处「收礼人」改为「受礼人」并落守卫；
- **可验收证据**：禁用词命中数 `→ 0`，守卫在 CI 常驻。

## W4 · 视觉设计风格：三级规范推广
- **已有**：详情页 L1/L2/L3 +「L1 之外不得出现品牌亮金」+ `check:detail-visual-tiers`；
- **目标**：把同一套规范推广到 **藏品库列表 / 礼赠 hub & 编排 / 我的 / 订单**；
- **手段**：每页先定「哪三个元素是 L1」，再收敛金色与字号（与 W1 联动）；
- **可验收证据**：每页一条 `check:<page>-visual-tiers`（或并入现有守卫）。
