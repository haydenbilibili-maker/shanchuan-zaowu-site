**误报说明（重要）**：首轮朴素正则曾报 97 条「tabBar 页面用 `navigateTo`」，逐条核对后**全部是 `fail:` 回调里的降级链**，例如 `subpackages/business/about/index.js:169-171`：

```js
goBack() { wx.navigateBack({ fail: () => wx.switchTab({ url: '/pages/user/index' }) }); }
```

正则把 `fail` 闭包里的 `url` 当成了外层 `navigateBack` 的参数。改用平衡括号取**顶层** `url` 后归零。

**唯一一处 P2（P2-7）**：`app.json:8` 把 `custom-tab-bar/index` 登记进 `pages`，而 `custom-tab-bar/index.js:4` 是 `Component({})`。官方自定义 tabBar 只需目录约定 + `tabBar.custom:true`，不需要进 `pages`。当前无页面跳它，故未见故障，属卫生问题（若将来被 `navigateTo` 命中会以「组件当页面」失败）。
