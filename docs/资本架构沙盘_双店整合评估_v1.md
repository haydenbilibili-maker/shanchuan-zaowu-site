## 一、执行摘要

1. **沙盘现有的估值锚点与真实基本面差 2.5–5 倍，必须先校准再对外用。** 沙盘总览页硬编码「6 个月营收 126.5 万 / 月均 17.5 万」，年化约 253 万；而你给的真实 TTM 是 93.7 万（月均 7.81 万）。所有下游数字（三档锚点 1500 / 4000 / 9000 万、推荐报价 4500 万）都建在那个高锚点上。中性锚点 4500 万隐含集团年净利约 173 万，相当于 5.3 家同等门店已经跑起来——这是「未来目标」，不是「今天估值」。

2. **双店合计的现实估值区间是 ¥550–850 万（中性），不是 ¥3500–4500 万。** 按楼下店取楼上店 80% 的中性假设，双店合计营收约 168.7 万、净利约 55.3 万，零售逻辑 PE 12–15x 得 664–830 万，加 30% 战略溢价上限约 1080 万。若按 4400 万 post-money 融资，投资人算出来的 PE 是 79.6 倍——尽调环节必被击穿。

3. **单店公允值的可防守区间是 ¥80–150 万/店，不是 PE 高倍数。** 商场店受租约年限约束、没有永续价值，5 年有限期 DCF（20% 折现）给出楼上店 72–102 万。这个数字才是**回购、置换、收购定价**的基准；PE 高倍数只能用于集团层融资叙事，不能用于跟老投资人算钱。

4. **两店都在「这有山」同一商业体，对投资人是集中度风险而非双店溢价。** 商场客流波动对两店 100% 相关，不构成地理分散。必须诚实处理：双店的价值来自「主店零售 + 楼下工坊定制/课程」的业态互补，而不是「店数 ×2」。协同若不能用数据证明（工坊订单里来自主店引流的占比），估值只能加总甚至因管理分散打折。

5. **沙盘的门店维度是缺失的，这是结构性 gap。** ERP 财务账本本身已按 `storeId` 记账，但 `financeSandboxBridge.js` 把所有门店合并成一个总数推给沙盘；沙盘再用 `直营店数 × 单店营收` 反推——两店营收差异越大，误差越大。而且 `storeRev` 滑杆下限是 180 万，**根本无法表达 93.7 万的真实值**。

## 二、双店基本面整合

### 2.1 楼上店（星宸标本 / 既有店）· 已知数据

| 项目 | 数值 | 口径说明 |
|------|------|----------|
| TTM 营收 | ¥93.7 万 | 过去 12 个月 |
| 月均营收 | ¥7.81 万 | 93.7 / 12 |
| 净利率 | 30%–40% | **口径待确认（见下）** |
| 年净利 | ¥28.1 万 – ¥37.5 万 | 中值 35% → ¥32.8 万 |
| 营收展望 | 略降 | 消费环境 + 楼上同质化竞争 |

**净利率口径必须先确认这三件事**，否则整个估值浮动一倍：

1. **是否已扣创始人/主理人薪酬？** 沙盘内置双口径正是这个逻辑（账面 46% / 调整 29%，差额对应 ¥30k/月）。若你的 30–40% 是「不计创始人薪酬」，按两人市场化薪酬 6–8k/月计，年成本 14.4–19.2 万，调整后净利约 ¥16 万，净利率降到 **17%**。此时 PE 4–6x 只值 ¥64–96 万。
2. **是否已扣装修/展陈摊销？** 标本零售的展陈是持续性资本支出，不摊销会虚增净利。
3. **是否为税后？** 小微主体的实际税负与合规成本要落在模型里。

> 结论：对外报价用账面口径，但**内部决策和回购定价必须用调整口径**。建议在沙盘里把这两个口径的差额金额显式写出来，而不是只给两个百分比。

### 2.2 楼下门店 · 数据缺口与最小清单

仓库里楼下店目前只有 C 端展示数据（`miniprogram/cloudfunctions/getStoreConfig/storeSeed.js` 中的 `store_xingchen`），**没有任何财务数据**。且存在一处主数据不一致需要先修：seed 里「星宸标本工作室」标注的是 `locationLabel: '这有山 · 楼下'`、`floor: '楼下'`，而你的口径是星宸在楼上。命名与楼层必须先统一，否则后续所有按店拆分的报表都会错位。

**最小数据清单（10 项，缺任一项则楼下店只能给区间不能给点值）：**

| # | 数据项 | 为什么必须 |
|---|--------|-----------|
| 1 | 经营主体与股权：营业执照主体、股东出资、是否同品牌、商标授权关系 | 决定能否并表、直营化走收购还是换股 |
| 2 | 近 12 个月营收，按 POS / 私域 / 定制订单三口径分开 | 定制订单毛利结构与零售完全不同，混算会误判 |
| 3 | 成本结构：租金物业水电、人力（明确是否含创始人）、货品成本/毛利率、平台佣金、装修摊销 | 推导真实净利率，也是经营杠杆测算的输入 |
| 4 | **租约**：起止日、剩余年限、递增条款、押金、免租期、续约优先权 | 直接决定 DCF 的明确期年数，剩 2 年 vs 剩 5 年估值差 40% 以上 |
| 5 | 累计投入：装修 + 展陈 + 设备 + 首批库存的原值、账面余值、剩余折旧年限 | 资产法估值下限；也是收购对价的谈判底盘 |
| 6 | 标本库存：数量、成本、可变现价值 | 标本业态特有的重资产项，是估值里唯一的硬资产 |
| 7 | 客流与转化：进店人数、成交率、客单价、复购率 | 判断「略降」是客流问题还是转化问题，决定展陈调整能否见效 |
| 8 | 与楼上店的重叠度：SKU 重叠比例、客群重叠、互相分流估计 | 决定双店能否算协同溢价，还是要算内部分流折价 |
| 9 | 现有分红/合作协议：外部投资人、分红比例、锁定期、退出条款 | 直营化的最大障碍通常在这里 |
| 10 | 合规：标本经营资质、CITES 涉及品类清单 | 尽调硬门槛，出问题直接一票否决 |

### 2.3 楼下店的三情景占位假设（拿到真实数据前用）

## 三、估值锚点方法论

标本零售是「小微线下零售 + 内容/IP 溢价」的混合体。四种方法给出的结果差异很大，**用途不同不能混用**——这是当前沙盘最大的方法论问题。

### 3.1 方法一：净利倍数（PE）

| 层级 | 合理倍数 | 理由 |
|------|---------|------|
| 单店权益（不含品牌） | **4–6x** | 非上市小微、无控制权溢价、流动性折价大 |
| 集团层（含品牌/SOP/复制能力） | **10–15x** | 零售逻辑，对应现有投资文档口径 |
| 集团层（IP 赛道叙事成立时） | 20–30x | 需要 IP 授权收入或加盟已签约作为证据，**目前不成立** |

楼上店单体（含营收下滑 -10% 的调整）：

| 口径 | 净利 | PE 4x | PE 5x | PE 6x |
|------|------|-------|-------|-------|
| 账面 35% · 不下滑 | ¥32.8 万 | ¥131 万 | ¥164 万 | ¥197 万 |
| 账面 35% · 营收 -10% | ¥25.7 万 | ¥103 万 | ¥129 万 | ¥154 万 |
| 调整口径（扣创始人薪酬） | ¥16.0 万 | ¥64 万 | ¥80 万 | ¥96 万 |

### 3.2 方法二：营收倍数（PS）

**单店 PS 合理区间 0.8–1.5x**，不是沙盘代码里写死的 5x。5x 是「集团 + IP 赛道」口径，套到单店上会高估 3–6 倍。

- 楼上店：93.7 × 0.8 = **¥75 万** ｜ ×1.2 = **¥112 万** ｜ ×1.5 = **¥141 万**
- 双店合计（集团口径，含品牌资产）：168.7 × 1.5 = ¥253 万 ｜ ×3.0 = ¥506 万

### 3.3 方法三：EBITDA / 业主可支配收益（SDE）

小微零售实务里，买方看的是 SDE = 净利 + 业主薪酬 + 非经营性支出。以楼上店为例：

- SDE ≈ ¥32.8 万（账面净利，已含业主劳动回报）
- 市场化管理成本 ≈ ¥16.8 万/年
- 可转让盈利 ≈ **¥16 万/年** ← 这是「换个店长也能拿到」的钱

买方倍数 2.5–3.5x 可转让盈利 → **¥40–56 万**。这是最保守的地板价，也是对方压价时最可能拿出的算法，提前准备好反驳（品牌、内容、私域、库存资产不在此列）。

### 3.4 方法四：简化 DCF（推荐作为置换/回购定价基准）

轻资产、维护性 capex 低，可近似 FCF ≈ 净利（扣展陈更新支出）。商场店无永续价值，**明确期取租约剩余年限**，折现率 20%（小微线下、单一渠道依赖）。

以楼上店基准 FCF ¥30 万、5 年期：

| 情景 | 年变化 | NPV |
|------|--------|-----|
| 衰退 | -8%/年 | **¥72.5 万** |
| 持平 | 0% | **¥89.7 万** |
| 展陈调整见效 | +5%/年 | **¥102.3 万** |

> **关键判断**：DCF（72–102 万）显著低于 PE 4–6x（131–197 万），差额来自 PE 隐含永续、DCF 只算 5 年。商场店没有永续，**DCF 更接近真相**。
> 建议对外用 PE，对内和对老投资人用 DCF；单店成交区间定 **¥80–150 万**。

### 3.5 综合锚点（建议替换沙盘现有三档）

| 档位 | 区间 | 成立条件 | 用途 |
|------|------|---------|------|
| **保守 / 地板** | ¥250–400 万 | 双店现状、DCF + 资产法、不给品牌溢价 | 内部底线、回购定价 |
| **中性 / 锚点** | ¥550–850 万 | 双店直营已完成、净利 55 万、PE 10–12x + 品牌资产 | 对外首次报价的可防守值 |
| **乐观 / 目标** | ¥1200–1800 万 | 双店 + 至少 1 家加盟已签约 或 IP 授权已产生收入、PE 15–20x + 溢价 | 有多方竞标时使用 |
| 现有沙盘三档 | 1500 / 4000 / 9000 万 | 需 5 店以上 + 加盟体系跑通 | **改标注为「达成 X 店后的目标估值」** |

### 3.6 融资含义（直接影响下一步动作）

| 方案 | Post-money | 融资额 | 投资人占比 | 隐含 PE | 可行性 |
|------|-----------|--------|-----------|---------|--------|
| 沙盘默认（C·标准天使） | ¥4400 万 | ¥400 万 | 9.1% | **79.6x** | 尽调必被击穿 |
| 现实朋友轮 | ¥750 万 | ¥150 万 | 20.0% | 13.6x | 可谈，但稀释偏大 |
| 现实小额天使 | ¥900 万 | ¥120 万 | 13.3% | 16.3x | 需品牌叙事支撑 |
| **建议：先不融，做数据** | — | — | — | — | 12 个月把双店营收做到 250 万+、净利 80 万+，再按 PE 12–15x 谈 ¥1000–1200 万 |

按当前基本面融资，等于在最低估值点卖出最大比例股权。**先补基本面比先融资划算得多。**

## 四、未来直营化与股权架构路径

### 4.1 建议的四层结构（早期可合并 1、2 层）

```
① 品牌 / IP 主体（杭州山海造物文化创意有限公司）
   持有：商标、IP、SOP、数字资产、小程序与私域
   股东：创始人 + ESOP + 投资人 ← 融资只在这一层发生
        │
        ├─ 100% ─► ② 门店 SPV：长春主店（星宸标本）
        │            隔离租约、用工、标本经营合规风险
        │
        ├─ 100% ─► ③ 门店 SPV：长春楼下店
        │
        └─ 100% ─► ④ 工坊 / 供应链主体（若标本加工需独立资质）
```

早期不必先搭控股平台，`①` 直接持股各 SPV 即可，等门店数超过 4 家或引入区域合伙人时再加一层。**一店一 SPV 是必须的**——商场租约、用工纠纷、标本合规任一出问题都不会传染到品牌主体。

### 4.2 直营化的两条路径

**路径 A · 现金收购门店权益**
- 定价基准：DCF 口径 ¥80–150 万/店
- 优点：结构最干净，一次性了断，不影响集团 cap table
- 缺点：吃现金，且现有账上很可能拿不出

**路径 B · 换股（推荐）**
- 门店权益按公允值换集团股权。举例：楼上店估 ¥120 万，集团 pre-money 按 ¥700 万 → 对方换得 **17.1%**
- 与沙盘「置换计算器」逻辑一致，但沙盘默认 `cvGroupVal = 4000 万`。用 4000 万算，同样 120 万只换 3.0%——对方不会签；若对方接受，说明他没算过账，这种协议在下一轮融资时会翻案
- 配套条款：24 个月锁定期 + 业绩对赌 + 未达标回购权 + 4 年 vesting

**长春店现行三方协议是最大变量。** 现有结构是李贺 30% / 朱俊宇 30% / 廉澍 40%（回本前 4:4:2 → 回本后 3:3:4）。并入集团需三方同意，且需先明确「回本」是否已达成——这决定了朱俊宇现金流权益的现值，也决定他应换多少集团股。**这项要在做任何对外报价之前算清。**

### 4.3 执行顺序

1. 统一门店主数据与财务归集口径（1 周，纯 ERP 工作）
2. 拿齐楼下店 10 项数据，出双店真实净利表（2 周）
3. 用真实数据重跑沙盘，锁定三档锚点（1 周）
4. 拿锚点跟朱俊宇谈置换（DCF 口径，路径 B）
5. 杭州主体注册 + 门店 SPV 设立
6. 换股/收购落地，双店并入直营
7. 再谈融资

## 五、风险与敏感项

| 风险 | 量化影响 | 处置 |
|------|---------|------|
| **营收下滑（经营杠杆）** | 租金人力固定，营收 -10% → 净利 **-22%**（弹性约 2.2x）→ 估值同步 -22% | 沙盘必须加负增长档；对外报价预留这个缓冲 |
| **净利率口径被击穿** | 若 30–40% 未扣创始人薪酬，尽调后降至 17%，估值腰斩 | 现在就按调整口径准备一套数，别等对方问 |
| **同质化竞争** | 楼上多家同类店，标本本身无护城河 | 护城河在 IP、内容、定制与私域。用 SKU 独占率、定制订单占比两个指标去证明，讲不出数就别讲故事 |
| **双店协同未兑现** | 若楼下工坊无法转化主店客流，等于两个亚规模单店，估值只能加总甚至因管理分散打折 | 立即开始记录「工坊订单中来自主店引流的占比」，这是协同溢价唯一的证据 |
| **同一商业体集中度** | 两店客流 100% 相关，投资人视为集中风险而非分散 | 诚实披露，用业态互补而非店数讲价值 |
| **租约剩余年限** | 剩 2 年 vs 剩 5 年，DCF 差 40% 以上 | 两店租约到期日是估值第一硬约束，先查清 |
| **分红协议法律风险** | 未来加盟店分红投资若人数与宣传失控，触及非法集资边界 | 沙盘已标红，需私募律师审协议 |

## 七、需要创始人拍板的三件事

1. **30–40% 净利率是否含创始人薪酬、展陈摊销、税？** 这一项决定估值上下浮动一倍，是所有后续测算的前提。
2. **楼下店的经营主体与所有权状态** —— 同品牌还是独立主体？有无外部投资人？这决定直营化走收购还是换股。
3. **是否接受「先做 12 个月数据、再谈融资」** —— 按当前基本面融资，等于在最低点卖最大比例股权。
