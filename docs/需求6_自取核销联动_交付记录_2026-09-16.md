## 2. 自动刷新（核销联动）实现

`miniprogram/subpackages/business/pickup-pass/index.js`

| 常量 / 方法 | 作用 |
|---|---|
| `PASS_POLL_MS = 3000` | 待领取期间每 3s 静默读一次**自己的** `orders` 文档（顾客直读，无需新云函数、无需「按自取码查单」的顾客接口） |
| `PASS_POLL_MAX_MS = 15min` | 上限；超过即停表，回落下拉刷新 / 重新进入（顾客把页面晾在柜台后不再空耗） |
| `PASS_RESUME_MS = 1500` | 回前台静默补拉的节流，避开 `onLoad` 后的首个 `onShow`（原为 15s，感知太慢） |
| `startWatching` / `stopWatching` / `canWatch` | 只在「有订单号 + 待领取态」盯；`done` / `closed`、`onHide`、`onUnload` 立即停表 |
| `loadOrder` 去重 | 轮询 / `onShow` / 下拉刷新可能同时到达 → 同一时刻只保留一次读库（并发调用返回同一 Promise） |
| `announceClaimed` | 检测到「待领取 → 已交付」跃迁：停轮询 + 震动 + toast「门店自取已完成」+ 恢复屏幕亮度 |

**不做误报**：只有**先看到过待领取基线**（`_sawPending`）才提示成功态 ——
顾客打开一单历史已核销的凭证时，页面直接是终态，不震动、不弹「刚完成」。

**只有 `code` 没有 `id`**（历史链接）时不查库、不轮询：顾客不能按自取码查他人订单，页面标为「以专员核实为准」。

## 3. 「已自提」水印与收口形态

`pickup-pass/index.wxml` + `index.wxss`

- 二维码 **canvas 全页仅一个**（不因状态切换重建节点，避免 `selectorQuery` 取到旧节点）。
- done 态：`.pass-qr-used` 让码面变灰（`opacity: 0.2`），`.pass-qr-stamp` 以 `absolute + z-index:2` 盖上
  绿色斜章「已自提」（`rotate(-14deg)`，与 #7 券面 `.stamp-void` 打孔章同一视觉语言）。
- done 态**收起自取码行**（`.pass-code-row` 收在 `pass.statusTone !== 'done'` 分支内），
  只留对勾回执 + 核销时间；提示改「此自取码已核销，请勿再次出示」。
- 待领取态底部提示改为「店员核销后本页自动更新；也可下拉刷新。」
