## 六、执行方式

```bash
# 1) 再跑一次 dry-run 确认（不写库）
node scripts/scan-gift-scenes.mjs --dry-run --out /tmp/gift-plan.json
# 2) 确认后写入（自动生成回滚文件 + 只更新有差异的条目）
node scripts/apply-gift-scenes.mjs --apply
```

- 写入前会把每件商品的**原 `giftScenes`** 存到 `scripts/apply-gift-scenes-rollback.result.json`，可原样回滚；
- 幂等：已符合建议的条目不写；
- 结果落 `scripts/apply-gift-scenes.result.json`（与仓库既有 `*.result.json` 约定一致，且被同步守卫忽略）。
