# 祈福墙 ·「马上有」展品信息 —— 可用字段与待补清单（2026-09-27）

> 背景：产品负责人口径「马上有 = 门店核心 IP」，祈福墙要把这件展品讲清楚。
> 纪律：**不臆造展品信息**。本文件列出「已有出处、已上墙」的字段，以及「没有出处、需要产品负责人提供」的字段。
> 代码落点：静态文案在 `miniprogram/config/wallExhibit.js`（字段旁逐条注明出处）；
> 商品侧字段由 `miniprogram/utils/wallExhibitProduct.js` 按既有只读方式从 `products` 取，读不到就不显示。

## 3. 需产品负责人点名的改动（本轮未做）

1. **官网加盟页的触摸文案**：`src/pages/for-franchise.astro` 第 17 行「摸一下它的鼻子，你马上就有」与 PRD §2.2「不得引导触摸标本」冲突。属官网文案，不在本轮范围。
2. **商品开墙字段进 ERP**：小程序已认 `wishWallEnabled` / `wishWallKey`（`utils/wishWall.isWishWallProduct` / `resolveWishWallKey`），但 ERP 商品表单里**没有**这两个字段，只能靠标题含「马上有」兜底命中。要让运营显式指定「哪件是马上有」，需要在 ERP 加表单项（涉及商品集合字段，稳定期需点名）。
3. **门店配置记录展品位置**：若要做到「在哪家门店可见实物」的精确展示，需要门店配置新增字段（稳定期需点名）。
