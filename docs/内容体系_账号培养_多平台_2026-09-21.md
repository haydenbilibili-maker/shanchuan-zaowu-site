## 1. 第一原则：账号人格不能只有一张脸

山海造物在内容工厂里**已经定义了两个 IP 人格**（`admin/src/config/contentConstitution.js` 的 `IP_TONE`）：

| IP | 调性 | 语言禁令 | 适合的内容 | 适合的平台 |
|----|------|---------|-----------|-----------|
| **`GRAVITY`** | 沉静、单句偏长、节奏慢；可留白 | 禁「哇/绝了/太好看了/爆款/冲/必入」等刺激词与感叹堆砌 | 工艺纪录、博物小课、光与容器 | 视频号、小红书（质感向）、B 站（第三阶段） |
| **`LIGHTNESS`** | 明亮、亲切、可读性强 | 禁「宝宝们/家人们/卖萌/亲/集美」等廉价称呼与直播腔 | 日常、人物、开箱、知识轻讲 | 抖音、小红书（日常向） |

### 1.1 为什么必须分人格

- **同一张脸打三个平台**会导致：抖音嫌你太慢、小红书嫌你太吵、私域嫌你太营销。
- 双 IP **本来就是品牌资产**，不是本次规划发明的——内容工厂、话术宪法都按双 IP 校验。
- 分人格**不等于分裂品牌**：两者共用一个品牌名、一个 VI、一套《不做清单》。

### 1.2 账号矩阵（推荐形态）

| 账号 | 平台 | 人格 | 定位 | 更新频率 |
|------|------|------|------|---------|
| **山海造物**（主号） | 抖音 | `LIGHTNESS` 为主 | 拉新破圈 | 3–5 条/周（第一阶段 3 条） |
| **山海造物**（主号） | 小红书 | 双人格并用 | 种草与搜索长尾 | 3–5 篇/周 |
| **山海造物**（主号） | 视频号 | `GRAVITY` | 沉淀与转发 | 1–2 条/周 |
| 山海造物·工坊（垂类号） | 小红书/抖音 | `GRAVITY` | 手艺深度（**第二阶段再开**） | 2 条/周 |
| 山海造物·门店号 | 小红书/抖音 | `LIGHTNESS` | 到店与活动（**第三阶段再开**） | 2 条/周 |
| **小程序 + 企业微信/社群** | 微信自有 | 品牌一致 | 承接、复购、UGC | 持续 |

> **纪律：第一阶段只开 3 个主号 + 私域。** 垂类号/门店号在闸口 1 通过前不开——
> 开号容易，持续供内容是难的，空号比没号更伤。

## 2. 抖音：拉新与破圈

### 2.1 平台特性（决定打法）

| 特性 | 对内容的含义 |
|------|-------------|
| 推荐制，靠完播/互动/关注转化 | 前 3 秒决定生死；**内容必须自证价值** |
| 竖屏、快节奏消费 | 15–45s 为主，一屏一个信息 |
| 强算法、人群画像快速成型 | 冷启动期**账号标签一致性**极重要（别今天拍蝶明天拍矿石后天拍猫） |
| 评论区也是内容场 | 评论回复本身要能产出新选题 |

> ⚠️ **与品牌调性的张力（必须拍板）**：`GRAVITY` 的「慢」与抖音的「快」天然冲突。
> 本文件建议：**抖音主号用 `LIGHTNESS`，把「慢」留给视频号与小红书。**
> 若业务坚持抖音也走慢节奏，请回到总纲 §8 Q7 拍板并书面确认接受增长较慢。

### 2.2 主页五件套（开号即定，不要反复改）

| 项 | 要求 | 反例 |
|----|------|------|
| 头像 | 主标志（**山海印章纯图形版**，深色底用反白版） | ❌ 随手一张门店照 |
| 昵称 | `山海造物`（与品牌规范一致） | ❌ 「山海造物 Nature's Creations」同行混用（VI 手册明令禁止） |
| 简介 | 一句话说清「我们做什么 + 你能看到什么 + 去哪找你」，含小程序引导 | ❌ 堆关键词 |
| 背景图 | 一张 `SC-CABINET` 或 `SC-WORKSHOP` 横图 | ❌ 网图 |
| 置顶 | 3 条：**最好的一条工艺片 + 一条博物小课 + 一条门店/人物** | ❌ 置顶促销 |

### 2.3 内容配比（第一阶段）

| 类型 | 占比 | 说明 |
|------|------|------|
| 工艺爽感（P2） | 40% | 切、钉、封、擦——动作明确、有完成感 |
| 博物小课（P3） | 25% | 「这只好看在哪」的知识反转 |
| 光与容器（P1） | 20% | 氛围片，用于涨粉后的调性沉淀 |
| 人物/门店（P4） | 15% | 冷启动期靠员工与主理人 |

### 2.4 前 3 秒钩子库（与话术宪法兼容）

**铁律：钩子里不能出现「标本作主语 + 主动动词」。**

| 钩子类型 | 示例（合规） | 为什么有效 |
|---------|-------------|-----------|
| 尺度数字 | 「内口每边多留 1 到 2 厘米——多的那点，是给以后的季节。」 | 具体数字 + 悬念 |
| 动作入画 | （无口播）手直接开始切 45 度角，第 2 秒出现缝隙 | 动作即钩子 |
| 反常识 | 「标本框最容易坏的地方，不在玻璃，在背板。」 | 认知冲突 |
| 价格诚实 | 「这个框的成本一半在木料，我把单子给你看。」 | 诚实即差异化 |
| 光的变化 | 「下午三点，这道光会自己走到这里。」 | 期待感 |

**禁用钩子**：`❌「太美了！」 ❌「最后一个，抢完就没」 ❌「家人们快看」 ❌「必入」`

### 2.5 发布纪律

| 项 | 规则 |
|----|------|
| 频率 | 第一阶段 ≥ 3 条/周；**不追求日更**（质＞量，且要留复盘余量） |
| 时段 | **用自己的后台数据决定**，不要抄网上「黄金时段」；冷启动期可试 12:00 / 19:00 / 21:00 三档比较 |
| 文案 | 走话术宪法；话题标签不超过 5 个，且**必带品牌词与品类词** |
| 评论区 | **每条都要回**（冷启动期评论区互动是算法信号）；回复内容可进选题库 |
| 私信 | 有人问价 → 统一话术引导小程序（**不在私信里直接报价成交**，避免私下交易风险） |
| 不做 | ❌ 买粉/刷量 ❌ 搬运他人素材 ❌ 用品牌 VI 手册禁止的写法 |

## 3. 小红书：种草与信任

### 3.1 平台特性（决定打法）

| 特性 | 对内容的含义 |
|------|-------------|
| **搜索驱动**，笔记有长尾 | 关键词研究比发布时间更重要；标题要含**用户会搜的词** |
| 图文仍是主流且成本低 | 图文笔记是第一阶段**性价比最高**的形式 |
| 收藏/点赞比评论更重 | 做「值得存下来」的内容（清单、教程、对照） |
| 用户带着目的来 | 「怎么选/怎么养/怎么搭/送什么」类内容转化最好 |
| 对硬广敏感 | **必须有信息增量**，不能只是产品图 |

### 3.2 关键词库（建设的核心动作）

第一阶段建立并维护关键词表（放选题库，按周更新）：

| 词类 | 例（需用小红书搜索验证真实热度） | 用途 |
|------|--------------------------------|------|
| 品类词 | 蝴蝶标本、昆虫标本、标本框、玻璃罩、蝶翅画 | 标题必含 |
| 场景词 | 书桌布置、卧室装饰、玄关摆件、礼物、伴手礼 | 标题必含 |
| 人群词 | 自然爱好者、手作、家居审美、学生礼物 | 选题方向 |
| 求知词 | 标本怎么保存、标本会坏吗、标本怎么清洁 | 高转化内容 |
| 情绪词 | 把自然带回家、秋天的收束、安静的角落 | 调性内容 |

> ⚠️ **热度必须实测**：上方词表是**假设**，需在小红书搜索框逐词验证搜索联想与笔记量后再定稿。

### 3.3 内容配比（第一阶段）

| 类型 | 占比 | 形式 |
|------|------|------|
| 图文清单/教程（P3） | 35% | 「标本养护 5 件事」「蝴蝶标本怎么选」 |
| 质感视频（P1） | 25% | 30–60s，`GRAVITY` |
| 工艺过程（P2） | 25% | 制框、装裱过程 |
| 开箱/顾客故事（P4） | 15% | `LIGHTNESS` |

### 3.4 首图与标题规范

| 项 | 要求 |
|----|------|
| 首图 | **必须有信息量**：不是「好看的标本」，而是「能看出内容」的画面（手在做什么、光照在哪、几个格子里有什么） |
| 标题 | 含 1 个搜索词 + 1 个价值点；不超 20 字；**禁标题党**（小红书对夸张标题有流量惩罚） |
| 正文 | 走话术宪法；第一段给价值，不铺垫 |
| 标签 | 品类词 + 场景词 + 品牌词；不堆砌 |
| 评论 | 引导「想看哪个角度」类互动，而非「求链接」 |

### 3.5 发布纪律

| 项 | 规则 |
|----|------|
| 频率 | 第一阶段 ≥ 3 篇/周（图文与视频混排） |
| 合集 | 满 10 篇后建**合集**（如「制框日常」「博物小课」），合集是长尾放大器 |
| 专业号 | 是否开专业号（企业号）**待确认**（涉及认证与商业化合规，见总纲 §9 C2） |
| 不做 | ❌ 抄袭/洗稿 ❌ 互赞互粉群 ❌ 极限词（最/第一/唯一） ❌ 未标注的广告 |

## 4. 微信小程序 + 私域：承接与复购

> 详细运营见 `docs/内容体系_私域与转化闭环_2026-09-21.md`，本节只讲**账号侧的培养**。

### 4.1 与公域平台的根本区别

| 维度 | 抖音/小红书 | 微信小程序私域 |
|------|-----------|--------------|
| 流量归属 | 平台 | **自己** |
| 触达 | 受算法限制 | **可主动触达**（订阅通知/社群） |
| 归因 | 弱 | **强**（`entrySource` + `qr_material_enter`） |
| 转化 | 跳转有损耗 | **闭环内完成** |
| 内容形态 | 视频/图文 | 社区内容、祈福墙、直播、会员页 |

### 4.2 小程序侧的「账号培养」是什么

小程序没有「粉丝数」，所以培养的目标物是**三个可观测资产**：

| 资产 | 观测方式 | 第一阶段目标 |
|------|---------|-------------|
| **注册用户数** | 云函数/后台统计 | 有可归因的净增（来自内容与直播） |
| **会员/权益持有数** | 会员体系 | 有净增且可解释来源 |
| **可触达名单**（订阅通知授权 / 社群人数） | 订阅通知 + 社群 | 建立节拍（见私域文件） |

### 4.3 内容在私域里的形态

| 形态 | 用什么既有能力 | 频率 |
|------|--------------|------|
| 社区内容 | 小程序社区（41 篇既有内容 + 新拍素材） | 2–3 条/周 |
| 祈福墙 UGC | `docs/祈福墙_PRD_v1_2026-09-20.md` | 持续，周产出目标 ≥ 10 条（第三阶段） |
| 馆内直播 | `showLive` + 主播工作台 | 第一阶段 4 场 → 第二阶段每周 1 场 |
| 会员/积分触达 | 会员体系 + 订阅通知 | 按节拍 |
| 内容→私域入口 | 物料码 + `entrySource` | 印刷码/立牌/直播挂车 |

## 5. 90 天账号培养路线（第一阶段）

### 5.1 第 1–4 周：**开号与定型**

| 周 | 抖音 | 小红书 | 私域 |
|----|------|-------|------|
| W1 | 主页五件套 + 发 3 条（工艺 2 + 小课 1） | 主页装修 + 3 篇图文（清单型） | 确认承接阵地（总纲 Q5） |
| W2 | 3 条（工艺 2 + 人物 1） | 3 篇（图文 2 + 视频 1） | 建立第一版导流话术 |
| W3 | 3 条（小课 2 + 光 1） | 3 篇（教程 2 + 质感 1） | 把 1 条内容挂上物料码路径 |
| W4 | 3 条 + **首次数据小结** | 3 篇 + 建第一个合集 | 首次归因核对（内容带来了几个人） |

**第 4 周末检查点**：三平台各累计 ≥ 12 条；确认「哪种内容自己的数据最好」——**不要凭感觉，看后台**。

### 5.2 第 5–8 周：**找信号**

| 动作 | 说明 |
|------|------|
| 加倍表现最好的 1 种内容 | 用它填满 50% 的产能 |
| 砍掉表现最差的 1 种 | 进 `stopList` |
| 试投流（**小额**，可选） | 只投已验证的内容，不投未验证的；金额待 Q4 预算确认 |
| 开始评论区选题 | 每周从评论里捞 ≥ 3 条选题进 `content_topics` |
| 直播首播 | 4 场（见直播文件） |

**第 8 周末检查点**：能说出「我们的观众是谁、他们要什么」——如果说不出来，说明复盘没做真。

### 5.3 第 9–12 周：**固定节拍**

| 动作 | 说明 |
|------|------|
| 固定栏目雏形 | 每个平台定 1 个固定栏目（有名字、有片头） |
| 固定周更 | 三平台周更不断档 |
| 内容→私域路径跑顺 | 有稳定（哪怕很小）的每日/每周新增 |
| 闸口 1 自评 | 对照总纲 §3.1 的四条逐条打勾 |

### 5.4 里程碑（相对口径，**不承诺绝对粉丝数**）

| 里程碑 | 判据 |
|-------|------|
| M1 开号完成 | 三平台主页五件套齐 + 各 ≥ 3 条内容 |
| M2 找到信号 | 至少 1 种内容类型的**互动率**显著高于其他（用自己的后台对比） |
| M3 节拍成立 | 连续 4 周周更达标且未追加人力 |
| M4 路径跑通 | 至少 1 条内容带来可归因的私域新增 |
| M5 闸口 1 通过 | 总纲 §3.1 四条全满足 |

> **为什么不给绝对粉丝数**：粉丝数取决于平台扶持、投流、赛道竞争等不可控因素，
> 写死在文档里只会制造「没达标=失败」的假信号。**要盯的是「节拍是否稳定」和「路径是否可归因」。**

## 6. 一源多切的分发纪律

**同一条母素材，三平台三种切法**（不是复制粘贴）：

| 平台 | 切法 | 标题/文案 |
|------|------|----------|
| 抖音 | 20–40s，前 3 秒动作钩子，字幕少 | 口语化，带话题 |
| 小红书 | 30–60s 或图文，首图有信息量 | 含搜索词，干货向 |
| 视频号 | 60–180s 完整版，`GRAVITY` | 沉静，适合转发 |
| 小程序社区 | 横屏完整版 + 工艺/养护说明 | 与百科/养护页互链 |

### 6.1 分发登记（必须做）

每条成品在 `content_pieces` 里登记时，**必须写清**：

- `platform`：这条是给哪个平台的（同一素材切出的多条 = 多条 `content_pieces`）
- `publishMeta.externalUrl`：发布后的真实链接
- `metrics`：回填真实数据（`views` / `完播率` / `收藏` / `评论具体句` / `引流私域`）

> ⚠️ **不登记 = 不存在。** 内容工厂的价值全在「可复盘」，发了不登记等于白做。

## 7. 老号救活 vs 冷启动（差异打法）

| 维度 | 冷启动（0 粉） | 老号救活（有粉但停更/标签乱） |
|------|--------------|---------------------------|
| 前 2 周 | 直接发内容，用高频帮算法定型 | **先清标签**：连续 7–10 天只发核心品类内容 |
| 主页 | 一次装修到位 | 重装修 + 隐藏/删除与现定位冲突的历史内容（**谨慎，删除可能损失权重**） |
| 内容 | 严格按 §2.3 配比 | 前 30 条**只发 P2/P3**，把账号标签拉回「手作/标本」 |
| 互动 | 从头养 | 先清理僵尸粉/无关评论，再重启互动 |
| 预期 | 3–4 周见信号 | 可能 4–8 周才有反应（历史标签拖累） |

> 具体走哪条路，取决于总纲 §8 Q1 的答案。

## 8. 合规与风险控制

| 风险 | 控制动作 |
|------|---------|
| 平台对标本类目的限制 | 总纲 §9 C1–C4 必须人工核实后再放量 |
| 极限词/虚假宣传 | 话术宪法已禁「不夸大」；额外加一道人工终审 |
| 私下交易 | 私信一律引导小程序，不在私信成交 |
| 肖像/隐私 | 顾客、员工、未成年出镜需授权（总纲 C5） |
| 学名/产地错误 | P3 类内容需二次核对（总纲 C6） |
| 账号安全 | 主号绑定固定手机/邮箱，开启双重验证；**不要把账号密码交给外包** |
| 素材版权 | 只用自己拍的；BGM 用平台曲库；**复核 41 篇既有社区内容是否有引用风险** |
