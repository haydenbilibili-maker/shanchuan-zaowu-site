## 3. 使用纪律（**先看这一节再用**）

1. **本套是规划，不是已发生的交付。** 凡未标「已核实」的数字（人力、预算、粉丝、产能、节庆档期）都是**假设**。
2. **开工前先看总纲 §8「待产品负责人确认项」**——那里 8 条不拍板，执行会空转。
3. **合规条目（总纲 §9）必须人工去平台核实**，AI 不替平台下结论。
4. **不要另起炉灶**（总纲 §6）：选题/脚本/终审/复盘一律走内容工厂；直播一律走小程序主播工作台。
5. **产能表（总纲 §7）是估算**：跑满 2 周后回来修正，再据此调阶段目标。
6. **测不了的就写「不可测」**，不要为了周报好看编数字（私域文件 §9 已列明当前测不了什么）。

## 4. 最短上手路径（今天就能做的三件事）

1. **读总纲 §8**，把 8 条待确认项发给产品负责人拍板。
2. **按拍摄文件 §2.1 凑出起步设备包**（一台手机 + 三脚架 + 一盏灯 + 一个麦），
   定下**每周固定拍摄日**（拍摄文件 §6.2：周一）。
3. **照拍摄文件 §5.1 的片单模板**写下第一次拍摄日的 8 条母素材，拍完 24 小时内落库到内容工厂。
