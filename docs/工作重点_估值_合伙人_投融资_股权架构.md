## 1. 为什么是这四个主题

`文档体系治理总览 v0.1` 的待办全账中，**D · 资本结构/股权设计模块** 是唯一与「拓店」并列的 P1 级待开工模块，含四个子项，与本主题一一对应：

| 治理总览待办 | 对应主题 | 状态 |
|------|------|------|
| D1 · 估值模型（可比公司、收入/EBITDA 倍数、品牌 IP 与标本库存资产估值） | **估值** | 未开工 |
| D2 · 员工期权池设计（池规模、vesting、行权价、刷新机制） | **合伙人管理** | 未开工 |
| D3 · 期权授予标准（角色 × 表现 × 任期 × 里程碑） | **合伙人管理** | 未开工 |
| D4 · 投资人股比估算（pre/post-money、轮次稀释、特殊条款） | **投融资 / 股权架构** | 未开工 |

同时，创始人级治理文档（双 CEO 架构、创始人 IP 治理）已在 2026-05 完成 v0.1，被列为「最高优先级 #11/#12」，需要从文档走向机制。因此这四个主题是「文档已有、机制未成」的下一阶段主战场。

## 3. 现状要点速览（已调取的既定结论）

**股权架构（方案层已定，法律层未动）**
- 双层架构：品牌平台公司（拥有品牌/IP/SOP/渠道）+ 门店投资实体（外投资金、公司能力入股）。
- 公司层股权：李贺 45% / 廉澍 35% / 人才期权池 20%（双方各出 10%）。
- 门店层三模式：① 长春店按现有协议独立运行（回本前 4:4:2 → 回本后 3:3:4），公司与门店签《品牌授权与管理服务协议》；② 合作门店固定 60:40（投资人 ≤3 人、设投资人代表）；③ 全资直营店（未来战略高地旗舰）。
- 保护条款：4 年成熟期（每年 25%）、未成熟部分按约定估值回购、IP 一律归公司、竞业 2 年、每月对账 + 季度财务报告。

**估值（锚点已提出，模型未建立）**
- 融资三档：种子 300–500 万 / 天使 800–2000 万 / A 轮 3000 万–1 亿。
- 估值体系双轨：零售逻辑（单店 2–3x 营收、公司 PE 10–15）vs IP 逻辑（IP 店 5–10x、公司 PE 25–40）。
- 沙盘已有三档估值锚点与五情景对照，但**参数未与真实财务基线校准**，D1 估值模型未建。

**投融资（材料齐、动作未启动）**
- 原则：投资人进公司层、每轮 ≤20%、创始人合计 ≥51% 底线。
- 材料：BP、投资说明、IP 叙事、路演文档均已成稿（2026-04），需对齐最新股权/估值后再外发。
- 工具：沙盘含稀释模拟、融资后股权架构、三阶报价、见顾问前 12 问，可支撑谈判。

**合伙人（机制文档已成、落地动作待做）**
- 双 CEO（李贺内容/廉澍运营）+ 创始人 IP 模型 C 已定稿 v0.1，含季度回看机制。
- 期权池 D2/D3 未设计；保密/竞业模板有空项待补；无正式合伙人协议模板（现有仅门店合作协议）。

## 5. 工作重点框架（W1–W4）

> 输出物建议全部落到 monorepo（`shanchuanzaowu/docs/`）与 ERP 工具层；业务侧文件仍在桌面归档，完成版回写。

### W1 · 估值体系落地（D1）
- **目标**：从「叙事估值」走向「可计算、可校准的估值模型」。
- **输入**：财务基线（启动成本与跑道模型、四阶段对比、单店模型）+ 沙盘三档锚点 + TEVC。
- **动作**：
  1. 汇总并锁定财务基线口径（营收/毛利/现金流，与 ERP 财务核算对齐）；
  2. 建立估值模型 v1：可比公司法 + 收入/EBITDA 倍数法 + IP 资产（品牌、标本库存、数字资产）估值法；
  3. 回填资本架构沙盘三档估值锚点与五情景；
  4. 输出《估值模型 v1》文档，作为融资与股权回购的基准。
- **依赖**：财务数据口径确认；创始人确认三档锚点假设。

### W2 · 工作室/公司股权架构落地（D4 前置）
- **目标**：从方案到注册，双层架构实质化。
- **动作**：
  1. 拍板第 4 节待决 #1–#3；
  2. 委托律师起草《公司章程》《股东协议》（含 4 年 vesting、回购、竞业、IP 归属条款）；
  3. 完成杭州主体 + 长春工作室注册；
  4. 起草《品牌授权与管理服务协议》模板（公司 ↔ 门店），完成与长春店的第一次衔接；
  5. 规划长春店权益并入公司层路径（转让/换股，需三方同意）。
- **输出**：《股东协议》定稿、注册完成凭证、《品牌授权与管理服务协议》模板。

### W3 · 合伙人与人才机制（D2 + D3）
- **目标**：合伙人管理从文档走向机制。
- **动作**：
  1. 期权池设计定稿：规模（10% vs 20% 待决）、vesting 节奏、行权价、池刷新机制；
  2. 期权授予标准：角色 × 表现 × 任期 × 里程碑四维框架；
  3. 双 CEO / 创始人 IP 治理文档进入季度回看机制（已内置，需排期执行）；
  4. 补全保密/竞业模板空项并纳入入职流程；
  5. 评估 ERP 是否新增正式「合伙人/股权管理」模块（现「合伙人命理中心」不承担该职能）。
- **输出**：《期权池设计 v1》《期权授予标准 v1》、合伙人协议模板、ERP 模块建议。

### W4 · 投融资推进
- **目标**：材料与工具就绪，启动投资人对接。
- **动作**：
  1. 路演 BP / 投资说明 / IP 叙事对齐最新股权架构与估值锚点（避免外发旧版）；
  2. 组尽调资料包：财务模型、合作协议、IP 与商标清单、标本合规口径、数字化资产清单；
  3. 建投资人清单与接触节奏；使用沙盘「三阶报价 + 12 问」推进谈判；
  4. 同步《政策红利执行计划书 2026》（pages 待读）中可用的政策红利。
- **输出**：《尽调资料包 v1》、更新版 BP、投资人对接节奏表。

## 6. 建议的执行顺序

```
W1 估值（先定锚点，一切谈判的基准）
  ↓
W2 股权架构（方案→律师→注册→门店衔接）
  ↓ 并行
W3 合伙人机制（期权池 + 授予标准 + 协议模板）
  ↓
W4 投融资（材料对齐 → 尽调包 → 对接）
```

- **W1 与 W2 优先**：估值是谈判基准，股权架构是承接资本的前提；两者都无硬性外部依赖，可立即启动。
- **W3 与 W2 有耦合**：期权池规模影响公司层股权比例，须在律师起草前定稿。
- **W4 依赖 W1/W2**：外发材料必须对齐最终架构，避免旧版外发。
