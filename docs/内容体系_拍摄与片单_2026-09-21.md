## 2. 最低可行设备包（第一阶段不必买贵）

### 2.1 起步包（先跑通，能出片即可）

| 项 | 建议 | 用途 | 为什么够用 |
|----|------|------|-----------|
| 拍摄机 | **一台近三年的手机**（主摄 + 微距能力） | 全部内容 | 竖屏平台原生，第一阶段不需要专业机 |
| 稳定 | 三脚架 + 手机夹（含横竖切换） | 固定机位、延时 | 工艺类内容 70% 是固定机位 |
| 光 | **一盏可调色温的 LED 补光灯 + 柔光罩** | 工坊/桌面 | 自然光不可控，补光是画质分水岭 |
| 收音 | 领夹麦（有线即可）**+ 一支桌面麦** | 口播、工艺环境音 | 手机内录的环境音是最大的质感杀手 |
| 反光/背景 | 一块黑绒布、一块微暖白布（`#FAFAF5` 系） | 器物底衬 | 与品牌 VI 的微暖白一致 |
| 其他 | 无绒布、酒精棉（擦玻璃）、备用电池 | 拍摄现场清洁 | 制框流程本身就要用 |

**总成本**：约 ¥800–2000（不含手机）。**建议第一天就用这套拍出 10 条母素材**，不要等设备。

### 2.2 进阶包（第二阶段，跑出栏目后再加）

| 项 | 建议 | 解决什么问题 |
|----|------|-------------|
| 微距镜头（手机外接或相机） | 蝶翅鳞片、矿石断面、叶脉 | P3 知识点的「看清」价值 |
| 第二机位（或第二次拍摄） | 主镜 + 特写同时 | 一镜到底之外的剪辑自由度 |
| 滑轨 / 小摇臂 | 陈列墙横移 | P1 的「看的人经过」视角 |
| 持续灯 ×2（双色温） | 稳定布光 | 冬季日照短时的产能保障 |
| 录音笔 / 环境音采集 | 工坊、门店、雨、风 | `GRAVITY` 人格的「寂静」是需要录下来的 |

### 2.3 明确**不要**买（第一阶段）

- ❌ 无人机（除非有户外采集场景，且需空域合规确认）
- ❌ 大型影视灯/绿幕（与「克制、留白」的品牌调性相反）
- ❌ 昂贵相机（第一阶段瓶颈是流程不是画质）

## 3. 母素材标准化（进 `content_assets` 的硬要求）

母素材是**内容工厂的原料**，不是成品。凡是「拍完就扔在手机相册里」的，都不算母素材。

### 3.1 入库字段（对齐既有 `content_assets` 模型）

| 字段 | 必填 | 填写要求 |
|------|------|---------|
| `type` | ✅ | `video` 或 `photo` |
| `title` | ✅ | 见 §3.2 命名法 |
| `desc` | ✅ | **客观描述**：画面里有什么、几秒、什么声音。**不许写形容词**（改写 Agent 要用它，形容词会污染） |
| `fileRefs` | ✅ | 云存储路径或 CDN URL |
| `specimenRef` | 建议 | 关联藏品档案 id（可空） |
| `shootDate` | ✅ | 实际拍摄日 |
| `ipTags` | ✅ | `['GRAVITY']` / `['LIGHTNESS']` / 两者都有 |
| `reusableClips` | ✅ | 这条母素材能切出几条成品（估） |
| **新增建议字段** | | |
| `pillar` | ✅ | `P1` / `P2` / `P3` / `P4`（见总纲 §2） |
| `scene` | ✅ | §1 的场景 ID |
| `category` | ✅ | 用价目表口径：玻璃罩/相框/冰箱贴/精灵球/蝶翅画/压制标本/创意摆件/首饰/收藏级标本/其它标本 |
| `bio` | 建议 | 植物果实/海洋/蝴蝶/昆虫/哺乳动物/两栖动物/爬行动物 |
| `durationSec` | 建议 | 视频必填 |
| `orientation` | ✅ | `vertical` / `horizontal` / `both` |
| `audio` | 建议 | `has_ambient` / `has_speech` / `silent` |

> ⚠️ **新增字段（`pillar`/`scene`/`category` 等）需要落到 CloudBase 集合与内容工厂 UI**
> —— 这是**代码改动**，需按 AGENTS.md 的「新增云集合三处同步」与模块注册规范执行，
> 并先落蓝图。**本规划只提出字段需求，不代表已经实现。**

### 3.2 命名法（人可读、可排序、可检索）

```
YYYYMMDD_场景_题材_镜头_序号
例：20260928_工坊_制框_45度切角_01
    20260928_门店_玻璃罩陈列_横移_03
    20261005_祈福墙_写愿签_手部特写_02
```

**禁止**：`IMG_2024.mp4`、`新建文件夹`、`最终版`、`最终版2`。

### 3.3 单次拍摄的「三收」原则

每次开机必须**至少**收回三种素材，否则这次拍摄不划算：

| 收什么 | 为什么 | 最少时长 |
|-------|-------|---------|
| **过程**（一镜到底的完整动作） | P2 的主体，也最耐磨 | 60–180s |
| **细节**（手、工具、材质、纹理） | 剪辑的呼吸点、封面素材 | 每动作 3–5 个，各 5–10s |
| **环境/空镜**（光、容器、看的人、空间） | P1 的主体，`GRAVITY` 的骨架 | 5–8 个，各 8–15s |

## 4. 镜头语言规范（与话术宪法同构）

**核心原则（来自 `contentConstitution.js`）**：**标本不能作主语，也不能配主动动词。**
这对拍摄的直接翻译是：

| 话术规则 | 镜头翻译 | 具体做法 |
|---------|---------|---------|
| 主语只能是光/空气/季节/容器/看的人/时刻/产地/温度/湿度/声音/寂静 | **镜头主语也不能是标本** | 先给光（逆光、斜射、光斑移动）→ 再带出容器边缘 → 标本在景深里「被看见」 |
| 让出动词，用被动/描述性语态 | **避免「展示式」运镜** | ❌ 绕着标本转圈展示、❌ 推近强调「这就是新品」 ✅ 固定机位等待光变化、缓慢横移让标本进入画面 |
| 视角永远在标本之外 | **机位在「看的人」这一侧** | 加入肩膀、手的入画、玻璃反光里的房间，让观众感到自己是那个停留的人 |
| 诚实走过问题 | **不掩盖瑕疵** | 允许出现胶痕、木料砂痕、失败重做的镜头——这是可信度来源 |
| `GRAVITY` 禁刺激词 | **禁花字轰炸、禁加速卡点** | 少字幕、慢节奏、保留环境音 |
| `LIGHTNESS` 禁直播腔 | **禁夸张表情特写、禁「家人们」式口播** | 明亮、干净、正面光，语速正常 |

### 4.1 竖屏与横屏

| 平台 | 画幅 | 构图要点 |
|------|------|---------|
| 抖音 | 9:16 竖屏 | 主体放在上半 2/3（避开评论/按钮区）；字幕位置在安全区 |
| 小红书 | 3:4 或 9:16 | 图文的图用 3:4，视频用 9:16；首图必须有信息量 |
| 视频号/长视频 | 16:9 横屏 | P2 工艺纪录片用横屏 |
| 小程序社区 | 两者都要 | 社区内容列表以横图/方图为主 |

> **一次拍摄双画幅**：固定机位时横竖各拍一遍成本最低；运动镜头则**以竖屏为主**（公域分发优先）。

### 4.2 时长规范

| 形态 | 时长 | 用在哪 |
|------|------|-------|
| 强钩子短片 | 15–30s | 抖音 |
| 知识短片 | 30–60s | 抖音/小红书 |
| 质感短片 | 30–60s | 小红书 |
| 工艺纪录 | 60–180s | 视频号/小红书/小程序社区 |
| 直播切片 | 30–90s | 全平台复用（从直播回放切） |

### 5.2 母素材 → 成品的切分口径

**一条 120s 的过程素材，标准切出 3–5 条成品**：

| 切法 | 平台 | 处理 |
|------|------|------|
| 完整过程 + 环境音 + 少量字幕 | 小红书 / 视频号 | 保留原速 |
| 最精彩的 20s + 一个知识钩子 | 抖音 | 前 3 秒必须是「手在动」或「光在变」 |
| 3–5 张关键帧 + 长文案 | 小红书图文 | 静帧 + `desc` 改写 |
| 切片进小程序社区 | 小程序 | 横屏版，配养护/工艺说明 |

### 6.3 每个阶段的拍摄节奏

| 阶段 | 拍摄日 | 母素材目标 | 成品目标 |
|------|-------|-----------|---------|

### 6.4 排产前必须向供应链确认的四件事

- [ ] 蝶类/昆虫的**采集季与到货高峰期**（决定何时拍「新到标本」类内容）

- [ ] 矿石/化石的**补货周期**
- [ ] 门店**客流高峰时段**（决定直播时段与到店联动）

## 7. 拍摄 SOP（现场执行）

### 7.1 拍摄前一天

- [ ] 片单定稿（§5.1），发到跟拍群
- [ ] 场景清场：工作台只留本次要用的工具
- [ ] 设备充电、存储清空、麦试音
- [ ] 确认出镜人着装（与品牌调性一致：素色、无大 logo）
- [ ] 确认商品：本次要拍的 SKU 是否在库、状态是否完好

### 7.2 拍摄中（时间盒纪律）

| 时间 | 动作 |
|------|------|
| 0:00–0:15 | 布光 + 试拍 3 条（检查曝光/白平衡/收音） |
| 0:15–2:30 | 按片单逐条拍；**每条拍完当场回看** |
| 2:30–2:45 | 补拍空镜（光、容器、环境）——**永远不要跳过这一步** |
| 2:45–3:00 | 现场整理：清点、粗标记、确认无遗漏 |

**现场三条铁律**：
1. **宁可多拍 30 秒，不要少拍一个动作。** 事后补拍成本是现场的三倍。
2. **每个动作拍「完整一镜」+「特写」两遍**，剪辑才有选择。
3. **录 60 秒纯环境音**（不开机拍画面，只录音）——这是 `GRAVITY` 内容最缺的东西。

### 7.3 拍摄后 24 小时内

- [ ] 素材备份到云端（**两份**：本地 + 云存储）
- [ ] 按 §3.2 改名
- [ ] 落库 `content_assets`（§3.1 字段全填）
- [ ] 在 `desc` 里写客观描述（**不许写形容词**）
- [ ] 标记 `reusableClips`
- [ ] 把可用素材关联到 `content_topics` 的候选选题

## 8. 质量验收（母素材能不能用）

**单条母素材的验收 5 问**：

| # | 问题 | 不合格就 |
|---|------|---------|
| A1 | 画面里**有没有光的变化**（或容器/看的人）？ | 只有标本特写的，退回重拍 |
| A2 | **声音**能用吗（环境音干净 / 口播清楚）？ | 只有噪声的，标注 `silent` 并计划后期配音 |
| A3 | `desc` 是否**客观可读**（无形容词、无评价）？ | 重写 `desc` |
| A4 | 是否**已改名并落库**？ | 视为未完成 |
| A5 | `reusableClips` ≥ 1 吗？ | 若为 0，说明这条素材拍废了，记录原因 |
| **A6** | **画面是真实拍摄的吗？**（若用了 AI 辅助氛围，是否已标注？） | `STOP_LIST` 第 3 条硬红线：**标本画面须真实拍摄，AI 仅可辅助氛围且须标注** |

**拍摄日的整体验收**：当天产出的母素材里，`reusableClips` 总和 ≥ 10 才算合格的一天。
