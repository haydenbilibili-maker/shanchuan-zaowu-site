## §2 怎么证明「没丢工作」（四条判据，都可复跑）

**判据 1 · 未合并提交已重放**
```bash
git log --format=%s origin/main | sort -u > /tmp/_om.txt
git rev-list origin/main..guard-registration | while read c; do
  git log -1 --format=%s $c | grep -Fqx -f /tmp/_om.txt || echo "未重放 $c"; done | wc -l
# → 0（58/58 全部已在 origin/main 以相同主题出现）
```

**判据 2 · 未提交内容是否被取代**
```bash
# 逐字节比对：相同的算「已被 origin/main 取代」
git diff --name-only | while read f; do
  git show "origin/main:$f" > /tmp/_o 2>/dev/null && cmp -s /tmp/_o "$f" && echo same; done | wc -l
# → 87 / 109
```
另两条独立佐证：`guards/_meta.json` 的 `minGuards` 工作区 **154 < origin/main 163**；
`package.json` 工作区**缺** `check:privacy-consent` / `check:register-unify` / `check:gift-claim-link` /
`check:address-parse` / `check:gift-compose-steps` / `check:require-call-shape` / `check:subpackage-size` 七条。
→ 工作区是**旧状态**，不是新工作。

**判据 3 · 未跟踪文件是否都是孤儿**
```bash
git status --short | grep '^??' | sed 's/^?? //' | while read -r f; do
  [ -f "$f" ] || continue
  for b in origin/main polish/r4-r5 polish/molecular vis3/brand-mark fix/gift-buttons-nowrap; do
    git cat-file -e "$b:$f" 2>/dev/null && { echo "已收录 $f"; break; }; done; done
# → 12/12 全部「已收录」，零孤儿
```

**判据 4 · 全部本地分支的产物是否存在（含 09-18 的 6 条历史分支）**
```bash
for b in <每个本地分支>; do
  git diff --name-status -z --diff-filter=A integrate/claude-salvage-1013...$b | while IFS= read -r -d '' st; do
    IFS= read -r -d '' f
    git cat-file -e "integrate/claude-salvage-1013:$f" 2>/dev/null || echo "缺 $f"; done; done
```
