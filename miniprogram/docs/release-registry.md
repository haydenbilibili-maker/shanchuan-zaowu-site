# 小程序上传版本登记

> 对应审计 **P2**：无小程序 CI，靠开发者工具手动上传。  
> 每次**上传体验版 / 提交审核**时补一行，便于回溯。

| 日期 | 版本号 | 变更摘要（≤3 条） | 上传人 | 备注 |
|------|--------|-------------------|--------|------|
| 2026-09-12 | （见 release-notes） | 见 [release-notes-20260912.md](./release-notes-20260912.md) | — | 历史 |
| 2026-09-14 | （待填） | 安全闸门：口令下沉 / manageStoreContent / 账本云写 / DB 规则收紧；文档索引 | — | 审计修复轮次 |

## 用法

1. 微信开发者工具上传成功后，记下「版本号」与「项目备注」。  
2. 在上表新增一行；长说明可另开 `release-notes-YYYYMMDD.md` 并在此表链过去。  
3. 审核驳回时在「备注」写原因摘要。

不替代 `上线检查清单.md` / `快速测试清单.md`。
