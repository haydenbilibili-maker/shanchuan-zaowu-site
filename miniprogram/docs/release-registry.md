## 用法

1. 微信开发者工具上传成功后，记下「版本号」与「项目备注」。  
2. 在上表新增一行；长说明可另开 `release-notes-YYYYMMDD.md` 并在此表链过去。  
3. 审核驳回时在「备注」写原因摘要。

不替代 `上线检查清单.md` / `快速测试清单.md`。
