## 1.1 我的常用（同日追加）

- 位置：入口块最顶部（待办条之上），最多 **8** 个（两行）；角标与分区磁贴同口径。
- 配置：右上角「编辑」打开自绘底部面板（不是 `wx.showModal`）：已选可**上移 / 下移 / 移除**，下方按分区列出可加入入口，「恢复默认」「保存」；满 8 个时加入按钮置灰并提示。
- 长按磁贴「加入常用」**没做**：分区磁贴是静态标记，其它域守卫按 `bindtap="…">` 文本锚点检查，逐枚加 `bindlongpress` 收益小、风险面大；编辑面板已能覆盖。
- 默认：超管 = 订单 / 账本 / 报表 / 审批 / 有信 / 藏品 / 核销验票 / 会员 CRM；店长 = 订单 / 账本 / 核销验票 / 审批 / 工单 / 礼赠 / 藏品 / 积分；再按权限过滤。
- 权限与失效：存稳定 id（`hubNav.HUB_ENTRIES`），展示前归一化 —— 旧 id / 被合并 id 经 `FAV_ID_ALIASES` 映射（如 `giftOps` → `gift`、旧合并入口 `memberCurator` → `memberLevel`（会员调级）、`honoraryCurators` → `curators`、`shipmentSku` → `shipment`），未知 id 与无权限入口过滤，超出上限截断；点常用磁贴时再判一次权限。
- 存储：本机 `wx.setStorageSync('manager_hub_favs_v1')`，按工作台角色分键；**不跨设备**。已查：仓库里没有员工偏好的云端存储可复用（命中的仅顾客推荐函数），按要求不新建集合。
- 统一清单：`HUB_ENTRIES`（id / 名称 / 图标 / 分区 / 权限键 / 跳转 / 角标）是常用区的数据源；分区磁贴仍是静态 WXML（原因同上），由 `check:hub-entries` 逐枚比对二者（入口 / 名称 / 图标 / 权限 / 分区），漂移即红。
