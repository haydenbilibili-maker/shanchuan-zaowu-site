# 生日礼券发放说明

云环境：`cloud1-8gnkty5bfff9f0bf`

## 产品规则

| 项 | 说明 |
| --- | --- |
| 触发日 | **生日当天**（Asia/Shanghai；2/29 非闰年按 2/28） |
| 积分 | 200 分，写入 `users.bonusPoints`，`point_records.excludeGrowth=true`，**不计入成长值** |
| 优惠券 | 面额 ¥20 × 3 张；满 ¥100 可用（约 **8 折**，不低于 7.5 折地板）；有效期至**生日本月最后一天** 23:59:59 CST |
| 防重 | 同一自然年只发一次 |

> 折扣纪律：满减有效实付比例 `(X−Y)/X ≥ 0.75`（即 Y/X ≤ 0.25）。旧版「满 300 减 100」≈ 6.7 折已废弃。

## 触发方式

1. **客户端补发（主路径）**：「我的」页 `onShow` → `initUserData` → `claimBirthdayGift`（`action=claim`）
2. **资料页**：用户把生日改成今天并保存后，进入「我的」也会触发
3. **定时批处理（辅路径）**：云函数 `claimBirthdayGift` 定时触发器 `processBirthdayGifts`，Cron `0 10 9 * * * *`（每天 09:10，云开发时区 UTC+8），扫描 `birthdayMonthDay` 为今日且本年未发放的用户

未登录用户不会发放。未填写生日不发放。

## 关键字段 / 防重键

| 位置 | 字段 |
| --- | --- |
| `point_records.dedupeKey` | `birthday_gift:{openid}:{year}` |
| `point_records.excludeGrowth` | `true` |
| `point_records.source` | `birthday_gift` |
| `users.birthdayGiftYear` | 发放年份（数字） |
| `user_coupons.source` | `birthday_gift` |
| `user_coupons.sourceYear` | 发放年份 |
| `user_coupons.minSpend` / `value` | `100` / `20` |
| `user_messages` 模板 | `birthday_gift`，`relatedId=year` |

## 自测

1. 云开发控制台将测试用户的 `birthday` / `birthdayMonthDay` 改为**今天**（并清除或改小 `birthdayGiftYear`）
2. 删除该用户本年的 `point_records`（`dedupeKey` 含 `birthday_gift`）与 `user_coupons`（`source=birthday_gift`）
3. 打开小程序 →「我的」页，应弹出生日卡，积分 +200，券包多 3 张「满100减20」
4. 再进一次「我的」：不应重复入账；站内信「山海有信」可见生日快乐私信
5. 确认 `getUserStats` 成长值未因这 200 分增加

```bash
./scripts/tcb-fn-deploy.exp claimBirthdayGift cloud1-8gnkty5bfff9f0bf
./scripts/tcb-fn-deploy.exp dispatchMessage cloud1-8gnkty5bfff9f0bf
```

会员等级文案「生日礼券」：代码默认已改；云库 `member_levels` 若仍写「生日礼遇」，读取时会 remap。Admin 默认配置（`shanchuanzaowu` / `shanchuan-admin`）已同步。若希望云库文档永久改写，可在 Admin 会员等级页保存一次。

## 线上存量券

- 部署新版云函数后，**新发放**的生日礼为「满100减20 ×3」。
- 建议对云库执行迁移（新会员礼包配置、未使用的穿底券、积分兑券模板）：

```bash
node scripts/migrate-coupon-discount-floor.cjs --dry-run
node scripts/migrate-coupon-discount-floor.cjs --execute
```

迁移行为摘要：
- `member_welcome_gift` 礼券档位改为代码默认（满100减10 / 满200减30 / 满300减50 / 满500减100）
- 未使用的旧生日券「满300减100」→「满100减20」
- 其它未使用且 Y/X>0.25 的券、以及 `coupons`/`rewards` 模板：门槛抬至 `ceil(面额/0.25)`
- 已使用券不动；即使未迁完，下单侧仍会按原价 75% 钳制实付
