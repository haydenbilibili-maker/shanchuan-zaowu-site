## 🔐 登录与权限

### 小程序端登录

1. 打开小程序，进入"我的"页面
2. 点击"店长后台"菜单项
3. 输入管理员密码（密码由超级管理员提供）
4. 登录成功后进入管理看板

### Web端登录

1. 访问Web管理后台地址
2. 在登录页面输入管理员密码
3. 登录成功后进入经营驾驶舱

### 权限说明

- **管理员**：拥有所有模块的操作权限
- **普通运营**：根据分配的权限操作对应模块
- **密码安全**：定期更换密码，不要泄露给无关人员

## 📦 商品/藏品管理

### 功能说明

管理商品/藏品的上架、下架、价格、库存等信息。

### 小程序端操作流程

#### 1. 查看商品列表

**路径**: 店长后台 > 藏品库

**步骤**:
1. 进入管理后台，点击"藏品"菜单
2. 查看当前所有商品列表
3. 支持按分类、状态筛选

#### 2. 新增商品

**步骤**:
1. 点击"新增"按钮（右上角+号）
2. 填写商品基本信息：
   - **商品名称**：必填，如"黑金甲虫标本"
   - **拉丁名**：可选，如"Pachnoda marginata"
   - **分类**：选择商品分类
   - **价格**：必填，单位：元
   - **成本价**：可选，用于计算利润
   - **库存**：必填，当前可用库存数量
   - **描述**：商品详细描述
   - **是否为珍品**：勾选后会在商品详情页显示特殊标识

3. 上传商品图片：
   - 支持多图上传
   - 第一张图片作为主图
   - 建议图片尺寸：800x800px

4. 营销设置（可选）：
   - **限时秒杀**：
     - 开启秒杀开关
     - 设置秒杀价格
     - 设置秒杀库存
     - 设置开始/结束时间
     - 设置限购数量
   
   - **拼团**：
     - 开启拼团开关
     - 设置拼团价格
     - 设置成团人数（如2人、3人等）

5. 点击"保存"完成商品创建

#### 3. 编辑商品

**步骤**:
1. 在商品列表中点击要编辑的商品
2. 修改需要更新的信息
3. 注意：修改价格和库存会影响已下单但未发货的订单
4. 点击"保存"完成更新

#### 4. 下架商品

**步骤**:
1. 在商品列表中点击商品
2. 将库存设置为0，或删除商品
3. 已下架商品不会在前端展示

#### 5. 库存管理

**操作要点**:
- 实时关注库存数量，及时补货
- 库存为0时，商品自动下架
- 定期盘点实物库存，确保数据准确性

### Web端操作流程

**路径**: 藏品档案库

**操作说明**:
- 功能与小程序端一致
- 支持批量导入导出
- 表格形式展示，便于批量操作
- 支持高级筛选和搜索

### 注意事项

1. ⚠️ **价格修改**：已付款订单不受价格变动影响
2. ⚠️ **库存预警**：库存低于5件时建议及时补货
3. ⚠️ **图片规范**：上传清晰、美观的商品图片
4. ⚠️ **分类管理**：正确分类有助于用户查找
5. ⚠️ **营销活动**：秒杀和拼团活动需要提前设置好时间

## 📋 订单管理

### 功能说明

处理用户订单，包括订单查询、发货、退款等操作。

### 订单状态说明

| 状态 | 说明 | 操作 |
|------|------|------|
| 待付款 | 用户已下单但未支付 | 可取消订单 |
| 待发货 | 用户已付款，等待发货 | 填写物流信息发货 |
| 待收货 | 已发货，等待用户签收 | 跟踪物流进度 |
| 已签收 | 用户已收货 | 订单完成，可归档 |
| 售后/退款 | 用户申请退款 | 处理退款申请 |

### 小程序端操作流程

#### 1. 查看订单列表

**路径**: 店长后台 > 订单管理

**步骤**:
1. 进入管理后台，点击"订单"菜单
2. 查看订单列表，支持按状态筛选
3. 订单列表显示：
   - 订单号
   - 商品信息
   - 订单金额
   - 订单状态
   - 下单时间

#### 2. 处理待发货订单

**步骤**:
1. 进入"订单管理"，切换到"待发货"Tab
2. 点击订单卡片，查看订单详情
3. 准备商品，打包发货
4. 点击"发货"按钮
5. 填写物流信息：
   - 物流公司（默认：顺丰速运）
   - 运单号（必填）
6. 确认发货后，订单状态变为"待收货"

#### 3. 处理退款申请

**步骤**:
1. 进入"订单管理"，切换到"售后/退款"Tab
2. 查看退款订单详情
3. 核实退款原因和订单信息
4. 确认退款：
   - 点击"确认退款"
   - 系统自动更新订单状态为"已退款"
   - 退款金额原路返回用户账户

#### 4. 订单查询

**功能**:
- 支持按订单号搜索
- 支持按商品名称搜索
- 支持按时间范围筛选

### Web端操作流程

**路径**: 全渠道订单

**操作说明**:
- 表格形式展示所有订单
- 支持批量导出订单数据
- 支持批量发货（需逐个填写物流信息）
- 财务数据汇总展示

### 注意事项

1. ⚠️ **发货时效**：订单付款后24小时内发货
2. ⚠️ **物流单号**：确保运单号准确无误
3. ⚠️ **退款审核**：核实退款原因后再确认退款
4. ⚠️ **异常订单**：及时处理异常订单，避免用户投诉
5. ⚠️ **库存扣减**：发货时系统自动扣减库存

## 🎫 预约管理

### 功能说明

管理用户预约（入店参观、手作课程、特别活动）的审核和核销。

### 预约类型

| 类型 | 说明 | 处理方式 |
|------|------|----------|
| 入店参观 | 免费预约参观 | 到店核销 |
| 手作课程 | 付费手作课程 | 到店核销 |
| 特别活动 | 付费特别活动 | 到店核销 |

### 小程序端操作流程

#### 1. 查看待核销预约

**路径**: 店长后台 > 核销验票

**步骤**:
1. 进入管理后台，点击"核销"菜单
2. 查看待核销预约列表
3. 显示信息：
   - 预约人姓名
   - 预约日期和时间
   - 预约人数
   - 预约类型

#### 2. 核销预约

**方式一：扫码核销**
1. 用户出示预约二维码
2. 点击"扫码核销"按钮
3. 扫描用户二维码
4. 系统自动识别并核销

**方式二：手动核销**
1. 在待核销列表中找到对应预约
2. 点击预约卡片
3. 查看预约详情
4. 点击"核销"按钮
5. 确认核销后，预约状态变为"已使用"

#### 3. 预约审核

**步骤**:
1. 查看新提交的预约申请
2. 核实预约信息（日期、时间、人数）
3. 确认可接待后，点击"确认"
4. 预约状态变为"已确认"

#### 4. 取消预约

**步骤**:
1. 用户申请取消预约
2. 查看取消原因
3. 确认取消后，预约状态更新
4. 如已付款，需处理退款

### 注意事项

1. ⚠️ **核销时效**：预约当天及时核销
2. ⚠️ **预约限制**：控制每日预约数量，避免超载
3. ⚠️ **临时变更**：如有变更，及时通知用户
4. ⚠️ **退款处理**：取消付费预约需及时退款

## 📝 内容管理

### 功能说明

管理社区内容，包括知识文章、视频内容、专题策展。

### 内容类型

| 类型 | 数据集合 | 用途 |
|------|---------|------|
| 知识文章 | articles | 科普文章、知识分享 |
| 视频内容 | articles (videoUrl字段) | 视频内容 |
| 专题策展 | cms_wikis | 主题展览、策展内容 |

### 小程序端操作流程

#### 1. 进入内容管理

**路径**: 店长后台 > 内容管理

**步骤**:
1. 点击"内容"菜单
2. 选择内容类型：
   - **专题策展**：管理展览内容
   - **知识文章**：管理文章和视频

#### 2. 发布知识文章

**步骤**:
1. 点击"新增"按钮
2. 填写文章信息：
   - **标题**：必填
   - **分类**：标本知识/艺术鉴赏/制作工艺/藏品故事
   - **作者**：必填
   - **封面图**：上传文章封面
   - **摘要**：简短介绍
   - **内容**：富文本内容（支持HTML）
   - **标签**：用逗号分隔
   - **视频链接**（可选）：如文章包含视频

3. 编辑富文本内容：
   - 支持文本、图片、视频
   - 支持HTML格式
   - 建议使用专业的富文本编辑器编辑后复制

4. 点击"保存"发布文章

#### 3. 发布视频内容

**步骤**:
1. 选择"知识文章"类型
2. 填写视频信息（同上）
3. 必填"视频链接"字段
4. 上传视频封面图
5. 保存后自动归类为视频内容

#### 4. 发布专题策展

**步骤**:
1. 切换到"专题策展"Tab
2. 点击"新增"按钮
3. 填写专题信息：
   - **标题**：必填
   - **副标/拉丁**：可选
   - **封面图**：必填
   - **导语/摘要**：简短介绍
   - **内容**：富文本内容
   - **标签**：用逗号分隔

4. 保存发布

#### 5. 编辑/删除内容

**步骤**:
1. 在内容列表中找到要编辑的内容
2. 点击内容卡片进入编辑
3. 修改后保存
4. 删除内容：点击删除按钮，确认删除

### Web端操作流程

**路径**: 运营配置 > 内容管理

**操作说明**:
- 功能与小程序端一致
- 支持批量编辑
- 表格形式展示，便于管理
- 支持内容状态筛选（已发布/草稿）

### UGC内容管理

**用户发布内容**:
- 用户在社区页面发布的文章/视频会标记"UGC"标签
- 管理员可在内容管理中查看所有UGC内容
- 可对不当内容进行删除或下架处理

### 注意事项

1. ⚠️ **内容质量**：确保内容准确、有价值
2. ⚠️ **图片规范**：封面图尺寸建议 800x600px
3. ⚠️ **标签优化**：合理使用标签，便于用户搜索
4. ⚠️ **发布时机**：选择合适时间发布，提高曝光
5. ⚠️ **UGC审核**：及时审核用户发布内容，确保内容合规

## 🎁 营销工具

### 功能说明

管理营销活动，包括优惠券、拼团、限时秒杀。

### 1. 优惠券管理

#### 优惠券类型

| 类型 | 说明 | 使用场景 |
|------|------|----------|
| 满减券 | 满X元减Y元 | 促进消费 |
| 折扣券 | X折优惠 | 清仓促销 |
| 免邮券 | 免运费 | 提高客单价 |
| 新人券 | 新用户专享 | 拉新 |

#### 创建优惠券

**路径**: 店长后台 > 权益会员 > 新增权益（选择优惠券类型）

**步骤**:
1. 进入权益管理
2. 点击"新增权益"
3. 选择"优惠券"类型
4. 填写优惠券信息：
   - **优惠券名称**：如"满100减20"
   - **优惠类型**：满减/折扣/免邮
   - **优惠金额/折扣**：根据类型填写
   - **使用门槛**：最低消费金额
   - **有效期**：开始和结束时间
   - **发放数量**：限制领取数量
   - **限领规则**：每人限领数量

5. 设置发放方式：
   - **自动发放**：满足条件自动发放
   - **手动发放**：管理员手动发放
   - **分享领取**：用户分享后领取

6. 保存后优惠券生效

#### 优惠券使用

**用户端**:
- 用户在"我的-优惠券"查看可用优惠券
- 购物车结算时自动匹配最优优惠券
- 支持优惠券转赠好友

**管理端**:
- 查看优惠券使用情况
- 统计优惠券核销数据
- 管理优惠券状态（启用/停用）

### 2. 拼团管理

#### 设置拼团商品

**步骤**:
1. 在商品管理中找到要设置拼团的商品
2. 编辑商品，开启"拼团"开关
3. 设置拼团信息：
   - **拼团价格**：低于原价
   - **成团人数**：如2人、3人
   - **拼团有效期**：24小时/48小时等

4. 保存后商品显示拼团标识

#### 拼团流程

1. 用户发起拼团
2. 分享拼团链接邀请好友
3. 好友加入拼团
4. 达到成团人数后，订单生效
5. 未成团则自动退款

#### 管理拼团

- 查看拼团订单
- 监控拼团进度
- 处理拼团异常

### 3. 限时秒杀管理

#### 设置秒杀商品

**步骤**:
1. 在商品管理中找到要设置秒杀的商品
2. 编辑商品，开启"限时秒杀"开关
3. 设置秒杀信息：
   - **秒杀价格**：低于原价
   - **秒杀库存**：限量数量
   - **开始时间**：精确到分钟
   - **结束时间**：精确到分钟
   - **限购数量**：每人限购数量

4. 保存后商品在指定时间显示秒杀标识

#### 秒杀流程

1. 活动开始前，商品显示倒计时
2. 活动开始后，用户可抢购
3. 库存售罄后，恢复原价
4. 活动结束后，秒杀价格失效

#### 管理秒杀

- 提前设置好秒杀活动
- 监控秒杀库存
- 处理秒杀异常订单

### 注意事项

1. ⚠️ **活动时间**：提前设置，避免时间冲突
2. ⚠️ **库存管理**：确保活动库存充足
3. ⚠️ **价格设置**：合理设置优惠力度
4. ⚠️ **用户通知**：重要活动提前通知用户
5. ⚠️ **活动监控**：实时监控活动数据

## 👑 权益会员管理

### 功能说明

管理积分商品、会员权益等。

### 1. 积分商品管理

#### 创建积分商品

**路径**: 店长后台 > 权益会员 > 新增权益

**步骤**:
1. 点击"新增权益"
2. 选择"积分商品"类型
3. 填写商品信息：
   - **商品名称**：必填
   - **所需积分**：兑换所需积分
   - **库存数量**：可兑换数量
   - **商品图片**：上传商品图片
   - **商品描述**：详细描述

4. 保存后商品在积分中心展示

#### 积分规则

- 用户签到获得积分
- 购买商品获得积分
- 评价商品获得积分
- 分享内容获得积分

#### 积分兑换

**流程**:
1. 用户在积分中心选择商品
2. 确认兑换
3. 系统扣减积分
4. 生成兑换订单

## ❓ 常见问题处理

### 1. 订单相关问题

**Q: 用户下单后未付款，如何处理？**
- A: 待付款订单24小时后自动取消，也可手动取消订单。

**Q: 发货后发现地址错误怎么办？**
- A: 联系物流公司修改地址，或联系用户重新下单。

**Q: 用户申请退款，如何处理？**
- A: 核实退款原因，确认无误后点击"确认退款"，系统自动退款。

### 2. 库存相关问题

**Q: 库存显示为0，但实际有货？**
- A: 在商品管理中更新库存数量。

**Q: 商品库存预警如何设置？**
- A: 系统默认库存低于5件时建议补货，定期盘点确保数据准确。

### 3. 活动相关问题

**Q: 活动报名已满，但有人取消怎么办？**
- A: 在活动管理中修改"剩余人数"，其他用户即可继续报名。

**Q: 活动临时取消怎么办？**
- A: 在活动管理中关闭活动，系统自动通知已报名用户并处理退款。

### 4. 内容相关问题

**Q: 文章发布后无法在前端看到？**
- A: 检查文章状态是否为"已发布"，并确认分类设置正确。

**Q: 视频无法播放？**
- A: 检查视频链接是否正确，建议使用微信支持的视频格式。

### 5. 系统问题

**Q: 无法登录管理后台？**
- A: 检查密码是否正确，联系超级管理员重置密码。

**Q: 数据加载缓慢？**
- A: 检查网络连接，或刷新页面重试。

## 🚨 应急预案

### 1. 订单异常

**情况**：大量订单异常
**处理**：
1. 立即停止相关商品销售
2. 检查系统日志找出原因
3. 联系技术支持
4. 通知受影响用户

### 2. 库存异常

**情况**：库存数据异常
**处理**：
1. 暂停相关商品销售
2. 盘点实物库存
3. 手动修正库存数据
4. 恢复商品销售

### 3. 活动异常

**情况**：活动报名异常
**处理**：
1. 暂停活动报名
2. 检查活动设置
3. 修正后重新开放
4. 通知已报名用户

### 4. 系统故障

**情况**：系统无法访问
**处理**：
1. 记录故障时间
2. 联系技术支持
3. 通知相关人员
4. 等待系统恢复
