# 首页优化测试指南

## 📋 测试前准备

### 1. 部署云函数

在微信开发者工具中：

1. **部署 getRecommendations**
   - 右键点击 `cloudfunctions/getRecommendations` 文件夹
   - 选择"上传并部署：云端安装依赖"
   - 等待部署完成

2. **部署 trackUserBehavior**
   - 右键点击 `cloudfunctions/trackUserBehavior` 文件夹
   - 选择"上传并部署：云端安装依赖"
   - 等待部署完成

### 2. 创建数据库集合

在云开发控制台：

1. 进入"数据库" → "集合管理"
2. 创建新集合：`user_behaviors`
3. 设置权限：
   - 所有用户可读：否
   - 仅创建者可读写：是（或根据需求设置）

### 3. 检查数据库权限

确保以下集合的权限正确：
- `products` - 所有用户可读
- `banners` - 所有用户可读
- `framers` - 所有用户可读
- `activities` - 所有用户可读
- `cms_wikis` 或 `curated_collections` - 所有用户可读

## 🧪 测试步骤

### 测试1: 缓存功能测试

**目标**：验证数据缓存是否正常工作

**步骤**：
1. 清除小程序缓存（设置 → 清除缓存）
2. 打开首页，观察加载时间
3. 关闭小程序，重新打开首页
4. 观察第二次打开是否更快（应该从缓存加载）

**预期结果**：
- 首次加载：正常加载时间（1-2秒）
- 第二次加载：明显更快（< 0.5秒）
- 控制台应该看到缓存相关的日志

**验证方法**：
```javascript
// 在控制台执行
const { getCache } = require('./utils/cache');
console.log('BANNERS缓存:', getCache('BANNERS'));
console.log('COLLECTIONS缓存:', getCache('COLLECTIONS'));
```

---

### 测试2: 推荐模块显示测试

**目标**：验证推荐模块是否正确显示

**步骤**：
1. 打开首页
2. 滚动到"为你推荐"模块
3. 观察推荐卡片是否显示

**预期结果**：
- 推荐模块显示在"最新入库"之前
- 显示推荐卡片（至少1个）
- 每个卡片显示：图片、标题、价格、推荐理由
- 支持横向滚动

**可能的问题**：
- 如果推荐模块不显示：
  - 检查云函数是否部署成功
  - 检查控制台是否有错误
  - 确认 `products` 集合有数据

---

### 测试3: 用户行为追踪测试

**目标**：验证用户行为是否正确记录

**步骤**：
1. 打开首页
2. 点击任意商品卡片，进入详情页
3. 返回首页
4. 在云开发控制台查看 `user_behaviors` 集合

**预期结果**：
- `user_behaviors` 集合中新增一条记录
- 记录包含：`userId`, `action: 'view'`, `targetType: 'product'`, `targetId`
- `timestamp` 字段有值

**验证方法**：
```javascript
// 在云开发控制台执行
db.collection('user_behaviors')
  .orderBy('timestamp', 'desc')
  .limit(10)
  .get()
  .then(res => console.log('最近的行为记录:', res.data))
```

---

### 测试4: 推荐算法测试

**目标**：验证推荐算法是否基于用户行为

**步骤**：
1. 清除 `user_behaviors` 集合的数据（测试用）
2. 浏览几个商品（昆虫类）
3. 收藏1-2个商品
4. 返回首页，查看推荐内容
5. 刷新首页，再次查看推荐

**预期结果**：
- 首次访问：显示"热门推荐"
- 浏览后：推荐内容可能包含昆虫类商品
- 推荐理由显示："因为你浏览过类似内容" 或 "基于你的收藏偏好"

**验证方法**：
- 查看推荐卡片的推荐理由标签
- 检查推荐的商品是否与浏览/收藏的商品相关

---

### 测试5: 下拉刷新测试

**目标**：验证下拉刷新是否清除缓存并重新加载

**步骤**：
1. 打开首页（此时数据已缓存）
2. 下拉刷新
3. 观察数据是否更新
4. 检查缓存是否被清除

**预期结果**：
- 下拉刷新后，所有数据重新加载
- 缓存被清除
- 推荐内容可能更新

---

### 测试6: 错误处理测试

**目标**：验证错误处理和重试机制

**步骤**：
1. 临时禁用网络（开发者工具 → 网络 → 离线）
2. 打开首页
3. 观察是否显示错误提示或使用缓存数据
4. 恢复网络
5. 观察是否自动重试

**预期结果**：
- 网络错误时，使用缓存数据（如果有）
- 网络恢复后，自动重试加载
- 不会出现白屏或崩溃

---

### 测试7: 性能测试

**目标**：验证性能优化效果

**步骤**：
1. 使用微信开发者工具的"性能"面板
2. 记录首次加载时间
3. 记录缓存加载时间
4. 记录推荐模块加载时间

**预期指标**：
- 首屏渲染时间：< 1.5s
- 缓存加载时间：< 0.5s
- 推荐加载时间：< 2s
- 内存占用：< 100MB

---

## 🐛 常见问题排查

### 问题1: 推荐模块不显示

**可能原因**：
- 云函数未部署
- 数据库权限问题
- `products` 集合为空

**解决方法**：
1. 检查云函数部署状态
2. 检查数据库权限
3. 确认 `products` 集合有数据
4. 查看控制台错误信息

---

### 问题2: 缓存不生效

**可能原因**：
- 缓存工具未正确引入
- 存储空间不足
- 缓存被清除

**解决方法**：
1. 检查 `utils/cache.js` 是否正确引入
2. 检查存储空间
3. 在控制台验证缓存是否存在

---

### 问题3: 用户行为未记录

**可能原因**：
- 云函数未部署
- `user_behaviors` 集合未创建
- 权限问题
- `openid` 未获取

**解决方法**：
1. 确认云函数已部署
2. 确认集合已创建
3. 检查集合权限
4. 确认 `app.globalData.openid` 有值

---

### 问题4: 推荐内容重复

**可能原因**：
- 推荐算法去重逻辑问题
- 数据源问题

**解决方法**：
1. 检查推荐算法中的去重逻辑
2. 确认 `products` 集合数据质量

---

## 🔍 调试技巧

### 1. 查看控制台日志

在微信开发者工具中：
- 打开"调试器" → "Console"
- 查看缓存、推荐、行为追踪相关的日志

### 2. 查看云函数日志

在云开发控制台：
- 进入"云函数" → 选择函数 → "日志"
- 查看函数执行日志和错误信息

### 3. 查看数据库数据

在云开发控制台：
- 进入"数据库" → 选择集合
- 查看数据是否正确存储

### 4. 使用调试工具

```javascript
// 在页面中临时添加调试代码
console.log('当前缓存:', {
  banners: getCache('BANNERS'),
  collections: getCache('COLLECTIONS'),
  newArrivals: getCache('NEW_ARRIVALS')

console.log('用户OpenID:', app.globalData.openid);
```
