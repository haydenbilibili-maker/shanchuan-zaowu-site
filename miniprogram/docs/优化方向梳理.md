# 山海造物小程序 - 优化方向梳理

> 基于产品功能现状、PRD 与已知问题整理的优化方向，供排期与迭代参考。  
> 优先级：P0 高优 | P1 中优 | P2 一般 | 持续 长期建设

---

## 一、结构与路径（短期优先）

| 方向 | 优先级 | 说明 |
|------|--------|------|
| 统一百科详情路径 | P0 | 只保留一个 wiki-detail 路径，去除 detail/detail/wiki-detail 重复，更新所有跳转与 app.json |
| 统一成就/证书入口 | P0 | 明确 user/achievements 与 user/user/achievements、主包与分包 certificate 的职责，合并或区分后更新文档与路由 |
| 核对 app.json 与目录 | P1 | 确保 pages、subpackages、tabBar 与当前目录一致，并在《项目概览与开发计划》中同步 |

---

## 二、样式与体验（短期）

| 方向 | 优先级 | 说明 |
|------|--------|------|
| 样式规范与隔离 | P0 | 按《BUG复盘-样式文件重写问题》落实：避免全局样式污染、组件样式隔离、关键改动前检查影响范围 |
| 图标统一 | P1 | 按《icon优化清单》完成图标替换与命名统一，风格一致 |
| 首屏与骨架屏 | P1 | 首屏渲染时间目标 < 1.5s，骨架屏覆盖主要模块，懒加载/预加载策略 |
| 下拉刷新与空状态 | P1 | 关键列表页统一下拉刷新与空状态文案、插图 |

---

## 三、首页与推荐（中期）

| 方向 | 优先级 | 说明 |
|------|--------|------|
| 智能推荐完善 | P0 | 「为你推荐」模块的刷新策略、不感兴趣/收藏反馈、推荐理由展示与 getRecommendations 对齐 |
| 首页 A/B 与定时发布 | P1 | 模块级 A/B 测试、定时发布与版本管理（见 PRD 二期首页动态化） |
| 首页性能指标 | P1 | 白屏 < 0.8s、可交互 < 2.0s，关键资源预加载与 CDN/缓存 |

---

## 四、预约（中期）

| 方向 | 优先级 | 说明 |
|------|--------|------|
| 预约提醒全链路 | P0 | 预约成功/前 1 天/前 2 小时/改期/取消提醒，与站内信、模板消息打通，sendBookingReminder 规则可配置 |
| 预约改期与取消规则 | P0 | 支持用户改期、提前 X 小时免费取消等，规则与前端展示一致 |
| 候补能力 | P1 | 满员时可选加入候补，addToWaitlist 与通知流程打通 |
| 时间段动态与冲突检测 | P1 | 按日期动态加载时间段、实时可用性及冲突检测 |
| 日历增强 | P2 | 多月视图、节假日/闭馆日/活动日标记 |

---

## 五、收藏与内容（中期）

| 方向 | 优先级 | 说明 |
|------|--------|------|
| 收藏夹分享 | P1 | 分享整个收藏夹、生成链接或小程序码、分享到微信 |
| 收藏夹排序与封面 | P2 | 拖拽排序、按时间/名称排序、自定义或自动封面 |
| 收藏提醒 | P2 | 降价、补货、活动提醒（依赖消息与配置） |
| UGC 与社区内容 | P1 | 用户发文章/视频的审核、推荐与展示与 PRD 对齐 |
| 评论与评价 | P1 | 评价表单（星级+图文）、评价列表筛选与互动，与积分/风控结合 |

---

## 六、订单与营销（中期）

| 方向 | 优先级 | 说明 |
|------|--------|------|
| 优惠券组合与提醒 | P1 | 多张券叠加规则、即将到期提醒、使用率分析（PRD 三期优惠券升级） |
| 会员运营增强 | P1 | 生日礼遇、会员专享活动、成长路径可视化、权益到期提醒、推荐有奖（PRD 三期） |
| 支付与售后体验 | P0 | 支付结果页、退款进度、售后入口统一，错误提示与降级 |
| 订单与关键操作监控 | P1 | 下单/支付/预约等关键节点配合 logError 或扩展日志，便于告警与排查 |

---

## 七、用户与消息（中期）

| 方向 | 优先级 | 说明 |
|------|--------|------|
| 站内信分类与触达 | P1 | 预约/订单/活动/系统分类完善，与后台通知配置、模板消息互补 |

---

## 八、搜索与发现（中期）

| 方向 | 优先级 | 说明 |
|------|--------|------|
| 搜索联想与纠错 | P1 | 联想准确率、纠错与同义词、热门与个性化排序 |
| 搜索结果排序与筛选 | P1 | 综合/销量/价格等排序，分类与标签筛选 |
| 搜索分析 | P2 | 关键词统计、无结果词反馈，支撑运营与推荐 |

## 九、架构与质量（持续）

| 方向 | 优先级 | 说明 |
|------|--------|------|
| 请求与登录态封装 | 持续 | 公共请求封装、登录态校验、统一错误处理，减少页面重复代码 |
| 组件化 | 持续 | 列表、表单、空状态、弹窗等抽象为组件，UI 与交互统一 |
| 命名与规范 | 持续 | 页面/组件/云函数/样式类名规范，文档与代码一致 |
| 核心链路测试 | 持续 | 登录、下单、预约、支付等关键路径的自动化或核心用例，避免回归 |
| 云函数文档与校验 | 持续 | 每个云函数简短说明（用途、入参、权限），入参校验与错误码规范 |

---

## 十、三期规划方向（参考 PRD_三期规划）

- **智能营销**：用户分群、精准推送、流失召回、A/B 测试、会员生日与专享、优惠券引擎。  
- **内容生态**：UGC 社区、审核与推荐、标签与排行榜、知识体系。  
- **体验与商业**：个性化服务、营销工具升级、数据分析深化、性能与安全。

---

## 十一、排期建议（汇总）

1. **短期（1–2 周）**：路径与成就/证书统一、样式规范与图标、app.json 与文档同步。  
2. **中期（按 PRD 排期）**：推荐完善、预约提醒与规则、收藏夹分享、优惠券与会员、站内信与数据可视化、搜索与 UGC。  
3. **长期（持续）**：架构抽象、组件化、规范与测试、云函数文档与监控。
