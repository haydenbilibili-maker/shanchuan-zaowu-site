## 📊 数据流程

### 搜索联想流程

```
用户输入 → 触发onInput → getSuggestions()
  ↓
匹配历史记录（3条）
  ↓
匹配热门搜索（2条）
  ↓
查询数据库商品标题（3条）
  ↓
合并去重 → 显示建议（最多5条）
```

### 搜索历史流程

```

  ↓

  ↓

  ↓
点击历史 → 自动搜索
```

## 🔧 代码实现

### 搜索联想

```javascript
// 获取搜索建议
async getSuggestions(keyword) {
  // 1. 从历史记录匹配
  const historyMatches = this.data.historyList
    .filter(h => h.toLowerCase().includes(keyword.toLowerCase()))
    .slice(0, 3);

  // 2. 从热门搜索匹配
  const hotMatches = this.data.hotKeys
    .filter(h => h.toLowerCase().includes(keyword.toLowerCase()))
    .slice(0, 2);

  // 3. 从数据库查询
  const dbMatches = await db.collection('products')
    .where({ title: dbReg, isOffShelf: false })
    .limit(5)
    .get();

  // 4. 合并去重
  const allSuggestions = [...new Set([...historyMatches, ...hotMatches, ...dbMatches])];
  
  this.setData({ 
    suggestions: allSuggestions.slice(0, 5),
    showSuggestions: allSuggestions.length > 0
  });
}
```

### 建议选择

// 选择建议
selectSuggestion(e) {
