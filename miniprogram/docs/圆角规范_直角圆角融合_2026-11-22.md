## 二、融合原则：**容器与控件圆，物件方，线条细**

直角不废除，而是收进「物件」这一层：有实物隐喻的东西（纸、票、券、印、牌）保持锐利边角，这是博物馆质感的来源。其余可交互、可承载内容的东西统一圆角。

| 层 | 元素 | 圆角 | 令牌（新增语义令牌，值落在现有刻度上） |
|----|------|------|------|
| 物件 | 证书、票根 / 入馆券、礼券券面、铭牌、印章 / 方印、纸签、门店名片、礼笺 | 2–4rpx（保持） | `--r-object: 4rpx` |
| 线条 | 分隔线、进度条、指示线、骨架线、齿孔 | 保持现状（2rpx / 胶囊） | — |
| 标签 | 筛选 chip、状态标签、分类签、数字角标 | 胶囊 | `--r-pill: 999rpx` |
| 控件 | 主 / 次按钮、输入框 | 16rpx | `--r-control: 16rpx` |
| 控件 | 搜索框、小按钮（导航前往、清空） | 胶囊 | `--r-pill` |
| 图片 | 缩略图 ≥120rpx | 16rpx | `--r-thumb: 16rpx` |
| 图片 | 小图标图 <120rpx | 8rpx | `--r-thumb-sm: 8rpx` |
| 图片 | 头像 | 圆 | 50% |
| 容器 | 内容卡、列表组、面板、地图框、空态框 | 16rpx | `--r-card: 16rpx` |
| 容器 | 主视觉大卡、资产卡（钱包 / 积分 / 会员卡） | 24rpx | `--r-hero: 24rpx` |
| 浮层 | 弹窗 / 底部抽屉 | 24 / 32rpx（现有 pop 令牌，不变） | `--pop-radius-*` |

**不动的部分**：
- 钱包皮质卡、积分黑金卡、礼券券面的质感规则（R16-1 指纹锁定）；
- 证书、入馆券、礼笺等物件；
- 所有线条类元素。

## 四、全量落地计划（确认方向后执行）

1. `app.wxss` 增加上表语义令牌（值等于现有刻度，现有页面零变化）。
2. 按页面逐个改（不做跨文件 find-replace；每处按「角色」判断）：
   - 第一批：C 端主链路直角页（搜索、门店、预约非票卡部分、客服、标本师 5 页、定制）；
   - 第二批：员工 / 商家端（供应商、B2B、投资人、股东、审批、工作台）。
3. 新守卫 `check:radius-roles`：
   - 卡片 / 标签 / 按钮 / 输入类选择器出现 ≤4rpx 圆角即报错；
   - 物件白名单（cert / ticket / coupon / seal / plate / stamp / namecard …）与线条类豁免；
   - 直角总数只许减不许增（棘轮）。
4. 每批出图核对，真机抽查。
5. **稳定期报备**：电商 / 礼赠页面只改圆角展示值，不动结构与逻辑。
