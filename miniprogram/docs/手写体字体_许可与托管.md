## 字体
- **名称**：Ma Shan Zheng（马善政毛笔楷书）
- **来源**：Google Fonts（`google/fonts` 仓库 `ofl/mashanzheng/`）
- **许可**：**SIL Open Font License 1.1（OFL-1.1）→ 允许商用、允许嵌入/裁剪/再分发**
  - 版权声明（原样保留）：`Copyright 2018 The Ma Shan Zheng Project Authors (https://github.com/googlefonts/mashanzheng)`
  - OFL 要求：再分发（含裁剪版）时**必须保留版权与许可声明**，且**不得单独售卖字体本身**。
- **裁剪**：`pyftsubset` 到 GB2312 全集 + ASCII + 标点（7532 字，覆盖日常 ~99.9%）→ WOFF2 **3.08 MB**

## ⚠️ 上线前必做（真机生效的关键）
**把字体域名加入 downloadFile 合法域名**：小程序后台 → 开发管理 → 开发设置 → 服务器域名 →
`downloadFile 合法域名` 添加：
```
https://636c-cloud1-8gnkty5bfff9f0bf-1387508856.tcb.qcloud.la
```
（实测该 URL 公开可读：HTTP 200 + `content-type: font/woff2`；但**真机上 `loadFontFace` 仍要求域名在白名单内**。）
开发/体验版可先在开发者工具勾「不校验合法域名」快速验证。

## 加载（`utils/handFont.js`）
- 首选 `wx.cloud.downloadFile` → 本地临时文件 → `wx.loadFontFace`：
  **cloud API 不受 downloadFile 合法域名限制**，故默认路径无需改小程序后台；
- 兜底静态 https：该路径需要把 `636c-cloud1-8gnkty5bfff9f0bf-1387508856.tcb.qcloud.la`
  加入 **downloadFile 合法域名**；
- 关键参数：`global: true` + `scopes: ['webview','native']`
  —— 缺 `native` 时 iOS 的 `<text>` 不会用上该字体（这正是此前"怎么改都没效果"的原因）。
- **`wx.loadFontFace` 的 source 只接受网络 URL**：传 `wxfile://` 本地路径（如 `wx.cloud.downloadFile`
  得到的 `tempFilePath`）**不生效** ✗ —— 2026-09-19 真机事故即因此（且当时失败后没有再试 https ✗）；
  现改为多源链：**https 优先** → 云探测 → 1.5s 整体重试，并在失败日志里直接给出上面的白名单提示。
- 用法：WXSS 里 `font-family: 'ShanhaiHand', <系统字体兜底>;`（加载失败自动落系统字体，不报错）。

## 为什么要走网络字体（2026-09-19 结论）
iOS 真机上系统字体栈 `"HanziPen SC" / "Hannotate SC" / "STKaiti" / "Kaiti SC"` **全部取不到**
（祈福墙与礼赠卡同时失灵 → 证明是平台限制而非写法问题）→ 必须 `loadFontFace` 加载网络字体。
