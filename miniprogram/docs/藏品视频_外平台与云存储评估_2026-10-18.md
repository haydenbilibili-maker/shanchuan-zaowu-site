# 藏品实拍视频 · 外平台链接与云存储上传评估（2026-10-18）

> **产品负责人点名**：「产品详情页添加视频模块，用于展示实拍的标本视频，视频支持填写视频平台地址如 bilibili，也需要评估微信是否允许小程序展示外平台链接。或者评估本地服务器上传视频文件的方案，但需要评估速度，效率与成本。并对藏品库相关模块做对应修改。」
> 承接：`藏品视频与实况_2026-09-28.md`。云存储视频（`products.media`）那时已落地，店长端可以上传，详情页顶部主图轮播可以播放；**缺的是 ERP 藏品档案库的录入入口，以及外平台视频**。本轮补齐这两块。

## 1. 结论速览

| 方案 | 能否在小程序内播放 | 结论 |
|---|---|---|
| **云存储直传**（CloudBase，`media` 字段） | ✅ 原生 `<video>`，静音、不自动播放 | **主力方案**。已在用，本轮补上 ERP 上传入口 |
| **微信视频号**（`channel-video`） | ✅ 可内嵌：同主体直接嵌；非同主体需 `feedToken`，且不能自动播放 | **推荐的外平台**。本轮支持 |
| **哔哩哔哩 / 抖音 / 小红书** | ❌ 不能内嵌，也不建议跳对方小程序 | 只做**卡片 + 复制链接**。本轮支持，作为补充 |
| 自建服务器 / 云点播转码 | ✅ | 现阶段不必要（见 §4.4） |

## 2. 微信是否允许小程序展示外平台视频（B站等）

1. **内嵌网页（`web-view`）不可行。**
   - `web-view` 只能打开两类链接：小程序关联公众号的文章，以及后台配置的「业务域名」。
   - 业务域名要求在**域名根目录放校验文件**，只有自己控制的域名才做得到。`bilibili.com` / `b23.tv` 不是我们的域名，无法配置。
   - 个人主体的小程序完全不能使用 `web-view`。
   - 来源：[阿里云开发者社区：webview 加载域名的限制](https://developer.aliyun.com/article/1338687)、[阿里云：在微信小程序中接入 Web SDK（要求非个人主体 + 备案域名）](https://help.aliyun.com/zh/ims/user-guide/how-to-access-h5-sdk-in-wechat-applet)。
2. **跳转到 B站小程序（`wx.navigateToMiniProgram`）不采用。**
   - API 本身允许跳转，但从基础库 2.3.0 起必须由用户点击触发（[官方文档](https://developers.weixin.qq.com/miniprogram/en/dev/api/navigate/wx.navigateToMiniProgram.html)）。
   - B站小程序的 AppID 和视频页路径**没有官方公开文档**，第三方帖子里的值无法核实，对方一改版就会失效。
   - 跳出去就离开了我们的购买链路，转化会受损。
3. **视听内容规则。**
   - 腾讯在 2018 年曾要求，外链在没有《信息网络传播视听节目许可证》的情况下不得传播视听节目内容，随后又删除了这一条（[界面新闻](https://m.jiemian.com/article/2157579.html)）。
   - 监管对象主要是提供视听节目服务的平台。商品实拍展示视频一般不属于「节目」，但**不是法律意见**：如果以后要做长视频、课程或直播回放，应先咨询。
4. **本轮做法**：详情页「实拍影像」区块给 B站 / 抖音 / 小红书显示一张卡片（平台名、标题、B站 BV 号），轻点复制链接，提示「可在哔哩哔哩打开」。**不内嵌，也不跳转。**

## 3. 视频号：小程序里唯一能内嵌的「外平台」

- 来源：[微信开放文档：小程序打开视频号视频](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/channels-activity.html)、[视频号主页](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/channels-profile.html)、[开发者社区：channel-video 内嵌问题](https://developers.weixin.qq.com/community/develop/doc/0000aecfe30868f9473134b6d6b800)、[书栈网转载的 channel-video 文档（2025-04 版）](https://www.bookstack.cn/read/miniprogram-202505/5bc4daa6ce102a4b.md)。
- **内嵌 `<channel-video>`**：
  - 基础库 2.31.1 之前，只能嵌入**同主体或关联主体**的视频号视频。
  - 从 2.31.1 起，**非个人主体**的小程序也可以嵌入非同主体的视频，但必须带 `feed-token`，而且**不能自动播放**。本项目基础库 3.11.2，满足要求。
- **跳转 `wx.openChannelsActivity`**：没有主体限制，但需要真机调试。
- **本轮做法**：
  - 视频号条目存 `finderUserName`（sph 开头的视频号 ID）、`feedId`、`feedToken`（选填）、`sameSubject`（是否同主体）。
  - 同主体，或者带了 token 的，**内嵌播放**；否则显示跳转卡片，轻点打开视频号观看。
  - 内嵌报错时就地降级成卡片，**不会自动把顾客带离详情页**。
- **需要产品负责人确认**：
  - 门店是否已开视频号，是否与小程序同主体（AppID `wxf2550373b010b447`）？
  - 不同主体时，`feedToken` 要在视频号助手里按视频逐条获取。

## 4. 云存储上传（「本地服务器上传」）：速度、效率、成本

### 4.1 现状

- 存储：CloudBase 云存储（`cloud://…/products/`）。
- 上传入口：店长端（小程序）在 2026-09-28 已支持；ERP 藏品档案库本轮补上（§5）。
- 播放：详情页顶部主图轮播，第 1 张仍是封面图，视频排在它后面；静音、**不自动播放**、只先加载封面帧。

### 4.2 速度

- **首屏：零影响。** 视频不自动播放，首屏只加载封面帧图片。顾客左滑到视频、并且点了播放，才开始拉流。
- **起播速度主要由两件事决定**：
  - **码率**：建议 720p、H.264、≤ 2.5Mbps。按 4G 实测常见的 10–30Mbps 下行估算，1–2 秒内可起播。
  - **moov 前置（faststart）**：手机直出的 `.mov` / 部分 `.mp4` 把索引放在文件末尾，播放器要先下载整个文件才能起播。剪映、Premiere、HandBrake 导出时勾选「网络优化 / Fast Start」就能解决。
- **ERP 本轮加的防护**：
  - 码率超过 4Mbps 会**提示**「建议导出 720p / 2.5Mbps 后再传」，但不拦截。
  - 超过 60 秒或 50MB **直接拒收**。
  - 浏览器端无法检测 faststart，这条写进了上传提示。

### 4.3 成本估算（**单价未核实**，以腾讯云控制台为准）

- 容器无法访问腾讯云官方价格页。搜到的参考价：
  - CloudBase 官方英文定价摘录：CDN 回源 ¥0.15/GB、外网出流量 ¥0.8/GB（[docs.cloudbase.net/en/pricing](https://docs.cloudbase.net/en/pricing)）。
  - 行业 CDN 下行价约 ¥0.18–0.24/GB（[阿里云 CDN 计费汇总](https://developer.aliyun.com/article/1715952)）。
- 下面用 **¥0.2/GB（走 CDN）** 与 **¥0.8/GB（按外网出流量）** 两档估上下限。

| 假设 | 数值 |
|---|---|
| 单段视频 | 30 秒 × 2.5Mbps ≈ **9.4MB** |
| 每天详情页浏览 | 1,000 次 |
| 点开播放的比例 | 20%（不自动播放，只有感兴趣才点） |
| 每天流量 | 200 × 9.4MB ≈ **1.9GB** → 每月 ≈ **56GB** |
| **每月流量费** | ¥0.2/GB → **约 ¥11**；¥0.8/GB → **约 ¥45** |
| 存储量 | 200 件藏品 × 2 段 × 10MB ≈ 4GB，存储费可忽略（个位数元 / 月） |

- 结论：在目前的访问量下，**每月几十元以内**。成本对码率最敏感：同样的视频用 8Mbps 原片，流量费约是 2.5Mbps 的 3 倍。所以 ERP 上的码率提示比「省存储」更重要。
- 环境若按套餐计费，套餐内 CDN 流量可能已覆盖这部分。

### 4.4 为什么不上云点播（VOD）或自建服务器

- **云点播**能自动转码、做自适应码率（HLS）、截图，但会多出转码费、点播流量费和一个新的 SDK 依赖。几十件藏品、每段 ≤ 60 秒的规模用不上。等以后有**长视频或课程**时再评估。
- **自建服务器**：要自己做带宽、HTTPS、域名备案，并在小程序后台配置合法域名，运维成本远高于 CloudBase。CloudBase 本身就在小程序的云环境里，`cloud://` 文件 ID 不需要配置域名。

### 4.5 效率（录入）

- **ERP 端**：拖拽上传，带进度条。自动读取时长和尺寸并校验，自动截取第 0.5 秒画面作为封面帧上传。支持转实况、排序、删除。
- **店长端**：手机上传，带压缩与重试，2026-09-28 已有。
- 两端写的是同一个 `media` 字段，互相可见。

## 5. 本轮改动（契约变更 · **单列报备**）

> 电商链路属于稳定期模块。本轮在产品负责人点名范围内，只做**向后兼容的新增字段和新增旁路**，不改购买、规格、价格逻辑。

- **新增可选字段 `products.externalVideos`**：`[{ platform: 'channels'|'bilibili'|'douyin'|'xiaohongshu', title, url, bvid, feedId, finderUserName, feedToken, sameSubject }]`，≤ 3 条。
  - **为什么不并进 `media`**：店长端编辑器只认 `video` / `live`，载入时会把其它类型过滤掉，保存时又把 `media` 写回去，外平台条目会被店长保存一次就洗掉。另开字段后，店长端不送它，`.update()` 合并写不会动它。
- **云函数 `manageProducts`**：
  - `ALLOWED_FIELDS` 加入 `externalVideos`。
  - 新增净化模块 `externalVideos.js`：只收 https 链接和白名单平台域名，仿冒域名、http 链接一律丢弃；能从 B站分享文案里提取链接和 BV 号；视频号的 ID 和 feedId 做格式校验；最多 3 条、自动去重。
  - 入参、出参和 `success` 语义不变。
  - ⚠️ **云函数需要重新部署**，否则新字段会被旧白名单静默丢弃：表现为保存提示成功，但外平台视频不生效。
- **ERP 藏品档案库**（`admin/src/App.vue` 编辑弹窗，轮播图下方新增「实拍视频（media · 外平台）」分区）：
  - 上传视频进 `media`：带进度条；超 60 秒或超 50MB 拒收；码率偏高时提示；自动截取封面帧；支持转实况、排序、删除。
  - 外平台录入进 `externalVideos`：两种方式，「链接」或「视频号」。
  - **保存规则与店长端一致**：只有字段有值、或原本有值后被删光时才送，避免把库里已有的视频清空。
  - `cloud.js` 的 `uploadAdminBinary` 新增一个**可选的** `onProgress` 参数，原有调用不受影响。
- **小程序详情页**：在「藏品参数」上方新增「实拍影像」区块，**只有填了外平台视频才显示**。
  - 视频号：内嵌播放，或显示跳转卡片。
  - B站 / 抖音 / 小红书：卡片，轻点复制链接。
  - 如果顶部主图里还有云存储视频，区块里提示「顶部主图另有 N 段实拍视频，左滑即看」。
  - 主图轮播的逻辑不变（守卫 `check:product-media`）。
- **数据结构文档**：`cloudbase/schema/products.md` 登记了新字段。集合与权限规则都没变（`products` 仍然只能由云函数写入）。
- **守卫**：新增 `check:product-external-videos`，覆盖 A–F 共 13 条断言，配 12 条内存注入自检。

## 6. 待产品负责人确认

1. 小程序主体是否为企业（非个人）？若是个人主体，非同主体的视频号视频无法内嵌，只能显示跳转卡片。
