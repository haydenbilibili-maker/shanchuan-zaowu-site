# 联系专员功能说明

## 功能概述

「联系专员」从单一微信客服按钮升级为独立服务页，与「山海有信」站内信形成互补：**即时对话 + 离线留言 + 常见问题自助**。

## 页面路径

- 入口：`pages/user/index` → 馆藏服务 → **联系专员**
- 服务页：`pages/user/support/index`
- 带上下文跳转：
  - 商详：`?topic=product&productId=&productName=`
  - 订单详情：`?topic=order&orderId=&orderNo=`

## 页面能力

| 模块 | 说明 |
|------|------|
| 咨询类型 | 订单 / 预约 / 藏品 / 鉴定 / 售后 / 其他 |
| 微信专员 | `open-type="contact"`，通过 `session-from` 传递订单/藏品上下文 |
| 消息卡片 | `send-message-title/path` 便于用户发送订单或商品卡片 |
| 电话专线 | 一键拨打门店电话 |
| 山海有信 | 跳转站内信查看留言回执与系统通知 |
| 官方社群 | 弹窗展示社群二维码 |
| 留言工单 | 提交文字留言 → `support_tickets` + 站内信回执 |
| 常见问题 | FAQ 折叠列表 |
| 到店导航 | 点击地址打开地图 |

## 云函数

| 云函数 | 用途 |
|--------|------|
| `getSupportConfig` | 读取 FAQ、营业时间、主题列表（可后台配置 `support_configs`） |
| `submitSupportTicket` | 提交留言工单，并调用 `sendInAppMessage` 发送回执 |
| `sendInAppMessage` | 留言回执写入山海有信 |

## 数据库

- `support_configs`：后台可配置 FAQ、电话、营业时间等（`status: active`）
- `support_tickets`：用户留言工单（`_openid`, `topic`, `message`, `orderId`, `status`）

## 部署

1. 部署 `getSupportConfig`、`submitSupportTicket`
2. 确保 `sendInAppMessage` 已部署（留言回执依赖）
3. 小程序后台配置微信客服（否则「开始对话」不可用，用户仍可使用留言/电话）

## 与山海有信的关系

- **联系专员**：主动咨询入口（即时 + 留言）
- **山海有信**：被动通知与回执（订单、预约、留言确认等）

留言提交后，用户可在「山海有信」收到「留言已收到」系统通知。
