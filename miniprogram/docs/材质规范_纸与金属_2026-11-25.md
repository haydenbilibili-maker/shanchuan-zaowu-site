# 材质规范 · 纸与金属（2026-11-25）

> 产品负责人：「目前小程序设计中有较多与材质质感相关的模块，如会员卡、积分卡、礼笺、山海有信、证书、商品详情中的博物卡片，材质涉及金属、纸质等多种类型，但是全局缺少统一的规范，部分可以使用材质的模块还未使用，样式交互质感等也需要规范和统一。」

## 一、现状（脚本实测）

- 材质已经在约 20 个页面 / 组件里落地，但**每个模块各自调色**，没有一个令牌。
  - 「浅纸标本签」这一种纸在 12 个文件里重复手写为 `linear-gradient(180deg, #F3ECDD, #E8DFCB)`，角度在 168 / 170 / 180deg 之间漂移。
  - 山海有信纸笺另调了一版 `#F5EEDE → #E9DEC6`，与标本签纸接近但不同。
  - 纸上的墨色有 `#2E2618` / `#2A2114` / `#241E14` 三种近似值；朱砂有 `#8E3B2E`，铜别针有 `#B08D57`、`#8A7530` 等写法。
- 全仓裸写的「已有令牌的纸 / 墨 / 印」色值有 **360 处，分布在 70 个文件**（材质棘轮基线 `miniprogram/scripts/materials-baseline.json`）。
- 交互不统一：
  - 有的纸卡按下时缩放 0.992，有的降透明度，有的只变底色；
  - 纸上的金色按钮有的配黑投影（像一块塑料）；
  - 山海有信的「山海」水印压在按钮上。
- 有些纸质的东西还是暗底深卡，例如商品详情「来源说明」里随附的合规文件。

## 二、材质清单与令牌（`app.wxss` 的 `page{}`，均为单行）

### 纸（Paper）

| 令牌 | 值 | 用在哪 |
|------|----|--------|
| `--mat-paper-label` | `#F3ECDD → #E8DFCB` | **标本签纸（默认）**：知识卡、证书缩样、成就签、礼赠页头、山海有信来信、来源说明 |
| `--mat-paper-letter` | `#FAF6ED → #F2EDE4` | **信笺纸**：礼笺、信件正文。比标本签更白、更轻 |
| `--mat-paper-kraft` | `#E6DAC2 → #D9CAAD` | **牛皮回执纸**：回执、附页、垫纸 |
| `--mat-paper-grain` | 6rpx 间距横纹，透明度 2.2% | 叠在纸底上面：`background: var(--mat-paper-grain), var(--mat-paper-label)` |
| `--mat-paper-edge` | 1rpx 内描边 | 纸的切边 |
| `--mat-paper-frame` | 发丝色 | 内框线（`::before` + `inset 8–14rpx`） |
| `--mat-paper-rule` | 虚线色 | 纸内分隔线（`1rpx dashed`） |
| `--mat-paper-shadow` / `-press` | 暗底上的纸投影 / 按下后的短投影 | 纸放在暗色页面上时 |

### 纸上的墨（Ink）：纸面上的文字只用这四档

| 令牌 | 用途 |
|------|------|
| `--mat-ink` `#2E2618` | 标题、正文主字 |
| `--mat-ink-body` `#4A3E28` | 正文、已读标题 |
| `--mat-ink-soft` `#6B5A3E` | 次要说明、拉丁学名 |
| `--mat-ink-label` `#8A6F45` | 眉标、时间、阶元小字 |

> ❌ 纸上**不用** `--color-text-*`：那组是给暗底用的，放到纸上就是「浅字贴纸」。`check:materials` M3 会拦截。

### 金属（Metal）

| 令牌 | 用途 |
|------|------|
| `--mat-brass` + `--mat-brass-edge` + `--mat-brass-shadow`，字用 `--mat-brass-ink` | **纸上的主动作 / 铭牌**：黄铜实心药丸，深墨字，暖棕浅影，一道内高光 |
| `--mat-brass-polished` | 抛光黄铜大面（心愿墙入口、徽记）。不用于按钮 |
| `--mat-brass-pin` | 铜别针 / 铆钉 |
| `--mat-blackgold` + `--mat-blackgold-line` | 黑金面（积分卡口径） |
| `--mat-porcelain` | 白瓷 / 银面（会员卡浅色皮肤口径） |

> 暗底页面上的主按钮仍然是 `--brass-400` 实心（VIS3 规则「实心金只给一个主 CTA」），不用 `--mat-brass`。
> `--mat-brass` 只出现在纸上。纸上的黄铜面**不配黑投影**（M4）。

### 印（Seal）

`--mat-seal` 朱砂 `#8E3B2E` 是纸上唯一的红，用于实心方印、火漆点、未读点。实心印上的字用 `--mat-seal-ink`。
细框印章（分类、合规标签）用 `--mat-seal-tint` 作底、`--mat-seal-line` 作内描边。

## 三、结构与交互

1. **纸的结构固定为三层**：纸底（+纸纹）→ 内框 `::before` → 正文。
   - 水印、印章这类装饰放在 `::after`，必须 `z-index: 0`，同时正文 `position: relative; z-index: 1`（M5）。
   - 山海有信的水印压住「查看物流」，就是缺了这一步。
2. **按压**：
   - 纸：下沉 `var(--mat-press-shift)`（2rpx），投影换成 `--mat-paper-shadow-press`，**不缩放、不降透明度**。缩放会让纸边和内框发虚。
   - 金属钮：下沉 1rpx，去掉内高光，投影收短。
   - 两者都要配 `hover-stay-time="80"`（既有守卫 `check:hover-stay`）。
3. **圆角**：沿用圆角规范。
   - 物件（证书、票、签、印）用 `--r-object`。
   - 作为「列表卡 / 内容容器」出现的纸卡用 `--r-card`。
   - 资产大卡（会员、积分、钱包）用 `--r-hero`。
4. **一屏一张主角纸**：同一屏里纸卡多于一张时，只有主角纸可以带水印或印章，其余只保留内框。
5. **特异性**：给已有暗底样式的模块换上纸面时，规则写在文件末尾，并且用**与旧规则相同的前缀**（同特异性，后写者胜）。不要退回短前缀，否则会输给旧规则。

## 六、守卫

`npm run check:materials`（visual 域，9 个内存注入，`--selftest`）检查以下几项：
- M1：令牌齐全且单行；
- M2：登记的材质模块在用令牌（新增材质模块要在 `check-materials.mjs` 的 `MODULES` 里登记）；
- M3：纸面规则不用暗底字色；
- M4：纸上的黄铜面不配黑投影；
- M5：文字水印沉底、正文抬层；
- M6：裸写的纸 / 墨 / 印色值按文件只减不增。
