# 弹层视觉规范 · 2026-10-13

> 产品负责人 2026-10-13 点名：「新增一个全局的弹窗样式优化和统一，现在的弹窗样式过于丑陋，需要统一到最新的视觉规范；搭建全新的弹窗样式视觉规范与标准。」
>
> 本规范是**全站弹层的唯一标准**：确认框、底部抽屉、仪式卡、轻提示。
> 承接契约 C7（`docs/契约C7_设计令牌与交互规范_2026-09-18.md` §4 弹层、§5 动效）与「我的设计原则」（说一次 / 发丝金 / 每屏一个实心金 / 眉标 + 主标两行 / 空字段不出）。
> 实现：`miniprogram/app.wxss` 的 `--pop-*` 令牌与 `ui-pop-*` 零件；`components/AppModal`、`components/AppToast` 是两个母版。

## 0. 改版前的问题（2026-10-13 实测）

| 问题 | 实测 |

## 1. 三种形态

| 形态 | 用在哪 | 结构 |
|---|---|---|
| **确认框 Dialog** | 二次确认、告知、需要用户做一个决定 | 居中；`ui-pop-mask is-center` > `ui-pop-dialog` |
| **底部抽屉 Sheet** | 选择（礼券 / 规格 / 门店）、填写（地址）、较长内容 | 贴底；`ui-pop-mask` > `ui-pop-sheet`（顶部抓手 `ui-pop-grip`） |
| **仪式卡 Ceremony** | 升级、生日礼、证书、海报 —— 有情绪的时刻 | 居中；`ui-pop-mask is-center is-deep`，允许一枚主视觉（印章 / 插图） |
| 轻提示 Toast | 结果反馈，不打断 | `AppToast`（非阻塞，不拦点击、不拦滚动） |

**选型规则**：只要一个「是 / 否」→ 确认框；要从多项里挑 / 要填东西 → 抽屉；不需要用户操作 → 轻提示；
**不得**用确认框承载列表，**不得**用抽屉问一个是否题。

## 3. 零件（`ui-pop-*`）

```
ui-pop-mask [is-center] [is-deep]      遮罩：淡入 240ms；catchtouchmove 防穿透
├─ ui-pop-dialog                       确认框牌面：≤600rpx 宽，48/40/32 内边距，上浮 16rpx + 0.97→1 缩放进场
└─ ui-pop-sheet                        抽屉：贴底、≤86vh、自带底部安全区、自下而上进场
   ├─ ui-pop-grip                      抓手 56×6rpx
   ├─ ui-pop-head [is-center]          头部
   │   ├─ ui-pop-kicker                英文大写眉标：等宽 18rpx、.32em、品牌金
   │   ├─ ui-pop-title                 中文主标：宋体 500、34rpx、白
   │   ├─ ui-pop-sub                   一句说明（可选）：24rpx secondary
   │   └─ ui-pop-close                 ✕：右上、88rpx 触控区、secondary 色
   ├─ ui-pop-body                      正文 / 列表区：左右 40rpx
   │   └─ ui-pop-row [is-off]          选择行：≥112rpx、发丝分隔（不做方框卡片）+ ui-pop-radio [is-on]
   └─ ui-pop-foot                      底栏：按钮区，抽屉带顶部分隔线
       └─ ui-pop-btn is-primary | is-ghost | is-danger [is-disabled]
```

**挂载方式两种，零件都支持**：
- `wx:if` 挂载（多数）：直接用上面的零件，进场动画由零件提供，退场硬切。
- 常驻节点、靠类切换显隐（有退场动画）：遮罩加 `is-toggle`，打开时再加 `is-open`。
  ⚠️ 不能对常驻节点用默认零件 —— 进场动画的 `fill-mode: both` 会把隐藏态的 `opacity` 顶成 1（看得见点不了）。
- 「先挂载、下一帧加 `on`」的抽屉（我的礼赠）：保留自己的过渡，只把底色 / 边 / 圆角 / 时长换成令牌。

纵向 flex 牌面里放 `ui-pop-btn` 要写 `flex: none`（零件默认 `flex: 1` 是给横排底栏用的）。

**页面 wxss 只写本弹层特有的内容**（列表行内排版、表单字段、尺寸）。
**不得**再自写：遮罩色、牌面底、圆角、金边、投影、进场动画、关闭钮样式、按钮主次样式。

## 4. 排版与文案

1. **头部两行**：英文眉标一行、中文主标一行；不写「EN / 中」单行；眉标可省，主标不可省。
2. **主标说清楚事**：`删除这条收货地址？` 而不是 `提示`；≤ 12 字，不换行。
3. **正文 ≤ 3 行**：26rpx、行高 1.7、secondary；`\n` 保留（pre-wrap），不得连续 3 个以上换行（C7 §4.4）。
   长说明放「了解规则 ›」之类的二级链接，不塞进弹窗。
4. **说一次**：弹窗里不重复页面上已有的价格 / 状态；同一提示不在弹窗和页面各写一遍。
5. **空字段不出**：没有值的行整行隐藏，不写「—」「暂无」。

## 5. 按钮

| 规则 | 说明 |
|---|---|
| **一个实心金** | 每个弹层最多一个 `is-primary`；其余用 `is-ghost`（发丝描边）或文字链 |
| 次按钮在左、主按钮在右 | 两个按钮等宽；三个及以上等分一行、字收一档（AppModal `actions`） |
| 动词、2–4 字 | `删除` `设为默认` `去支付`；取消类用 `取消` / `再想想` |
| 危险 | `is-danger` 只用于删除 / 退款 / 清空；危险弹窗**不可**点遮罩关闭（C7 §4.2 硬规则①） |
| 不换行 | `white-space: nowrap`，文案放不下就改短 |
| 高度 88rpx | 触控区不小于 88rpx |

单选抽屉（选券 / 选门店）：**点行即选中并关闭**，不另设「确定」；多选或需要二次确认时才有底栏主按钮。

## 6. 关闭与交互

| 形态 | 点遮罩 | ✕ | 说明 |
|---|---|---|---|
| 确认框（默认） | 不关 | 无 | `closable: false`，与改版前一致 |
| 确认框（纯告知 / 长说明） | 可配 | 可配 | AppModal `closable: 'mask' \| 'button' \| 'both'`，关闭一律结算为「取消」 |
| 抽屉 | 关 | 有 | 右上 ✕ + 点遮罩都关；正在提交时两者都不响应 |
| 仪式卡 | 不关 | 无 | 由主按钮 / 文字链收下 |

- 遮罩一律 `catchtouchmove`，防止背后页面跟着滚；抽屉内长列表用 `scroll-view`。
- 进场必有动效（遮罩淡入 + 牌面上浮 / 抽屉上滑，240ms）；退场可硬切（`wx:if` 卸载）。
- `prefers-reduced-motion` 下不做动效（零件已带）。
- 自定义组件要用零件，需 `options: { addGlobalClass: true }`。

## 7. 原生弹窗

- 新代码**不得**直接 `wx.showModal`（`check:modal-style` 棘轮只降不升）。两种接法：
  - Page 页：`withAppModal` 包配置 + `<app-modal id="appModal" />`，`await this.modal({...})`；
  - Component 构造的页面 / 组件 / 纯模块：`openAppModal(与 wx.showModal 相同的入参, this)`（`utils/appModal.js`），
    success / fail / complete 原样回调；`confirmColor` 为红自动转 `danger`；组件把宿主挂在自己的 wxml 里，模块不传 `this` 则找当前页。
- ⚠️ **必须保留系统弹窗的两类**：① 确认后要调「需要点击手势」的接口（`wx.openSetting`、`requestSubscribeMessage` 订阅授权、`navigateToMiniProgram` …）——
  系统弹窗的 success 被微信算作手势，AppModal 的回调是 Promise 异步触发、不算（起因：礼赠语音「去设置」，2026-10-13 发现即退回）；
  ② 需要输入框（`editable: true`，如店长口令）—— AppModal 不支持。`check:pop-spec` 会拦 ① 类。
- 轻提示走 `AppToast`；`wx.showLoading` / `wx.showActionSheet` 暂按 C7 §4.1 豁免并计入棘轮。

- `.ss-sheet-body { flex: 0 1 auto; min-height: 0 }`（R9-2，高度只认内联 `sheetBodyPx`）；
- 头部 / 搜索 / 底栏仍带 `catchtouchmove="noop"`，而**牌面容器上不许挂**（挂了就滑不动，R9-5 有注入专测）。
- `.is-top`（原来给选择器压层用的 z-index 50/51）**删掉**：零件统一 z-index 后「后出现的抽屉在上面」由 DOM 顺序保证，不必各写一套层级。
- 源码行变了 → 该守卫的注入锚点要跟着改（本次 `ss-sheet is-top` 那一行），改完跑 `check:c-stream-polish:selftest` 确认 96 个注入仍全部被检出。

### 11.3 迁移配方（照 C 端第 1／2 批的既有约定，逐条改、不做 find-replace）

- 遮罩：`class="X-mask"` → `class="ui-pop-mask is-center"`（抽屉不加 `is-center`）+ `catchtouchmove="true"`。
- 牌面：`class="X-sheet|X-modal"` → 追加 `ui-pop-sheet`（抽屉，配 `ui-pop-grip`）或 `ui-pop-dialog`（确认框）+ `catchtap="true"`；
  **页面自己的类保留**（`.modal .workbench-modal-foot` 这类后代选择器还靠它）。
- 头部：`modal-title` → `ui-pop-title`、`modal-sub` → `ui-pop-sub`，补一条等宽眉标 `ui-pop-kicker`；关闭文字 → `ui-pop-close` 的 ✕。
- 页面 wxss **只删**：遮罩色 / 牌面底 / 圆角 / 金边 / 投影 / 进场动画；保留尺寸、滚动、列表行。
  ⚠️ **牌面自带左右 `--pop-pad-x`（40rpx）**，页面内部块（body / 底栏）要把左右 padding 归零，否则两侧留白翻倍。
- 结束后：登记 `MIGRATED` → `node miniprogram/scripts/check-pop-spec.mjs --tighten`。

### 11.4 本批踩到的两个真坑（都已修 + 已有守卫能抓）

1. **平级结构要嵌起来**：`.ops-*` 原来是 `mask` 与 `sheet` **并列**（各自 `wx:if`）。`ui-pop-sheet` 是 `position: absolute`，
   必须有自己的定位祖先，否则抽屉会跟着页面滚 —— 所以迁移时把 sheet 嵌进 mask；为此还要**保留复合条件**
   （`wx:if="{{showDetail && detail}}"`）在牌面上，否则 `check:c-stream-polish` R9-6（page-meta 锁滚动）读首个条件会判红。
2. **共享定义带镜像**：`extra/utils/ops-museum.wxss` 与 `manager/utils/ops-museum.wxss` 是 `subpackage-mirrors.json` 里登记的镜像，
   改一份必须同步另一份，否则 `check:subpackage-refs` 判「镜像漂移」（本次就是它抓到的）。


### 11.6 第 3 批 d 的取舍（核销页：只换形态、排版保留）

`extra/staff/field` 是店员**全天在用**的现场核销 / 查证页，所以本批只把**形态**换成零件，**排版刻意不动**：

- 遮罩 → `ui-pop-mask is-center is-deep`（原值 0.88 / 0.94 → 令牌 `--pop-mask-deep` 0.88）；牌面 → `ui-pop-dialog`；
  进场动画改由零件提供，**退场动画保留**（`is-closing` → `.ui-pop-mask.is-closing { animation: mask-out }`，页面规则特异性更高、压得住零件的进场动画）；
  `mask-in` / `modal-in` 两个 keyframes 随之删除（不再有使用者）。
- **保留**：`.modal-title.ok/.no` 的核销状态色（success / warning）、`.kind-label` 眉标、`.modal-pass` 的「顶栏固定 + 中部滚动 + 底栏固定」三段布局、
  `.mask-blocker`（挡底层滚动的透明挡板）、`.mask-result` 的底边距（与贴底扫码条错开）。
- 理由：这页的标题是**状态语义色**（成功 / 失败），排版统一留到「全站状态色与字阶」那一轮一起做，避免在店员最常用的页上叠两处改动。
