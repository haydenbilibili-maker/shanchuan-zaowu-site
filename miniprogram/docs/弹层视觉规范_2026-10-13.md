# 弹层视觉规范 · 2026-10-13

> 产品负责人 2026-10-13 点名：「新增一个全局的弹窗样式优化和统一，现在的弹窗样式过于丑陋，需要统一到最新的视觉规范；搭建全新的弹窗样式视觉规范与标准。」
>
> 本规范是**全站弹层的唯一标准**：确认框、底部抽屉、仪式卡、轻提示。
> 承接契约 C7（`docs/契约C7_设计令牌与交互规范_2026-09-18.md` §4 弹层、§5 动效）与「我的设计原则」（说一次 / 发丝金 / 每屏一个实心金 / 眉标 + 主标两行 / 空字段不出）。
> 实现：`miniprogram/app.wxss` 的 `--pop-*` 令牌与 `ui-pop-*` 零件；`components/AppModal`、`components/AppToast` 是两个母版。

---

## 0. 改版前的问题（2026-10-13 实测）

| 问题 | 实测 |
|---|---|
| 遮罩各写各的 | C 端 53 个固定定位弹层，遮罩约 **30 种**写法：`rgba(0,0,0,.45)` ~ `rgba(26,24,20,.98)`，冷黑与暖黑混用 |
| 层级无序 | z-index 从 40 到 10050，同类弹层高低不一 |
| 牌面三种语言 | 平涂 / 渐变 / 米白纸感；四角铭牌、2rpx 金边、方框列表卡片并存 |
| 头部无规矩 | 有的 30rpx 黑体单行标题、有的「EN / 中」挤一行、有的没标题；关闭钮有 ✕ 有「关闭」有没有 |
| 无动效 | AppModal 写了 `is-on/is-off` 过渡，但用 `wx:if` 挂载 → 过渡从未生效，硬切 |
| 原生白底弹窗 | C 端仍有约 23 处 `wx.showModal`（白底 Material），与博物黑两张皮 |
| 抽屉高度写死 | 例：购物车选券列表 `height: 56vh`，只有 1 张券时下面空一大片 |

## 1. 三种形态

| 形态 | 用在哪 | 结构 |
|---|---|---|
| **确认框 Dialog** | 二次确认、告知、需要用户做一个决定 | 居中；`ui-pop-mask is-center` > `ui-pop-dialog` |
| **底部抽屉 Sheet** | 选择（礼券 / 规格 / 门店）、填写（地址）、较长内容 | 贴底；`ui-pop-mask` > `ui-pop-sheet`（顶部抓手 `ui-pop-grip`） |
| **仪式卡 Ceremony** | 升级、生日礼、证书、海报 —— 有情绪的时刻 | 居中；`ui-pop-mask is-center is-deep`，允许一枚主视觉（印章 / 插图） |
| 轻提示 Toast | 结果反馈，不打断 | `AppToast`（非阻塞，不拦点击、不拦滚动） |

**选型规则**：只要一个「是 / 否」→ 确认框；要从多项里挑 / 要填东西 → 抽屉；不需要用户操作 → 轻提示；
**不得**用确认框承载列表，**不得**用抽屉问一个是否题。

## 2. 令牌（`app.wxss` `page {}`）

| 令牌 | 值 | 说明 |
|---|---|---|
| `--pop-mask` | `rgba(12, 11, 9, 0.72)` | 确认框 / 抽屉遮罩（唯一值） |
| `--pop-mask-deep` | `rgba(12, 11, 9, 0.88)` | 仪式卡遮罩 |
| `--pop-surface` | `linear-gradient(180deg, #221F1B 0%, #1C1A17 100%)` | 牌面（极轻的上亮下暗，不做纸感 / 金属感） |
| `--pop-hairline` | `rgba(196, 167, 108, 0.36)` | **1rpx** 发丝金边（确认框四边、抽屉只顶边） |
| `--pop-divider` | `rgba(255, 255, 255, 0.06)` | 列表行 / 底栏分隔 |
| `--pop-radius-dialog` / `--pop-radius-sheet` | `24rpx` / `32rpx` | 抽屉只圆上两角 |
| `--pop-shadow-dialog` / `--pop-shadow-sheet` | `0 24rpx 64rpx rgba(0,0,0,.55)` / `0 -16rpx 48rpx rgba(0,0,0,.42)` | |
| `--pop-pad-x` | `40rpx` | 弹层内左右留白（全站唯一） |
| `--pop-danger-from` / `--pop-danger-to` | `#B4432F` / `#93321F` | 危险主按钮（= C7 §4.3） |
| `--dur-instant/fast/base/slow` | `80 / 160 / 240 / 400ms` | = C7 §5.1 |
| `--ease-standard` / `--ease-out-soft` | 见 app.wxss | = C7 §5.2；**弹层禁用回弹缓动** |

**层级**（新弹层按此取值；存量不为对齐而改，避免改变叠放关系）：
页面浮层（吸底栏 / 悬浮钮）≤ 100 < 抽屉 / 页面弹层 800 < 注册弹窗 900 < AppModal 950 < AppToast 1080。
特例：`SensitiveBlurGate` 偏好层、`MemberLevelModal` 需盖住全局元素，保留现值（10000+）。

## 3. 零件（`ui-pop-*`）

```
ui-pop-mask [is-center] [is-deep]      遮罩：淡入 240ms；catchtouchmove 防穿透
├─ ui-pop-dialog                       确认框牌面：≤600rpx 宽，48/40/32 内边距，上浮 16rpx + 0.97→1 缩放进场
└─ ui-pop-sheet                        抽屉：贴底、≤86vh、自带底部安全区、自下而上进场
   ├─ ui-pop-grip                      抓手 56×6rpx
   ├─ ui-pop-head [is-center]          头部
   │   ├─ ui-pop-kicker                英文大写眉标：等宽 18rpx、.32em、品牌金
   │   ├─ ui-pop-title                 中文主标：宋体 500、34rpx、白
   │   ├─ ui-pop-sub                   一句说明（可选）：24rpx secondary
   │   └─ ui-pop-close                 ✕：右上、88rpx 触控区、secondary 色
   ├─ ui-pop-body                      正文 / 列表区：左右 40rpx
   │   └─ ui-pop-row [is-off]          选择行：≥112rpx、发丝分隔（不做方框卡片）+ ui-pop-radio [is-on]
   └─ ui-pop-foot                      底栏：按钮区，抽屉带顶部分隔线
       └─ ui-pop-btn is-primary | is-ghost | is-danger [is-disabled]
```

**页面 wxss 只写本弹层特有的内容**（列表行内排版、表单字段、尺寸）。
**不得**再自写：遮罩色、牌面底、圆角、金边、投影、进场动画、关闭钮样式、按钮主次样式。

## 4. 排版与文案

1. **头部两行**：英文眉标一行、中文主标一行；不写「EN / 中」单行；眉标可省，主标不可省。
2. **主标说清楚事**：`删除这条收货地址？` 而不是 `提示`；≤ 12 字，不换行。
3. **正文 ≤ 3 行**：26rpx、行高 1.7、secondary；`\n` 保留（pre-wrap），不得连续 3 个以上换行（C7 §4.4）。
   长说明放「了解规则 ›」之类的二级链接，不塞进弹窗。
4. **说一次**：弹窗里不重复页面上已有的价格 / 状态；同一提示不在弹窗和页面各写一遍。
5. **空字段不出**：没有值的行整行隐藏，不写「—」「暂无」。

## 5. 按钮

| 规则 | 说明 |
|---|---|
| **一个实心金** | 每个弹层最多一个 `is-primary`；其余用 `is-ghost`（发丝描边）或文字链 |
| 次按钮在左、主按钮在右 | 两个按钮等宽；三个及以上等分一行、字收一档（AppModal `actions`） |
| 动词、2–4 字 | `删除` `设为默认` `去支付`；取消类用 `取消` / `再想想` |
| 危险 | `is-danger` 只用于删除 / 退款 / 清空；危险弹窗**不可**点遮罩关闭（C7 §4.2 硬规则①） |
| 不换行 | `white-space: nowrap`，文案放不下就改短 |
| 高度 88rpx | 触控区不小于 88rpx |

单选抽屉（选券 / 选门店）：**点行即选中并关闭**，不另设「确定」；多选或需要二次确认时才有底栏主按钮。

## 6. 关闭与交互

| 形态 | 点遮罩 | ✕ | 说明 |
|---|---|---|---|
| 确认框（默认） | 不关 | 无 | `closable: false`，与改版前一致 |
| 确认框（纯告知 / 长说明） | 可配 | 可配 | AppModal `closable: 'mask' \| 'button' \| 'both'`，关闭一律结算为「取消」 |
| 抽屉 | 关 | 有 | 右上 ✕ + 点遮罩都关；正在提交时两者都不响应 |
| 仪式卡 | 不关 | 无 | 由主按钮 / 文字链收下 |

- 遮罩一律 `catchtouchmove`，防止背后页面跟着滚；抽屉内长列表用 `scroll-view`。
- 进场必有动效（遮罩淡入 + 牌面上浮 / 抽屉上滑，240ms）；退场可硬切（`wx:if` 卸载）。
- `prefers-reduced-motion` 下不做动效（零件已带）。
- 自定义组件要用零件，需 `options: { addGlobalClass: true }`。

## 7. 原生弹窗

- 新代码**不得**直接 `wx.showModal`：页面 `withAppModal` + `<app-modal id="appModal" />`，用 `this.modal()`（`check:modal-style` 棘轮只降不升）。
- 轻提示走 `AppToast`；`wx.showLoading` / `wx.showActionSheet` 暂按 C7 §4.1 豁免并计入棘轮。
