# 快速测试清单

## ⚡ 5分钟快速验证

### 步骤1: 检查文件完整性 (1分钟)

在微信开发者工具中，确认以下文件存在：

- [x] `utils/cache.js` - 缓存工具
- [x] `cloudfunctions/getRecommendations/index.js` - 推荐云函数
- [x] `cloudfunctions/getRecommendations/package.json` - 云函数配置
- [x] `cloudfunctions/trackUserBehavior/index.js` - 行为追踪云函数
- [x] `cloudfunctions/trackUserBehavior/package.json` - 云函数配置
- [x] `pages/index/index.js` - 首页逻辑（已更新）
- [x] `pages/index/index.wxml` - 首页结构（已更新）
- [x] `pages/index/index.wxss` - 首页样式（已更新）

### 步骤2: 部署云函数 (2分钟)

1. **部署 getRecommendations**
   ```
   右键 cloudfunctions/getRecommendations → 上传并部署：云端安装依赖
   ```

2. **部署 trackUserBehavior**
   ```
   右键 cloudfunctions/trackUserBehavior → 上传并部署：云端安装依赖
   ```

3. **验证部署**
   - 在云开发控制台 → 云函数
   - 确认两个函数状态为"正常"

### 步骤3: 创建数据库集合 (1分钟)

1. 云开发控制台 → 数据库 → 集合管理
2. 创建集合：`user_behaviors`
3. 设置权限：仅创建者可读写（或根据需求）

### 步骤4: 运行测试 (1分钟)

1. **编译运行小程序**
   - 点击"编译"按钮
   - 等待首页加载

2. **检查控制台**
   - 打开"调试器" → "Console"
   - 查看是否有错误信息

3. **验证功能**
   - [ ] 首页正常加载
   - [ ] 推荐模块显示（在"最新入库"之前）
   - [ ] 点击商品，查看详情页
   - [ ] 返回首页，检查推荐是否更新

## 🔍 快速问题排查

### 如果推荐模块不显示：

1. **检查云函数日志**
   ```
   云开发控制台 → 云函数 → getRecommendations → 日志
   ```

2. **检查数据库**
   ```
   确认 products 集合有数据
   确认集合权限为"所有用户可读"
   ```

3. **检查控制台错误**
   ```
   开发者工具 → 调试器 → Console
   查看是否有红色错误信息
   ```

### 如果用户行为未记录：

1. **检查 openid**
   ```javascript
   // 在控制台执行
   console.log('OpenID:', getApp().globalData.openid);
   ```

2. **检查云函数**
   ```
   确认 trackUserBehavior 已部署
   查看云函数日志
   ```

3. **检查集合权限**
   ```
   确认 user_behaviors 集合已创建
   确认权限设置正确
   ```
