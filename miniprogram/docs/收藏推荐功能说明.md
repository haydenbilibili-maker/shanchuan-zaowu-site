## 📋 部署步骤

### 1. 部署云函数

需要部署以下云函数：
```
cloudfunctions/getCollectionRecommendations
```

**部署命令**：
1. 在微信开发者工具中，右键点击 `cloudfunctions/getCollectionRecommendations`
2. 选择"上传并部署：云端安装依赖"
3. 等待部署完成

### 2. 确保数据库集合存在

功能依赖以下数据库集合：
- `collections` - 用户收藏数据
- `products` - 商品数据

### 3. 确保权限配置

确保云函数有权限访问上述数据库集合。

## 🎯 功能说明

### 推荐算法

#### 1. 收藏偏好分析
- 统计用户收藏商品的分类分布
- 统计用户收藏商品的标签分布
- 取前5个分类和前10个标签作为偏好

#### 2. 推荐策略
1. **基于分类推荐**：推荐与收藏商品相同分类的商品
2. **基于标签推荐**：推荐与收藏商品有相同标签的商品
3. **热门补充**：如果推荐不足，补充热门商品
4. **去重过滤**：排除已收藏的商品

#### 3. 推荐理由
- "基于你的收藏偏好" - 分类匹配
- "与你收藏的内容相似" - 标签匹配
- "为你推荐" - 默认理由

### UI展示

#### 收藏列表中的推荐
- 位置：收藏列表下方
- 标题："你可能也喜欢 / YOU MAY ALSO LIKE"
- 副标题："基于你的收藏偏好"
- 横向滚动卡片展示

#### 空状态时的推荐
- 位置：空状态提示下方
- 标题："为你推荐 / FOR YOU"
- 引导用户发现新内容

### 推荐卡片设计
- 卡片尺寸：240rpx × 360rpx
- 图片区域：240rpx × 240rpx
- 信息区域：标题、拉丁名、价格
- 推荐理由标签：右上角显示

## 🔧 代码实现

### 云函数调用

```javascript
// 在 pages/cart/index.js 中
async loadCollectionRecommendations() {
  const res = await wx.cloud.callFunction({
    name: 'getCollectionRecommendations',
    data: {
      userId: app.globalData.openid,
      limit: 8
    }
  });
  // 处理返回的数据
}
```

### 数据格式

云函数返回的数据结构：
```javascript
{
  success: true,
  data: [
    {
      _id: String,
      title: String,
      latinName: String,
      price: Number,
      image: String,
      category: String,
      tags: Array,
      reason: String // 推荐理由
    }
  ],
  count: Number,
  trend: {
    recentCollections: Array, // 最近收藏
    topCategories: Array, // 热门分类
    totalCollections: Number // 总收藏数
  }
}
```

## 📊 性能优化
