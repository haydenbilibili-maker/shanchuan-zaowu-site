## 3. 新设计：「心愿标本签」

把门店里真实存在的黑马标本当作展品，每条心愿 = 别在它身旁的一张**标本签**（编号 / 写签人 / 日期 / 展品 / 门店）；墙 = 标签柜。视觉完全沿用全站口径（博物黑、发丝金、纸质展签、眉标 + 主标、实拍渐隐），**不再使用任何金属 / 庙会元素**。

效果图：四屏（首页入口卡 / 展品首屏 / 写签 / 墙），见 2026-10-13 评审稿。

1. **首页入口卡**：黑马实拍缩略 + 「马上有 · 心愿签」+ 一句最新心愿；去跑马灯、铭牌、发光灯。
2. **展品首屏**：实拍 + 底部渐隐；展签式数据（总签数 / 今日 / 写签人）；三张最新签露角；唯一实心金「写一张心愿签」，「今日一签 ›」为文字链。
3. **写签**：底部弹层里一张空白标本签，在签上直接写；灵感词点按填入签面；额度与字数同一行；「别上墙」→ 签面飞上墙 → 分享卡（小程序码回墙）。
4. **墙**：纸签两列错落，只留「最新 / 我的」；刚写的那张描金标「我的 · 刚别上」；点签看详情，可「我也想要」/ 分享。

**删除**：木鱼 / 功德证 / 点灯 / 节气倒计时 / 音效开关 / 星座 / MBTI / 铜钱 / 拆签饼 / 节气签 / 彩蛋与博物笔记 / 弹幕跑马灯 / 三种排序与置顶筛选。**保留** 1 个「今日一签」（改为同一套标本签视觉）。

## 10. 语音心愿（2026-10-13 产品负责人新增）

**拍板**：文字必填、语音选附；单条 ≤ 15 秒；**全部人工试听**后才公开。

- **写签**：签下「按住附一段声音（15 秒内，可不录）」→ 试听 / 删除；录音只存本地，**点「别上墙」时才上传**到 `wish-voice/`（录了不发不留云端文件），`post` 失败即删刚传的文件。录音复用礼赠 `giftVoice.createGiftRecorder`（新增可选 `maxMs`，不传 = 礼赠原 60 秒，行为不变）。
- **云函数**：`post` 可选 `voiceFileID / voiceDuration`（校验目录与 1–15 秒，一律 `pending`）；公开列表只给 `approved` 的签换**临时播放链接**（不回 fileID）；`mine` 作者自己任何状态都能听；`staffList` 带链接、`voice=pending` 筛「待试听」；新增 `staffSetVoice`（仅超管 / 店长，条件更新只改 pending；驳回删文件、清 fileID，文字照常）。
- **展示**：通过的签上一枚细铜「▶ 0:08」小签，点了只播放不打开详情；作者自己的签标「声音审核中 / 声音未通过」（别人看不到）；签详情可「听这段声音」。
- **试听台**：超管「祈福墙管理」新增「待试听」页签，每条可试听、「通过公开 / 驳回删除」。
- **守卫**：`test:wish-labels` 增 C5/C6、F6–F9（注入 10 → 14）。
- **隐私**：录音为个人信息 —— 小程序后台「用户隐私保护指引」需包含「麦克风 / 录音」用途（礼赠语音已在用，补一句「心愿签语音」即可），由产品负责人在公众平台更新。
