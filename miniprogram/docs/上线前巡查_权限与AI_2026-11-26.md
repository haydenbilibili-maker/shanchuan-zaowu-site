# 上线前巡查：工作台权限 & AI 关闭后的痕迹（2026-11-26）

> 产品负责人提的两问：① 工作台会不会展示给未授权用户；② AI 全部关闭后还有没有痕迹漏出。

## 1. 工作台（超管/店长/店员）——未授权用户看不到

| 层 | 事实 | 结论 |
|---|---|---|
| 「我的」页工作台区 | `wx:if="{{workbenchTiles.length > 0}}"`；tiles 来自 `workbenchEntries(role payload)`，角色由 `manageStaff whoami` / 会话返回；游客 roles 为空 → 整块不渲染 | ✅ 不展示 |
| 超管工作台页 `subpackages/manager/manager/index` | `onLoad` 第一行 `if (!guardManagerPage()) return`；guard 校验 **openid + 设备 + TTL** 三重本地信任，失败即 toast + 返回 | ✅ 直接输 URL 也进不去 |
| 工作台内嵌 workspace 页 | 同样 `guardManagerPage()` 门禁 | ✅ |
| 云函数侧 | `manageProducts` / `manageStaff` / `getUserMessages` 等均按 openid 查 staff 角色再执法；本地信任只影响 UI，不构成越权 | ✅ 双保险 |

本次未发现漏洞；`guardManagerPage` 依赖本地信任记录（openid+device+TTL），换账号不匹配即失效。

## 2. AI 全部关闭后的痕迹 —— 本轮补了 3 处

| 位置 | 问题 | 处理 |
|---|---|---|
| `subpackages/ai/ai-center`、`ai-debate` | **客户端无员工门禁**：顾客从历史链接/深链可直接看到整页 AI 界面（云端会拒答，但界面与角色名仍可见） | 新增 `subpackages/ai/utils/staffGate.js`（主包不能放：会撑主包体积；manager 分包不能引：微信禁止分包互相引用），两页 `onLoad` 先 `guardAiStaffPage()`，非员工静默返回 |
| `subpackages/feature/identify/result` | 识别结果页可被分享/深链直达，AI 关闭后仍展示 AI 结论（含「AI 生成」标注） | 新增 `aiClosed` 门禁：缓存或云端 `showAiIdentify === false` → 整页换成「AI 鉴定暂未开放」+ 回到探索 |
| 云端 | 之前已加：`askMuseumGuide` 与 `identifySpecimen` 读内容开关，关闭即拒答 | 保持 |

已核查无遗漏的入口：我的页（AI 鉴定 / 博物君 fail-closed）、分类页、搜索页、图鉴详情与日志、首页口播与印章、博物君页（闭馆态）。
埋点 `ai_identify_*` / `support_*` 属统计代码，不在用户可见界面。

## 3. 建议的提审口径

- 若保留 AI：必须补「深度合成 - AI问答」类目（详见 `AI能力与审核口径_2026-11-26.md`）；
- 若暂不申报：需要从**发布包**移除 AI 页面（`subpackages/ai`、`museum-guide`、`identify`），只关开关不够。
