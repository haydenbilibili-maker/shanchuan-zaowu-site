# 首页「为你推荐」· 横滑展柜重做（2026-10-13）

> 产品负责人：对原「一主两辅 + swiper 翻页」的交互视觉不满 → 选定「横滑展柜」+ 卡片只留「名称 + 一行门类 + 价格」。
> 前两版：`首页为你推荐_全面升级_2026-09-27.md`、`首页为你推荐_博物视觉重构_2026-10-10.md`（本版替代其展示层）。

## 为什么重做而不是微调

| 问题 | 原状 |
|---|---|
| 太高 | 一页 = 封面 640 + 两列 576 ≈ 1240rpx（1.6 屏），压住工坊 / 名师 / 活动 |
| 版式跳 | 封面按图片比例在横 / 竖两档间切换，每翻一页形状都变 |
| 信息太满 | 编号 No.01、主题名、标题、学名、题记、门类、价格、查看展品同卡 |
| 两套翻看方式打架 | swiper 左右滑（无可见提示）+「换一批」 |

## 新形态

- **一批 6 件横滑**：统一 3:4 竖卡（300×400 图 + 166 定高卡体），图底三段渐隐接卡体，`aspectFill + lazy-load`。
- **卡上三行**：主名（有诗意主题名用主题名，否则标题，宋体 500）/ 副行「门类 · 标题」（缺门类不留「 · 」）/ 价格（多规格最低价 +「起」，售罄小字）。
- **事实角标**：孤品 / 新藏 / 来自祈福墙 → 图左上细金边小签；合法带证仍走 `protected-badge`（左下）。
- **换一批 = 下一批 6 件**（转圈过渡 + 卡片淡入），并滚回第一张；件数 ≥ 6 时末批从头补齐，批内不重复，补位件不重复计曝光。
- **末尾「逛全部藏品 ›」**小卡，替代原页码点与底部链接。
- 策展手记（推荐理由）仍按当前批计算、只在头部说一次。

## 不变

`getRecommendations` 入参 `{ limit }`、`getBlessProducts` 入参、祈运件每 3 件插 1 与去重、14 天祈福墙信号与留档键、三态（骨架 / 失败原位重试 / 空态）、点击带 category/tags 交给 `goToDetail`、埋点 `home_reco_click` / `home_reco_expose` 调用逐字（expose 的 `page` 字段 = 批序号）。
