## 改前问题

1. 价目列表不显示图（37 条明明有图），每张卡四个「标签按钮」（上架中·点此下架 / 上移 / 下移 / 编辑）堆在一起，状态标签兼当按钮；
2. 图片只能手填「图片地址（可空，cloud:// 或 https）」；搜索框、编辑页出现「skuId」「服务端」等技术词；
3. 编辑页是一长串平铺表单，保存按钮在最底部；删除与保存挤在一起；
4. 伙伴卡无头像，只有「尾号 xxxxxx」；伙伴页功能说明写着「B2B 支付修复流的函数里，待其接入（蓝图 CR-1）」；
5. 加载只有一行「正在读取…」；网络失败提示直接显示云函数名与原始报错；订单页四排筛选芯片常驻，首屏被挤满。

## 图片的数据约定（只加图片字段，业务 / 权限 / 契约不变）

- **价目图（多图，2026-09-30 产品负责人拍板）**：沿用 ERP 维护的 `price_list_items.images`，约定与 ERP `normalizeImageFields`、官网 `priceListCloud.ts` 一致
  —— **`images[0]` 即封面，`image = images[0]`**（官网读 `image || images[0]`、图集读 `images`，无 `images` 时退回 `[image]`）。
  - 编辑页载入：封面（`image`）排首位 + 去重，与 ERP 打开编辑框看到的顺序相同；
  - 上传 → `b2b-price/` → 只存 `cloud://` fileID；**只有增 / 删 / 排序过才送整组 `images`**（不再送单张 `image`），没动图库里的图原样不动；
  - 云函数 `validateGallery`：入参带 `images` 才写（优先于单张 `image`）；**新图只收 `cloud://`**，库里该条目原有的地址（官网相对路径 / https）可原样保留；去重；**最多 9 张**；
    写入时同步 `image = images[0]`，清空 = `image: ''` + `images: []`；新建只收 `cloud://`。旧客户端只送单张 `image` 的路径仍兼容（换封面保留其余图）。
  - 列表缩略图仍取封面；点缩略图 / 「查看大图」可左右滑看整组。
- **伙伴资料图**：`staff_members.b2bProfile = { logo, licenses[] }`，新动作 `adminSavePartnerProfile`（登记在超管动作表里，走同一道超管门禁 + 操作日志），只写带了的键（换门头不动资质照）。
  资质照只经超管动作读出；页面直接用 `cloud://` 显示（按云存储权限读），**不转成公开 https 链接**；门头图按价目图同样方式显示。
- 显示统一走 `b2bdesk/utils/deskImage.js`（只调用 `utils/imageUrl`，不改它）。

## 真机验证点

1. 价目列表：有图条目显示缩略图，点缩略图看大图；「更多」弹层里下架 / 上架、上移 / 下移生效；
2. 编辑一条官网图条目，只改名称保存 → 回列表图仍在（未送图）；
   多图条目：打开编辑页图的顺序与 ERP 一致；把第 3 张「设为封面」、左右移、删一张后保存 → 列表缩略图 = 新封面，官网报价单封面与图集顺序同步，ERP 打开看到同样顺序；
   上传一次多选 3 张 → 按选择顺序追加；满 9 张后「＋」消失；
3. 新建价目带图 → 采购商工作台「供货价目选购」能看到图；
4. 伙伴详情上传门头 / 资质照 → 返回列表头像更新；删除一张资质照其余仍在；
5. 断网进入各页：提示为大白话；弹层遮罩点空白处关闭；吸底栏不遮挡最后一个输入框（iPhone 带底部横条）。
