## 📋 部署步骤

### 1. 部署云函数

需要部署以下云函数：
```
cloudfunctions/getUserStatistics
```

**部署命令**：
1. 在微信开发者工具中，右键点击 `cloudfunctions/getUserStatistics`
2. 选择"上传并部署：云端安装依赖"
3. 等待部署完成

### 2. 确保数据库集合存在

功能依赖以下数据库集合：
- `user_behaviors` - 用户行为记录
- `orders` - 订单数据
- `bookings` - 预约/课程数据
- `collections` - 收藏数据

### 3. 确保权限配置

确保云函数有权限访问上述数据库集合。

## 🎯 功能说明

### 数据统计预览

在用户中心首页，新增了"我的数据"预览面板，显示：
- **浏览数**：用户浏览过的内容总数
- **收藏数**：用户收藏的内容总数
- **分享数**：用户分享的次数
- **订单数**：用户完成的订单数

点击预览面板或"馆藏服务"中的"我的数据"可查看详细统计。

### 详细数据统计

#### 1. 我的数据
- 浏览数：从 `user_behaviors` 统计 `action: 'view'`
- 收藏数：从 `user_behaviors` 统计 `action: 'collect'`
- 分享数：从 `user_behaviors` 统计 `action: 'share'`
- 搜索数：从 `user_behaviors` 统计 `action: 'search'`

#### 2. 消费统计
- **总消费**：所有已支付订单的总金额
- **订单数**：已支付订单总数
- **平均客单价**：总消费 / 订单数

#### 3. 学习记录
- **完成课程**：已完成的课程预约数
- **获得证书**：已签收的非代金券订单数

#### 4. 收藏分类
- **藏品**：收藏的藏品数量
- **活动**：收藏的活动数量
- **课程**：收藏的课程数量

#### 5. 活跃度
- **最后活跃**：最后一次行为的时间（相对时间显示）

## 🔧 代码实现

### 云函数调用

```javascript

async loadUserStatistics() {
  const res = await wx.cloud.callFunction({

  // 处理返回的数据
```

## 📊 性能优化

1. **按需加载**：统计数据仅在打开详情弹窗时加载
2. **缓存机制**：可以考虑添加缓存，减少云函数调用
3. **异步处理**：统计数据加载不阻塞主流程
