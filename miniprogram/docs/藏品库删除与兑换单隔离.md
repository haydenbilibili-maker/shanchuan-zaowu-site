# 藏品库删除 · 兑换单不进藏品订单

**落地日期**：2026-09-14  
**涉及**：`subpackages/manager/manager/`（藏品库编辑弹窗）、`cloudfunctions/manageProducts`、`subpackages/business/orders/`、`cloudfunctions/getAnalyticsDashboard`

---

## 1. 藏品库编辑页新增「删除」

**入口**：店长台 → 藏品库 → 点藏品右侧 ✎ 打开编辑弹窗 → 底栏「删除」（在「确认保存」左侧）。

**权限**：仅 **超管** 可见可点。三条防线：

1. 界面：`wx:if="{{isEditing && !artisanEmbed && workspaceRole==='super_admin'}}"`（标本师嵌入视图不出现）。
2. 云函数角色：`manageProducts` 统一走 `staffGuard`（需 `manageProducts` 权限）。
3. 云函数动作：`removeProduct` 再次校验 `actor.superAdmin`，店长调用返回「仅超管可删除商品」。

**实现**：二次确认（标题《藏品名》+ 不可恢复提示）→ `wx.cloud.callFunction({ name: 'manageProducts', data: { action: 'remove', productId } })` → 成功后本地移除并刷新统计。

**与「下架」的区别**：

| 操作 | 字段 | 可恢复性 | 入口 |
|------|------|----------|------|
| 下架 | `products.isOffShelf = true` | 可再上架（上架走超管审批） | 藏品库列表开关 |
| 删除 | 物理删除文档 | **不可恢复** | 编辑弹窗「删除」 |

删除只影响 `products` 文档；已售订单（`orders`）与账本（`store_ledger` / `finance_records`）保留历史记录，不受影响。删除动作写入 `admin_operation_logs`（`action: product_remove`）便于追溯。

> `products` 集合 `write:false`，客户端不能直删；`manageProducts.remove` 与 Admin ERP 的删除按钮是同一条链路。

## 2. 代金券兑换不再进入藏品订单

**背景**：`exchangeCoupon` 在发券成功后，会往 `orders` 写一条兑换单（`source: 'exchange'`、`status: 'exchanged'`、`totalPrice: 0`），积分中心「我的兑换」依赖它。

**问题**：藏品订单列表「全部」Tab 只排除 `void`，于是兑换单混进了藏品订单。

**修复**：

| 位置 | 处理 |
|------|------|
| 藏品订单列表 | 查询加 `source: _.neq('exchange')`，客户端再过一遍兜底 |
| 分析看板订单计数 | `getAnalyticsDashboard` 计数时跳过 `source === 'exchange'`（兑换不是订单，不计数） |
| 积分中心 | 不变，仍按 `source: 'exchange'` 展示「我的兑换」 |

**本来就看不到的地方**（无需改动）：店长端订单管理四个 Tab 按 `status ∈ {paid/shipped/received/refunding...}` 过滤，`exchanged` 不在其中；定制订单页要求 `customMeta` 存在；我的页面只统计 `status: 'received'`。

**新增兑换单的字段约定**：若以后新增其它兑换类记录，请沿用 `source: 'exchange'`（或新增 `source` 取值并同步本表过滤清单），避免再次混入藏品订单。
