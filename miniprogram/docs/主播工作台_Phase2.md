## 硬切割

- 禁止挂接工作室 `purchase-ops` / `shipment-ops` / `studio-bills`、投资/股东观测台写能力。  
- 全店内容开关、LIVE_* 环境变量、人员花名册仍在**超管**侧；主播台只消费结果并给出可执行提示。  
- 稳定期：不改 C 端下单/支付契约；挂车加购仍复用现有确认下单旁路。

## 入口与身份

| 身份 | 如何进 | Hub 表现 |
|------|--------|----------|
| `live_host` | 「我的」主播瓷砖 | 主播模式；主路径全开 |
| 超管 | 同瓷砖或超管台深链 | 「超管预览」芯片；可结束对方场次 |
| 店长（`manageLive`） | 有权限时 | 「店长代播」芯片 |
| 其他员工 | 无入口 / 深链被拒 | toast 后回退 |

## 人眼验收

1. 主播 → 主播工作台 → 流程条 + 下一步卡可读。  
2. 新建场次 → 挂品 → 开播控制台（真机推流）。  
3. 未配 LIVE_* / 未开 showLive → 黄条说明，不假装在播。  
4. 同事在播 → 占场提示；仅超管可结束对方。  
5. 无法从本台进入工作室账本页。

## 稳定期说明

未改 `makeOrder` / `payOrder` / `payCallback` / 礼赠 / 登录契约。观众观看与挂车购买行为保持既有 `manageLiveSession` 响应形态。
