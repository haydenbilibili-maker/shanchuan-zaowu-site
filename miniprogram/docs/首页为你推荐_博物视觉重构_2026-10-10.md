# 首页「为你推荐」博物视觉重构（2026-10-10）

> 产品负责人原话：「总感觉为你推荐模块的交互和视觉比较潦草、不高级，需要对这个模块进行一个样式重构，
> 要求质感是第一位的，博物视觉，视觉风格应该是这个模块的第一优先级。」
>
> 点名范围 = **首页「为你推荐」的展示层**。前几版口径见 `首页为你推荐_全面升级_2026-09-27.md`（理由诚实、分页、比例分档、三态、埋点），本次**全部沿用**。

## 1. 现状与范围

- 只出现在**首页**：`pages/index` 挂主包组件 `components/HomeReco`（取数、三态、换一批、埋点都在组件里）。
  购物车页底部的「为你推荐」是另一段独立列表（电商链路，本次不动）。
- 数据：`getRecommendations({ limit })` + 用户兴趣标签（`users.interestTags`）+ 近 14 天玩过祈福墙时的祈运件；一页 3 件（主推 1 + 次推 2），
  「换一批」= 翻到下一页（swiper 横移），末页循环补齐。
- 埋点：`home_reco_expose`（每页进入视口一次）、`home_reco_click`；点击交给首页 `goToDetail` 进商品详情。
- **本次不动**：推荐算法、云函数入参出参、埋点事件与字段、跳转目标、共享件（`utils/imageUrl` 等）、首页页面文件。

## 2. 改前的问题（真机截图 + 渲染台复现）

1. 标题中英同一行，像通用电商的区块头；「换一批」是描边胶囊，抢戏；
2. 推荐理由是一行金字，没有身份感；
3. 主推卡竖图被夹在 570 高里（9:16 宽 360 还要裁），右栏编号 / 名称 / 卖点 / 价格松散堆叠，「去看看 →」描边胶囊显廉价；
4. 次推卡只有「诗意名 / 名称 / 价格」，没有编号与分类，层级弱，和主推卡不是一套语言。

## 3. 设计：展窗 + 展签

**语言**：博物馆展窗里的展品 + 展签。少圆角（6rpx 近直角）、细金线、衬纸感底（CSS 点阵 + 暖色斜光，不用图片）、克制阴影，
字重以 500 为主、靠字号与字距分层，不靠加粗。

- **标题区**：英文 `FOR YOU` 大写小字在上、中文「为你推荐」在下（两行，本仓规范）；底部一道由金渐隐的发丝线。
  「换一批」改成**文字按钮 + 小环形箭头**（CSS 画，不依赖字体）：点一下图标转一圈、展签淡入；下拉刷新取数时图标持续转、文字变「更新中」。
- **策展手记**：推荐理由前加「策展手记」小标，左侧一道金色竖线，正文用衬线体浅金色；最多两行，不硬截。
- **主推卡（展窗）**：封面恒高 570 → **640**，按图片比例两档不变：
  - 横图（线上 58%）：图在上 686×430（3:2 只裁约 6%），展签在下 210；
  - 竖图（线上 38%）：图在左，宽 = 640 / 比例，夹在 360–420 → **2:3 与 9:16 都几乎不裁**（改前 9:16 要裁 10%）。
  - 图内 12rpx 处一道浅色细框（展柜玻璃 / 衬纸的意思），展签右上角一枚金色角标。
  - 展签秩序：`No.01 ——— 分类 · 孤品` / 诗意名（衬线大字，金）/ 名称 / 学名斜体 / 卖点 / 细线 / 价格 + 「查看展品 ——」。
    价格改为中等字重的等宽数字，行动入口改为文字 + 细长线，不再是胶囊。
- **次推卡**：统一展签层级：`No.02 · 分类 ··· 孤品` / 诗意名（无则学名）/ 名称两行定高 / 细线 + 价格 + 短金线。图 1:1，同样有内框。
- **节奏**：主推与次推间距 20，两卡间距 18；每格同一套边框、底纹、圆角。
- **按压**：卡片 `tap-press-soft`、按钮 `tap-press`（app.wxss 全局），`hover-stay-time="80"`；组件已 `addGlobalClass`。
- **骨架**：`ui-sk-card` + `ui-sk-line`，与真卡同几何（封面 640 / 次推 578），数据到达不跳高。

## 4. 缺字段与少量推荐

- 无诗意名：主推卡名称升为大字；次推卡改显示学名；都没有时该行留空（两卡仍对齐）。
- 无学名 / 卖点 / 分类 / 孤品标：对应行不渲染（`wx:if`），不留「—」之类占位。
- 长文本：诗意名 / 名称两行、卖点四行（竖档）、横档单行省略，不溢出。
- 推荐 2 件 = 只两列；1 件 = 只主推卡；swiper 按版式收高（沿用 §8 口径）。

## 5. 几何与体积

- swiper：满页 640 + 20 + 578 = **1238**；只两列 578；只主推 640。改任一项同步骨架与渲染台。
- 主包（推荐线 1.5M）：改前 1,494,542 B → 改后 **1,496,987 B**（净 +2,445 B，余 3,013 B）。只改本组件；WXSS 用局部变量收短重复色值、合并多行截断规则、删装饰性注释与「策展手记」换页淡入后的结果。
