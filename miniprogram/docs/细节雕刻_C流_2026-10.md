# 细节雕刻 · C 流（员工与管理端）· 2026-10

> 产品负责人 2026-10-01：小程序 1.1.5 进入超级稳定阶段，接下来做**细节雕刻**（交互、视觉、排版、文案、动线与丝滑度），三条并行流多轮自主优化。
> 本文件只记 **C 流：员工与管理端**（超管 / 店长工作台及其功能页、店员端、b2bdesk）。
>
> **稳定期纪律**：「后台」属稳定期模块。本流只动展示层与体验层；不改契约（字段 / 集合 / 云函数出入参与 `success` 语义）、
> 不改流程 / 状态机 / 权限判断 / 金额计算、不改共享件行为、不改生产数据。需要动这些的，列入文末「需产品负责人点名」。

> 守卫：`npm run check:c-stream-polish`（manager 域，含 `--selftest` 内存注入，每轮追加断言、条目只占一条）。

### 改动

1. **首屏骨架**：工作台首页（问候行 / 扫码主按钮 / 常用磁贴形状）与功能模块页（页头 / 筛选条 / 三张卡）改为骨架，样式 `wb-sk-*` 放在 `manager/index.wxss`（workspace 经 `@import` 共用，与 `ops-skeleton` 同节奏）。
2. **账本加载态**：`ledgerOverviewReady` 为假时总览位给骨架、旧流水压暗（`.revenue-list.is-stale`）；空态改为数据就绪后才出现。
3. **账本空态**：文案带月份「2026年10月还没有入账记录」+ 金色描边「记一笔」直达；去掉整块半透明，字色改 `--color-text-secondary`。
4. **账本细节**：票据卡标签 16 → 20rpx、`#888 → #777`（米白纸底对比度约 4.1:1）；「退款｜REFUND」→「退款｜门店」；记一笔 / 商城对账 / 删除加按压态；云端失败改为「账本暂时没取到，请检查网络后下拉刷新」（只换提示文案，取数逻辑不动）。
5. **订单空态下一步**：5 档空态统一加「清除搜索」（有关键词时）/「看全部日期」（按 7 / 30 日筛空时），直接调用既有 `clearOmQuery` / `setOmDays`；5 档切换加按压态；「待支付」空态改为「顾客已付款但订单仍停在待支付时，超管可在此补履约」。
6. **审批中心**：首屏骨架（`!ready`）+ 列表首次加载骨架；提交中（既有 `deciding`）整排按钮压暗且不可再点、催办同理；「通过」进入二次确认时描边加亮；三枚决策按钮加 `hover-class`；底部「加载中…」只在翻页时出现。
7. **审批文案**：「超时 N 条 · SLA 24h」→「超时 N 条 · 时限 24 小时」、「SLA 内」→「时限内」、「暂无更多字段」→「没有更多信息」。
8. **工作台首页**：「（不含mp）」→「（不含小程序订单）」；「编辑」「取消 / 收起」「上移 / 下移 / 移除」与常用面板芯片加按压态（`text` 不支持 `hover-class`，改为 `view`，类名与事件不变）。
9. **店员工作台**：错字改为「暂时没有可用的现场功能」+「开通后下拉刷新即可」；场景卡加 `hover-class="link-btn-press"`（样式写在 `staff/index.wxss`，不动双副本 `scene.wxss`）。

### 改动

1. **核销验票按压态**：页内全部操作按钮加 `hover-class`（`btn-outline-press` / `btn-ghost-press` / `btn-primary-press`）；「重选」由 `text` 改 `view`（类名、事件不变）。
2. **列表加载骨架**：待自取 / 待核销预约加载时出两行骨架（`.field-sk-*`，形状对齐 `.row`），不再一行字。
3. **提交中文字**：「试算积分 → 试算中…」「确认赠分 / 提交审核 → 提交中…」，绑定既有 `previewing` / `granting`，不新增状态。
4. **空态下一步**：待自取 / 待核销空态补一句提示；流水空态「今天还没有赠分记录」+「去消费赠分」（调用既有 `switchTab`，idx 0）。按钮另起一行居中（`.empty .empty-next`）。
5. **店员子页**：打卡「打卡中…」、请假 / 报销「提交中…」、门店清单「保存中…」、两个审批页「通过」→ 当前条「处理中…」（绑定既有 `reviewingId`），驳回 / 通过 / 行卡片 / 缩略图添加位加按压态。
6. **日报详情**：删正文那组重复的「复制 / 分享摘要」，只留底部一处（`dg-tools` 样式同删）。
7. **低频页文案**：客服配置「顾客端只读取『启用』中优先级最高的一条；一条都没有时使用系统默认设置」；飞书同步「飞书凭据还没配置」「默认关。开启后每天 03:30 自动拉取一次；关闭则只靠下方手动同步」；工资条后台「保存时会记录操作人」；报表「分时段分布暂无数据源（目前只按营业日统计）」。
8. **死样式净减**：`manager/index.wxss` 删 43 条零引用规则（−4.6 KiB，`.link-*` 因 rpx 白名单保留）；`extra` 的会员 CRM（18 条）、工匠分成（7 条）、直播开播（5 条）共删 30 条（−3.2 KiB）。判死口径：复合选择器**首个类名**在本页目录 + `extra/components` 的 wxml / js / json 零出现，且不被 `xx-{{}}` / `'xx-' +` 动态前缀覆盖；`.pill.ignored` 这类修饰类可能来自库里的状态值，一律不删。
