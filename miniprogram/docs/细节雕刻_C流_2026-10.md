### 给 A 流的共享层建议

1. **全局按压态类**：本流在 7 个文件里各定义了一份同值的 `.wb-press { opacity: .72 }`（各分包公共样式 + 不引公共样式的页面）。建议 `app.wxss` 提供一条全局 `hover-class` 用类（如 `.tap-press`），各页直接引用即可，分包里的副本届时可删。
2. **全局骨架原语**：`wb-sk`（工作台）/ `field-sk`（核销）/ `ir-sk`（发票）/ `ap-sk`（审批）四套骨架都是「一条 `--color-bg-elevated` 圆角条 + 1.2s 呼吸」。建议 `app.wxss` 出 `.sk-line` / `.sk-line.wide` + `@keyframes sk-pulse`，统一节奏与色值。
3. **组件约定**：`text` 不支持 `hover-class`，可点元素一律用 `view`；建议写进组件 / 样式规范，并在 `lint:wxml` 里对「`text` 上挂 `bindtap`」给出提示。
4. **灯语图例**（`signal-legend` / `signal-light`）目前来自全局样式，离线预览拿不到；如 A 流整理全局 token，建议把它们一并纳入预览可读取的范围。
