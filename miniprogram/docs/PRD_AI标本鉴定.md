## 2. 背景与问题陈述

### 2.1 业务诉求

AI 标本鉴定不应只是「附属工具页」，而应成为山川造物 C 端的**差异化能力标签**：

1. **降低认知门槛** — 用户不必先懂分类学，也能通过一张照片进入「博物世界」。
2. **串联内容 + 电商** — 鉴定结果自然导向馆藏档案（`cms_wikis`）与可购藏品（`products`），完成「好奇 → 了解 → 收藏/购买」闭环。
3. **沉淀用户资产** — 「我的自然图鉴」让每次鉴定可留存、可分享、可复访，提高 LTV。
4. **反哺内容与选品** — 用户纠错、高频物种、关联缺口，为运营与标本师提供数据输入。

### 2.2 现状诊断（基于代码 · 2026-05）

#### 已实现能力 ✅

| 能力 | 实现 | 说明 |
|---|---|---|
| 拍照 / 相册选图 | `pages/identify/index` | 压缩 ≤2MB、上传云存储、进度条 |
| 视觉识别 + 科普 | `identifySpecimen` | DashScope 多模态 + 文本生成；低置信度降级文案 |
| 同图缓存 | `identification_cache` | 同用户同图 hash 跳过重复 API 调用 |
| 结果展示 | `SpeciesCard` + 结果页 | 物种信息、分类、置信度、科普正文 |
| 关联推荐 | 云函数内 | `species_product_map` + 商品/百科模糊匹配 |
| 图鉴收藏 | `user_collection` | 结果页「保存到我的图鉴」 |
| 纠错反馈 | `identification_feedback` | 用户提交正确中文名 |
| 分享 | 小程序转发 + Canvas 海报 | `generateSharePoster` + 小程序码 |
| 埋点 | `trackBehavior` | `identify_start/success/result_view/save_atlas/to_product/to_wiki/to_gallery` |
| 专员咨询 | `getSupportConfig` | 支持「鉴定疑问」类型 |

#### 关键缺口 ❌

| 维度 | 现状 | 问题 |
|---|---|---|
| **入口曝光** | 仅「我的」菜单一项 | 探索首页、馆藏 Tab **无主入口**；用户难以发现该能力 |
| **品牌体验** | 功能页可用，但非「博物馆级」高光 | 缺铜牌标本信息区、分类树可视化、品类色体系对齐 |
| **转化链路** | 有关联则展示，无则空白 | 无「同馆推荐 / 定制咨询 / 预约到店确样」兜底 CTA |
| **图鉴体系** | Tab 仍为「昆虫/植物/矿物/海洋生物/其他」 | 与 `categories` 六馆白名单**未对齐** |
| **触达闭环** | `identify_result` 模板已定义 | `identifySpecimen` **未调用** `sendInAppMessage` |
| **数据隔离** | `loadRecent` 查全表最近 5 条 | **未按 `_openid` 过滤**，存在隐私风险 |
| **知识增强** | `species_knowledge` 可选读取 | 与 `cms_wikis`、六馆分类 **未形成 RAG 标准链路** |
| **运营闭环** | `identification_feedback` 仅落库 | 无店长/ERP 审核 → 知识库回写流程 |
| **会员 / 配额** | 无 | 无法做「免费 N 次 / 会员无限次」等运营策略 |
| **门店 O2O** | 无 | 未与门店签到、实物标本 QR、标本师确样打通 |

**结论**：技术底座已具备 MVP，下一阶段目标是 **「可见 → 可信 → 可转化 → 可运营」** 四段式升级。

## 3. 产品定位

### 3.1 一句话定位

> **AI 标本鉴定 = 山川造物口袋里的「博物鉴定室」—— 拍一张照片，获得一枚带铜牌标注的自然档案，并看见与之相关的馆藏与藏品。**

### 3.2 与竞品的差异（对内共识）

| 维度 | 通用识图 App | 山川造物 AI 鉴定 |
|---|---|---|
| 识别对象 | 泛植物 / 泛动物 | **标本、藏品、自然物**（含矿石、干花、贝壳等） |
| 输出形态 | 标签 + 百科摘抄 | **博物叙事**（形态 / 习性 / 分布 + 冷知识）+ 品牌语调 |
| 后续路径 | 广告 / 社区 | **馆藏档案 → 可购藏品 → 图鉴沉淀 → 门店确样** |
| 视觉气质 | 工具白底 | **Museum Mode** 暗色 + 黄铜金铜牌语义 |

### 3.3 与相邻模块分工

| 模块 | 关系 |
|---|---|
| **馆藏 Tab** | 鉴定结果「去馆藏看同类」跳转；馆藏内容反向可引导「拍一张试试 AI 鉴定」 |
| **我的自然图鉴** | 鉴定结果的个人资产库；与成就 / 会员成长值可联动 |
| **山海有信** | 鉴定完成站内信；低置信度时可推送「预约标本师确样」 |
| **标本定制 / 联系专员** | 识别到保护物种或无法确种时，引导合规咨询与定制 |
| **门店模块** | 到店扫码标本 → 带上下文鉴定；签到后推送「现场鉴定体验」 |

### 3.4 北极星指标（建议）

| 指标 | 定义 | M1 目标 **【待确认】** |
|---|---|---|
| **鉴定启动率** | 进入鉴定页 UV / 小程序 DAU | ≥ 8% |
| **鉴定完成率** | 成功出结果 UV / 发起识别 UV | ≥ 75% |
| **结果 → 图鉴保存率** | 保存图鉴 UV / 结果页 UV | ≥ 25% |
| **结果 → 商详 CTR** | 点击相关藏品 UV / 结果页 UV | ≥ 12% |
| **结果 → 馆藏 CTR** | 点击档案或「看同类」UV / 结果页 UV | ≥ 18% |
| **分享率** | 分享 / 海报保存 UV / 结果页 UV | ≥ 10% |
| **7 日复鉴率** | 7 日内再次鉴定用户 / 首次鉴定用户 | ≥ 20% |

## 4. 目标用户与核心场景

| 用户 | 场景 | 期望路径 |
|---|---|---|
| **自然新手** | 在公园 / 市集看到昆虫或矿石，好奇是什么 | 探索页入口 → 拍照 → 读懂故事 → 保存图鉴 |
| **送礼买家** | 想确认某标本「到底是什么」再下单 | 商品详情「拍实物对比鉴定」→ 结果页相关藏品 → 下单 |
| **复购藏家** | 已有多枚鉴定记录，想整理分类 | 图鉴按六馆浏览 → 点进历史结果 → 跳转馆藏补货 |
| **亲子 / 研学** | 门店或活动后延续兴趣 | 门店扫码 → 鉴定 → 分享海报 → 同学扫码进入 |
| **存疑用户** | AI 结果不确定 | 低置信度提示 → 纠错 / 联系专员 / 预约到店确样 |

## 5. 设计原则

1. **Specimen First** — 优先识别「标本 / 自然物」，非标本图诚实降级，不硬编物种名。
2. **Museum Plate** — 结果页核心信息区采用「铜牌标注」语义（中文名宋体、拉丁名斜体、产地 / 分类）。
3. **Trust by Transparency** — 展示置信度与「仅供参考」说明；低置信度给明确下一步（重拍 / 确样）。
4. **Content → Commerce** — 每条有效鉴定至少提供一条去向：档案、商品、馆藏分类或定制咨询。
5. **Privacy by Default** — 鉴定记录、最近列表、图鉴 **默认仅本人可见**。
6. **Cost Aware** — API 调用可缓存、可配额；避免无限免费刷量 **【待确认配额策略】**。

```
探索 / 我的 / 馆藏（引流入口）
        ↓
  AI 标本鉴定（pages/identify）
   ├─ 拍照 / 相册
   ├─ 拍摄指引（角度 / 光线 / 主体）

        ↓
  鉴定结果（pages/identify/result）
   ├─ 铜牌物种卡（SpeciesCard 升级）

   ├─ 馆藏档案（cms_wikis）
   ├─ 相关藏品（products）
   ├─ 行动区：保存图鉴 / 去馆藏 / 分享 / 纠错 / 确样咨询
   └─ 低置信度：重拍引导 + 备选候选（M2）
        ↓
  分享海报（pages/identify/share）
  我的自然图鉴（pages/collection · 六馆 Tab）
```
