## 2. 设计结论

**一句话**：把「一串横滑方卡」改成**一张展签大卡 + 三件一组**的策展编排，头部用一句**真话**说清为什么推荐给你，
理由不足时优雅回退成「馆里今天的精选」；三态齐全、可换一批、有曝光/点击埋点，并把推荐点击的兴趣标签补回服务端。

### 2.1 版式

```
为你推荐  FOR YOU                                   换一批 1/3
按你常看的「闪蝶」「甲虫」挑的                               ← 为什么（hr-why）
┌──────────┬─────────────────────────────┐
│          │ No.01 · 常看 · 闪蝶            │  ← 展签大卡（hr-lead）
│  3:4 图  │ 蓝闪蝶原木标本框（衬线 2 行）     │     图 → 名 → 寓意/学名 → 价格
│          │ 「海上月光」一整片南美雨林的蓝…    │
│          │ Morpho menelaus               │
│          │ ¥388                 去看看 → │
└──────────┴─────────────────────────────┘
┌────────┐ ┌────────┐ ┌────────┐            ← 三件一组（hr-row / hr-card）
│ 3:4 图 │ │ 3:4 图 │ │ 3:4 图 │               小标叠在图左上（理由，可缺省）
│ 名     │ │ 名     │ │ 名     │
│ 寓意   │ │ 寓意   │ │ 寓意   │
│ ¥168   │ │ ¥99    │ │ ¥128起 │
└────────┘ └────────┘ └────────┘
依据：你的浏览标签与祈福墙记录              逛全部藏品 →
```

- **统一比例 3:4**（与「最新入库」`ProductCard` 同比例），**去掉压暗滤镜**；
- 层级：图 → 名（标准名 `title`，衬线）→ 寓意（`themeName` 以「」包裹 + `themeNote`；没有则学名斜体）→ 价格（DIN 黄铜，多规格「起」）；
- **1 + 3 编排**与下方双列商品流、上方横滑拉开节奏：推荐区是"策展"，商品流是"货架"；
- 色彩只用 `app.wxss` 令牌（博物黑 / 卡片 `#1F1D1A` / 黄铜 `--brass-*`），与首页 section 头（`t-cn`/`t-en`）同一套。

### 2.2 「为什么推荐给你」（诚实优先级）

| 条件 | 头部一句 | 卡片小标 |
|---|---|---|
| 兴趣标签与**本页展示的商品**真有重合 | 按你常看的「A」「B」挑的 | 命中的那件：常看 · A |
| 服务端给了 `相近标签` 但本地没算出命中 | 按你近来看过的藏品挑的 | 与你所看相近 |
| 近 14 天玩过祈福墙玩法且开关开 | 你来过祈福墙 · 这面墙偏「求财」，配了几件 | 祈运配的那件：马上有 · 求财 |
| 以上都没有（冷启动） | 还在认识你 · 先看馆里今天的精选 | 只用事实：孤品 / 新藏（否则不显示） |

硬口径：**不编造社会证明**（没有「同好也在看」「大家都在买」）、不显示「同品类推荐」「智能推荐」这类空话；
小标只写**我们真的知道的事**。

### 2.3 交互与三态

- **加载**：骨架与真卡同几何（展签大卡 + 三件一组），数据到达不跳高；下拉刷新时保留旧内容，只在「换一批」处转圈；
- **失败**：模块不消失，原位显示「推荐没能送到 · 轻点重试」（`hr-error` + `hr-retry`）；
- **空**：「馆里正在上新 · 先去逛逛全部藏品 →」；
- **换一批**：一次取「后台首页配置 · 推荐显示数量」件（1–20，未配置时 12）+ 祈运最多 2 件，4 件一页、循环翻页（`1/3`）；
  翻页只在本地切页，不额外打云；
- **到底**：底栏「逛全部藏品 →」切到馆藏 Tab。

### 2.4 埋点

- 新增 `home_reco_expose`（模块进入视口、每页一次；targetType=`reco`，targetId=依据 `interest|personal|wall|cold`，properties 带本页 ids）；
- 新增 `home_reco_click`（targetType=`product`；properties：`pos`、`mode`、`chip`）；
- 推荐卡点击仍经页面 `goToDetail` 上报 `product_view`，但**把 `category/tags` 带上**（修 §1-7）。**不改 `product_view` 语义**。
- 两个新事件双端登记：`miniprogram/utils/analytics/eventSchema.js` ↔ `admin/src/utils/analyticsSchema.js`（`check:analytics-schema` 守）。

### 2.5 落点与体积

- 新组件 **`components/HomeReco/`（主包）**：`index.*` + 纯逻辑 `logic.js`（渲染台与守卫直接跑它）。
  产品负责人 2026-09-27 补充口径「主包 1.5M 是推荐，2M 以内可以」→ **不走分包异步化**（避免占位闪烁），首屏最稳；
- 首页删除旧推荐 WXML / WXSS（`.recommend-*` `.rec-*` `.sk-rec-card`）与 `loadRecommendations` 取数；`loadModuleData('recommendations')`
  仍返回成功（组件自取数），**保持首页整页错误态的原有判定不变**；
- 主包体积守卫同日改口径：硬线 1,950,000（微信 2M − 余量），1,500,000 为推荐线只警告（见 `check-main-package-size.mjs` 头注释）。

## 3. 需产品负责人点名的改动（本次未做）

1. **服务端返回推荐依据**：`getRecommendations` 目前只回 `相近标签/同品类推荐/为你推荐` 三个粗粒度理由，
   冷启动也给「同品类推荐」。若要做「因为你看过 X」（精确到某件藏品），需要云函数回包带上依据（命中的标签/来源商品 id）—— 改出参 = 电商链路契约。
2. **冷启动理由修正**：热门兜底路径的 `reason` 应为「馆藏精选」而不是「同品类推荐」（改云函数输出语义）。本次客户端**不展示**这类理由，规避了误导。
3. **购买信号**：已购商品的同系列/配件推荐需要读订单，属电商链路。
4. **会员价**：列表卡全站不展示会员价；如要在推荐卡显示「会员 ¥x」，需复用会员价计算共享口径并统一到 `ProductCard`。
5. **`product_view` 双计**：推荐/商品流点击在首页报一次 `product_view`，详情页 `onLoad` 再报一次（既有行为，非本次引入），兴趣权重被放大一倍；是否去重需点名（埋点已有语义）。
6. **后台「推荐算法」选项未生效**：ERP 首页配置里的「推荐算法」下拉写进了配置，但 `getRecommendations` 从不读取（既有现象）；
   要么云函数按它分支，要么后台隐藏该项 —— 两者都需点名。
7. **`guards/_meta.json` 的历史说明**：`_minGuardsNote` 原写「主包 <1.5M」，本次已按新口径补写（meta 属跨流，已单列报备）。
8. **推荐卡收藏心心**（二版评估）：收藏只在详情分包 `toggleFavorite` 里有页面内实现（含售罄走「想要」候补等规则），
   主包没有可复用的共享收藏件；要在首页卡上收藏，需先把它抽成共享件（动电商链路的详情页），且首页还得先查一遍收藏状态 —— 需点名。
9. **祈运件的场景名**：`getBlessProducts` 场景兜底行只回 `matchSource:'scene'`，不回命中的是哪个礼赠场景；
   若要写「来自祈福墙 · 乔迁」这类更具体的话，需云函数回包带场景名（改出参）。

## 4. 人眼验收清单（按二版 + 三版封面，见 §6 / §7）

1. 首页下滑到「为你推荐」：一格展柜封面 + 两列。**横图**（多数 3:2 商品图）封面图满宽、展签在图下方一条；
   **竖图**（2:3 / 3:4 / 手机竖拍）图贴左占满高、展签竖排在右、价格沉底；**两种封面同高**，左右滑动时下方两列不上下跳；
   展签**不压图**，封面里没有大片虚化空底；
1a. 首次打开（清缓存）封面先是一块走光占位，约一瞬后出图、不会先出错档再跳；第二次进入直接出正确版式（比例已缓存）；
1c. 一直左滑到最后一页：**每页都是封面 + 两列满 3 件**；推荐总数不是 3 的倍数时，末页用第 1、2 件补齐（编号仍是 No.01 / No.02）；
    推荐只有 1 件时只显示封面、2 件时只显示两列，下方都没有空白；
1b. 两列小卡里的竖图，裁切偏上（标本头部 / 上半保留）；图片出来的一瞬可能有轻微上移（比例到达后切到偏上裁），可接受；
2. 推荐理由**只在头部说一次**：卡上没有「常看 · X」角标、底部没有「依据：…」；图上除保护徽标外不压任何字；
3. 头部一句与账号实际相符：新账号为「还在认识你…」；多看几件闪蝶后下拉刷新，出现「按你常看的「闪蝶」…」；
4. 祈福墙开关开、玩过摇签后回首页下拉：两列右格出现写「来自祈福墙」的祈运件；只有该商品真打了「求财」祈运标签才写「来自祈福墙 · 求财」；
5. 左右滑动换页有横移过渡、下方页码点跟着走；点「换一批 ›」同样横移到下一页，末页回第一页；**换页时页面不跳、滚动位置不动**；
6. 两列标题最多两行、两张卡等高；按下卡片有轻微缩放；
7. 断网后首次进入：推荐区显示「推荐没能送到 · 轻点重试」，恢复网络点它能出内容；
8. 点任一推荐卡进入正确详情；返回后祈福墙入口、马上有展签、灵动球、最新入库等其它区块不受影响；
9. 敏感藏品仍走模糊门（封面图被门遮住），保护徽章照常显示（封面左上 / 小卡左下）。
10. 封面图在真机上清晰（尤其横图满宽封面，放大看羽毛 / 鳞片细节不糊）；小卡加载速度与之前相当；
11. 竖图封面右栏：价格上方有一道细线，「去看看 →」是描边小按钮；页码点右侧显示「1 / 4」，滑动 / 换一批后同步变化；

13. 打开读屏（iOS 旁白 / 安卓 TalkBack）：聚焦封面或小卡会读出藏品名称并提示为按钮。

## 6. 二版：交互视觉再升级（2026-09-27 晚，真机截图反馈）

### 6.1 问题复核（真机截图 + 渲染台复现 `.tmp/home-reco-0927b/before-*.png`）

1. **同一件事说三遍**：头部「按你常看的「玻璃罩装」「大蓝闪蝶」挑的」+ 每张卡「常看 · X」角标 + 底部「依据：你的浏览兴趣」；且角标压在图上挡展品。✔ 属实
2. **大卡裁图、右侧空**：大卡左图固定 270×360（3:4）aspectFill，手机竖拍（≈9:16）的孔雀被裁掉头尾；右栏只有 4 行字，下半空。✔ 属实
3. **三列太挤**：每件 ≈216rpx 宽，标题单行 ellipsis（「大蓝闪蝶贝壳…」）。✔ 属实
4. **「马上有 · 求财」贴错**：`getBlessProducts` 的行分两种 —— 显式打了 `fortune` 标签（`matchSource:'tag'`）与靠礼赠场景兜底命中（`'scene'`）；

- **理由只说一遍**：头部那一句是唯一的推荐理由；卡上**不再有理由角标**，底部「依据」删除。卡上只保留**这件东西本身的事实**小字

## 8. 每页满员：末页循环补齐 + 总数 < 3 降级（2026-09-28，真机截图「第四批只有主图」）

### 8.1 根因

`logic.buildView` 按 `PAGE_SIZE = 3` 直接 `slice` 切页：推荐 10 件 → 3+3+3+**1**，第 4 页只有封面、`row` 为空；
swiper 定高 1120（为满页设计）→ 下方空出 532rpx。凡总数不是 3 的倍数都会出现（余 1 空两格，余 2 空一格）。

### 8.2 策略

- **≥ 3 件：每页永远满 3**，页数 = ⌈n/3⌉。末页不足时**从列表开头循环补齐**（n=10 末页 = No.10 + No.01 + No.02）。
  末页起点下标 ≥ 3、最多补 2 件（取下标 0/1），**天然不会页内重复**。
  选它而不是「丢余数」：丢余数会让第 10 件永远不露出；均摊会让页型不一（有的页 4 件）破坏定高。
- **补位件**：`dup: true`；**No.xx 与 `pos` 沿用原件**（同一件藏品在任何页编号一致，点击走原位）。
- **2 件**：`layout = 'row'`，不画封面，两件走两列（避免封面 + 半边空白单卡）；swiper 收到 532。
- **1 件**：`layout = 'lead'`，只画封面；swiper 收到 570；不画空两列行。页码点 / 「换一批」在单页时本就不显示。
- **曝光口径**：`home_reco_expose` 仍「每页进入视口一次」（页级计数不变）；事件里的 `ids` **只列本次加载首次露出的件**
  → 翻到末页时补位的 No.01/No.02 不会再被计一次商品曝光。下拉刷新 / 重试开启新一次加载（`_seq`）后重新计。
  点击 `home_reco_click` 的 `pos` 为原件位置，与首次露出时一致。
- 不变：云函数契约、埋点事件名与字段、比例分档、三态。加载中骨架仍按满页画（总数 < 3 时数据到达会收高一次，属罕见情况）。
