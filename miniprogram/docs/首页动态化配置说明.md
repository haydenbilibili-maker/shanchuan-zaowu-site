# 首页内容动态化配置说明

## ✅ 功能概述

首页内容动态化功能已完成，支持：
- ✅ 模块顺序配置
- ✅ 模块显示/隐藏控制
- ✅ 每个模块的数量、排序等参数配置
- ✅ 配置缓存机制（24小时）
- ✅ 默认配置降级

## 📋 部署步骤

### 1. 部署云函数

在微信开发者工具中：

1. **部署 getHomeConfig**
   - 右键点击 `cloudfunctions/getHomeConfig` 文件夹
   - 选择"上传并部署：云端安装依赖"
   - 等待部署完成

### 2. 创建数据库集合

在云开发控制台：

1. 进入"数据库" → "集合管理"
2. 创建新集合：`home_configs`
3. 设置权限：
   - 所有用户可读：是（小程序需要读取配置）
   - 仅创建者可读写：是（后台管理需要写入）

### 3. 添加配置数据（可选）

如果不添加配置，系统会使用默认配置。

**配置数据结构**：
```javascript
{
  status: 'active',        // 'active' | 'inactive' | 'draft'
  priority: 1,             // 优先级，数字越大越优先
  version: '1.0.0',        // 配置版本号
  modules: [               // 模块配置数组
    {
      id: 'banners',        // 模块ID
      name: '轮播图',       // 模块名称
      enabled: true,       // 是否启用
      order: 1,            // 显示顺序（数字越小越靠前）
      config: {            // 模块特定配置
        limit: 5,          // 显示数量
        autoplay: true,    // 自动播放
        interval: 6000     // 轮播间隔（毫秒）
      }
    },
    {
      id: 'categories',
      name: '分类球',
      enabled: true,
      order: 2,
      config: {
        limit: 4,          // 显示数量
        showAll: false
      }
    },
    {
      id: 'collections',
      name: '专题展览',
      enabled: true,
      order: 3,
      config: {
        limit: 10,
        sortBy: 'createTime',
        sortOrder: 'desc'
      }
    },
    {
      id: 'framers',
      name: '名师手作',
      enabled: true,
      order: 4,
      config: {
        limit: 6,
        sortBy: 'createTime',
        sortOrder: 'desc'
      }
    },
    {
      id: 'activities',
      name: '近期活动',
      enabled: true,
      order: 5,
      config: {
        limit: 5,
        status: 'open',    // 活动状态筛选
        sortBy: 'date',
        sortOrder: 'asc'
      }
    },
    {
      id: 'recommendations',
      name: '为你推荐',
      enabled: true,
      order: 6,
      config: {
        limit: 8,
        algorithm: 'mixed' // 'mixed' | 'hot' | 'personalized'
      }
    },
    {
      id: 'newArrivals',
      name: '最新入库',
      enabled: true,
      order: 7,
      config: {
        limit: 10,
        sortBy: 'createTime',
        sortOrder: 'desc'
      }
    }
  ],
  updatedAt: new Date(),   // 更新时间
  _createTime: new Date(), // 创建时间
  _updateTime: new Date()  // 更新时间
}
```

## 🖼 轮播图 `banners` 集合（CMS）

首页 Hero 轮播读取云库集合 **`banners`**（`orderBy('sort', 'desc')`），与店长后台「装修 / Banner」、Admin「首页轮播配置」同一套文档。图片请用云存储 **fileID**（`cloud://...`），不要把大图打进主包。

标本师招募与其它 banner **完全相同**：在集合里新增一条即可。客户端**不会**再硬编码插入招募轮播；本地 `/assets/banners/framer-recruit.jpg` 已弃用。

`getHomeConfig` 会幂等写入一条 `_seedKey: banner_framer_recruit` 的示例（仅当库中尚无任何招募相关 banner 时），字段含 `enabled: true`。运营可在 Admin/店长后台关闭 `enabled`，或直接删除该条。

**文档示例**（云开发控制台 → 数据库 → `banners` → 添加记录，或 Admin → 首页轮播 → 新增海报）：

```javascript
{
  id: 'framer-recruit',
  title: '标本师招募',
  subtitle: '把手艺带到更多柜门前',
  badge: '合作',
  image: 'cloud://cloud1-8gnkty5bfff9f0bf.636c-cloud1-8gnkty5bfff9f0bf-1387508856/banners/d225de57986a74fc592cc876cd09a4df-2524a3ca-bb99-481.png',
  // fileID 也可，客户端会读 image || fileID
  type: 'scheme', // product | category | booking | scheme
  target: '/subpackages/business/framer-recruit/index?from=home_banner',
  link: '/subpackages/business/framer-recruit/index?from=home_banner',
  sort: 80,       // 越大越靠前
  enabled: true   // false 则首页不展示，配置仍保留
}
```

字段说明：

| 字段 | 说明 |
|------|------|
| `image` / `fileID` | 云 fileID 或 HTTPS |
| `type` | `product` 商品 / `category` 分类 / `booking` 预约 / `scheme`（亦接受 `page`/`path`）功能页 |
| `target` | 商品 ID、分类关键词，或功能页完整 path（可带 query） |
| `link` | 小程序可 `navigateTo` 的完整 path；Admin/店长保存时会按 type 自动补齐（分类跳转无 link，客户端用 globalData + switchTab） |
| `title` / `subtitle` / `badge` | 轮播文案 |
| `sort` | 越大越靠前 |
| `enabled` | 缺省 true；设为 `false` 则首页过滤不展示 |

### Admin / 店长配置「标本师招募」步骤

1. 打开 **Admin → 首页轮播**，或小程序 **店长后台 → 装修**
2. 新增海报，上传招募图（建议 16:9）
3. 跳转类型选 **功能页**，常用入口选 **标本师招募**（路径 `/subpackages/business/framer-recruit/index`，可加 `?from=home_banner`）
4. 设置排序权重与「首页展示」开关后保存
5. 小程序下拉刷新首页（或清 `BANNERS` 缓存）即可看到

功能页常用入口与 `utils/bannerNav.js` / Admin `BannerManager` / 店长装修的 `SCHEME_PRESETS` 对齐，含：新用户注册、注册完成页、探索/馆藏/标本工坊/购物车/我的、山海图鉴、线下门店、预约到店、我的积分、我的钱包（含券夹；亦可深链「我的券夹」）、订单、订单认领、个人资料（生日礼）、伴宠记忆、联系专员、标本师招募、社区、养护、AI 鉴定等，末项仍为「自定义路径」。

配好后清小程序缓存即可看到云图。

## 🔧 工作原理

1. **配置加载**
   - 首页加载时，优先从缓存读取配置
   - 如果缓存不存在或过期，调用云函数获取配置
   - 配置缓存24小时

2. **模块渲染**
   - 根据配置的 `enabled` 字段决定是否显示模块
   - 根据配置的 `order` 字段决定显示顺序
   - 根据配置的 `config` 字段控制模块参数

3. **降级处理**
   - 如果配置加载失败，使用默认配置
   - 默认配置：所有模块启用，按默认顺序显示

## 🎨 前端实现

### 模块显示控制

在 `pages/index/index.wxml` 中，每个模块都添加了 `wx:if` 条件：

```xml
<!-- 轮播图模块 -->
<view class="hero-section" wx:if="{{showBanners}}">
  <!-- ... -->
</view>

<!-- 分类球模块 -->
<view class="section-box orbs-section" wx:if="{{showCategories}}">
  <!-- ... -->
</view>
```

### 配置应用

在 `pages/index/index.js` 中：

1. `loadHomeConfig()` - 加载配置
2. `updateModuleVisibility()` - 更新模块显示状态
3. `loadModuleData(moduleId)` - 根据配置加载模块数据

## 📊 配置管理建议

### 多版本配置

支持多个配置版本，通过 `priority` 字段控制优先级：

```javascript
// 高优先级配置（当前使用）
{
  status: 'active',
  priority: 2,
  modules: [...]
}

// 低优先级配置（备用）
{
  status: 'active',
  priority: 1,
  modules: [...]
}
```

### A/B测试

可以通过创建多个配置来实现A/B测试：

```javascript
// 配置A：推荐模块在前
{
  status: 'active',
  priority: 1,
  name: 'config_a',
  modules: [
    { id: 'recommendations', order: 3 },
    { id: 'collections', order: 4 }
  ]
}

// 配置B：专题展览在前
{
  status: 'active',
  priority: 1,
  name: 'config_b',
  modules: [
    { id: 'collections', order: 3 },
    { id: 'recommendations', order: 4 }
  ]
}
```

然后通过用户ID或其他条件来选择使用哪个配置。

## ⚠️ 注意事项

1. **配置缓存**
   - 配置缓存24小时，修改配置后可能需要等待缓存过期
   - 或者清除小程序缓存强制刷新

2. **默认配置**
   - 如果没有配置或配置加载失败，使用默认配置
   - 默认配置确保首页始终可以正常显示

3. **模块顺序**
   - 模块在WXML中的顺序是固定的
   - 配置中的 `order` 字段主要用于逻辑控制，实际显示顺序由WXML决定
   - 如果需要真正的动态顺序，需要重构WXML使用循环渲染

4. **性能考虑**
   - 配置缓存24小时，减少云函数调用
   - 配置加载失败不影响首页显示（使用默认配置）

## 📞 测试验证

1. **测试默认配置**
   - 不创建配置数据
   - 验证首页是否正常显示所有模块

2. **测试隐藏模块**
   - 创建配置，设置某个模块 `enabled: false`
   - 验证该模块是否隐藏

3. **测试数量限制**
   - 创建配置，设置 `limit` 参数
   - 验证模块显示数量是否符合配置

4. **测试配置缓存**
   - 修改配置数据
   - 验证是否立即生效（可能需要清除缓存）
