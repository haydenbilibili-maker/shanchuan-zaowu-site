# 首页内容动态化配置说明

## ✅ 功能概述

首页内容动态化功能已完成，支持：
- ✅ 模块顺序配置
- ✅ 模块显示/隐藏控制
- ✅ 每个模块的数量、排序等参数配置
- ✅ 配置缓存机制（24小时）
- ✅ 默认配置降级

## 📋 部署步骤

### 1. 部署云函数

在微信开发者工具中：

1. **部署 getHomeConfig**
   - 右键点击 `cloudfunctions/getHomeConfig` 文件夹
   - 选择"上传并部署：云端安装依赖"
   - 等待部署完成

### 2. 创建数据库集合

在云开发控制台：

1. 进入"数据库" → "集合管理"
2. 创建新集合：`home_configs`
3. 设置权限：
   - 所有用户可读：是（小程序需要读取配置）
   - 仅创建者可读写：是（后台管理需要写入）

### 3. 添加配置数据（可选）

如果不添加配置，系统会使用默认配置。

**配置数据结构**：
```javascript
{
  status: 'active',        // 'active' | 'inactive' | 'draft'
  priority: 1,             // 优先级，数字越大越优先
  version: '1.0.0',        // 配置版本号
  modules: [               // 模块配置数组
    {
      id: 'banners',        // 模块ID
      name: '轮播图',       // 模块名称
      enabled: true,       // 是否启用
      order: 1,            // 显示顺序（数字越小越靠前）
      config: {            // 模块特定配置
        limit: 5,          // 显示数量
        autoplay: true,    // 自动播放
        interval: 6000     // 轮播间隔（毫秒）
      }
    },
    {
      id: 'categories',
      name: '分类球',
      enabled: true,
      order: 2,
      config: {
        limit: 4,          // 显示数量
        showAll: false
      }
    },
    {
      id: 'collections',
      name: '专题展览',
      enabled: true,
      order: 3,
      config: {
        limit: 10,
        sortBy: 'createTime',
        sortOrder: 'desc'
      }
    },
    {
      id: 'framers',
      name: '名师手作',
      enabled: true,
      order: 4,
      config: {
        limit: 6,
        sortBy: 'createTime',
        sortOrder: 'desc'
      }
    },
    {
      id: 'activities',
      name: '近期活动',
      enabled: true,
      order: 5,
      config: {
        limit: 5,
        status: 'open',    // 活动状态筛选
        sortBy: 'date',
        sortOrder: 'asc'
      }
    },
    {
      id: 'recommendations',
      name: '为你推荐',
      enabled: true,
      order: 6,
      config: {
        limit: 8,
        algorithm: 'mixed' // 'mixed' | 'hot' | 'personalized'
      }
    },
    {
      id: 'newArrivals',
      name: '最新入库',
      enabled: true,
      order: 7,
      config: {
        limit: 10,
        sortBy: 'createTime',
        sortOrder: 'desc'
      }
    }
  ],
  updatedAt: new Date(),   // 更新时间
  _createTime: new Date(), // 创建时间
  _updateTime: new Date()  // 更新时间
}
```

## 🎯 支持的模块

| 模块ID | 模块名称 | 配置项 |
|--------|---------|--------|
| `banners` | 轮播图 | `limit`, `autoplay`, `interval` |
| `categories` | 分类球 | `limit` |
| `collections` | 专题展览 | `limit`, `sortBy`, `sortOrder` |
| `framers` | 名师手作 | `limit`, `sortBy`, `sortOrder` |
| `activities` | 近期活动 | `limit`, `status`, `sortBy`, `sortOrder` |
| `recommendations` | 为你推荐 | `limit`, `algorithm` |
| `newArrivals` | 最新入库 | `limit`, `sortBy`, `sortOrder` |

## 🔧 工作原理

1. **配置加载**
   - 首页加载时，优先从缓存读取配置
   - 如果缓存不存在或过期，调用云函数获取配置
   - 配置缓存24小时

2. **模块渲染**
   - 根据配置的 `enabled` 字段决定是否显示模块
   - 根据配置的 `order` 字段决定显示顺序
   - 根据配置的 `config` 字段控制模块参数

3. **降级处理**
   - 如果配置加载失败，使用默认配置
   - 默认配置：所有模块启用，按默认顺序显示

## 🎨 前端实现

### 模块显示控制

在 `pages/index/index.wxml` 中，每个模块都添加了 `wx:if` 条件：

```xml
<!-- 轮播图模块 -->
<view class="hero-section" wx:if="{{showBanners}}">
  <!-- ... -->
</view>

<!-- 分类球模块 -->
<view class="section-box orbs-section" wx:if="{{showCategories}}">
  <!-- ... -->
</view>
```

### 配置应用

在 `pages/index/index.js` 中：

1. `loadHomeConfig()` - 加载配置
2. `updateModuleVisibility()` - 更新模块显示状态
3. `loadModuleData(moduleId)` - 根据配置加载模块数据

## 📊 配置管理建议

### 多版本配置

支持多个配置版本，通过 `priority` 字段控制优先级：

```javascript
// 高优先级配置（当前使用）
{
  status: 'active',
  priority: 2,
  modules: [...]
}

// 低优先级配置（备用）
{
  status: 'active',
  priority: 1,
  modules: [...]
}
```

### A/B测试

可以通过创建多个配置来实现A/B测试：

```javascript
// 配置A：推荐模块在前
{
  status: 'active',
  priority: 1,
  name: 'config_a',
  modules: [
    { id: 'recommendations', order: 3 },
    { id: 'collections', order: 4 }
  ]
}

// 配置B：专题展览在前
{
  status: 'active',
  priority: 1,
  name: 'config_b',
  modules: [
    { id: 'collections', order: 3 },
    { id: 'recommendations', order: 4 }
  ]
}
```

然后通过用户ID或其他条件来选择使用哪个配置。

## ⚠️ 注意事项

1. **配置缓存**
   - 配置缓存24小时，修改配置后可能需要等待缓存过期
   - 或者清除小程序缓存强制刷新

2. **默认配置**
   - 如果没有配置或配置加载失败，使用默认配置
   - 默认配置确保首页始终可以正常显示

3. **模块顺序**
   - 模块在WXML中的顺序是固定的
   - 配置中的 `order` 字段主要用于逻辑控制，实际显示顺序由WXML决定
   - 如果需要真正的动态顺序，需要重构WXML使用循环渲染

4. **性能考虑**
   - 配置缓存24小时，减少云函数调用
   - 配置加载失败不影响首页显示（使用默认配置）

4. **测试配置缓存**
   - 修改配置数据
   - 验证是否立即生效（可能需要清除缓存）
