# 山海有信 · 文案语气指南

> 权威源：`cloudfunctions/dispatchMessage/templates.js` 顶部注释。本文为可读摘要。

## 气质

维多利亚博物学家的奇珍柜——博物、自然、收藏、品鉴、权威、人性化。  
结构：**事实 → 感受 → 连接**。权威但不冷冰；人性化但不甜腻。

## 称谓

| 场景 | 用法 |
|------|------|
| 顾客侧 | 默认「你」（朋友式）；少用客服腔「您」 |
| 工作流 | 中性陈述 + 克制祈使（「请到…安排」） |

## 时态

- 已发生：完成态（已入账 / 已启程 / 已入柜）
- 待办：温和祈使或留白（请在时限内… / 可前往…）

## 推荐词

标本、藏品、柜中、入册、启程、到柜、轻取轻放、馆员、候补、礼笺、山海有信

## 禁止

恭喜、火速、赶紧下单、亲、老板、请注意查收、已为您处理完毕、emoji 开头、直播电商话术、浮夸推销、科技感系统通知腔

## 示例

| 差 | 好 |
|----|----|
| 您的订单已发货，请注意查收 | 这件标本已启程。物流单号如下，到柜时请轻取轻放。 |
| 恭喜获得优惠券 | 柜中为你留了一份心意，可在会员页查看。 |

## 边界

- 只改表达；变量插值与业务语义不变
- 订阅消息模板字段 ID 不改；同源摘要语气对齐即可
