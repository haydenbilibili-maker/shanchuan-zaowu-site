# 馆藏与社区功能定位说明

> **命名更新（2026-05-22）**：底部 Tab「百科」已更名为 **馆藏**；页面路径仍为 `pages/category/index`。

## 馆藏页面 (`pages/category/index`)

### 功能定位
**标本档案 + 可购藏品的浏览与导购页**（内容优先，电商承接）

### 核心功能
1. **内容流（A 区）**
   - 展示 `cms_wikis` 标本档案、专题等内容
   - 左图右文列表，支持跳转内容详情（`wiki-detail`）
   - 有关联商品时展示转化条

2. **商品流（B 区）**
   - 展示未被内容关联的「孤儿 SKU」
   - 双列商品网格，价格、库存、售罄态
   - 跳转商品详情与购买

3. **分类与搜索**
   - 顶部品类 Pill 切换
   - 搜索入口跳转全局搜索（可带品类 scope）

4. **数据来源**
   - 内容：`cms_wikis`（云函数 `getEncyclopediaFeed` / `getWikiData`）
   - 商品：`products`（orphan 规则在服务端计算）
   - 不包含：社区 UGC 文章/视频（属社区 Tab 或独立入口）

### 页面特点（v1.1）
- 全宽单列布局，无左侧分栏
- 同一滚动流：先档案、后可购商品
- Museum Mode 暗色视觉

---

## 社区页面 (`pages/community/index`)

### 功能定位
**自然博物内容展示、用户交流、互动平台**

### 核心功能
1. **内容展示**：文章、视频、专题策展
2. **用户互动**：点赞、收藏、评论、分享
3. **UGC**：用户发布文章/视频（以实际开放为准）
4. **数据来源**：`articles`、`cms_wikis`（专题类，与馆藏 A 区运营分工不同）

---

## 功能解耦

### 数据分离
- **馆藏**：`cms_wikis`（档案）+ `products`（可购，orphan 规则）
- **社区**：`articles` + 社区向 `cms_wikis` 专题展示

### 功能分离
- **馆藏**：内容导购、品类浏览、加购与购买转化
- **社区**：内容浏览、互动、UGC 发布

### 导航
- **馆藏**：底部 Tab 第 2 项（文案「馆藏」）
- **社区**：独立页面（当前未在底部 Tab 中，以 `app.json` 为准）

---

## 注意事项

1. 馆藏与社区定位不同：馆藏负责「档案 → 购买」，社区负责「内容 → 互动」。
2. 同一 SKU 被馆藏内容关联后，仅在内容详情展示，不在馆藏 B 区重复出现。
3. 商品只能通过管理后台录入，社区不支持发布商品。
