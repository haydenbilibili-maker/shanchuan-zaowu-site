## 2. 背景与机会

### 2.1 业务诉求

山海造物线下门店已有成熟的**选标本 → 选框型 → 选包装 → 手写卡片 → 仪式交付**动线（见品牌 VI 手册「出口赠礼」章节）。线上目前以**标准 SKU 现货**为主，缺少：

1. **情感化送礼路径** — 生日礼盒、手写卡片、赠言等无法在线上表达；
2. **装裱 / 包装可视化选择** — 商详 SKU 维度偏「货架逻辑」，缺少「工坊定制感」；
3. **高客单转化** — 定制单客单价与毛利通常高于标品，但缺少专属入口承接。

### 2.2 现状诊断（基于代码）

| 维度 | 现状 | 缺口 |
|---|---|---|
| 商品规格 | `products` 支持 `skuDimensions`（如尺寸、装裱） | 未与「包装 / 礼盒 / 卡片」结构化绑定 |
| 下单链路 | `makeOrder` → `confirm-order` → 支付 | 无 `customMeta` 字段承载手写赠言、礼盒类型 |
| 标本师 | `framers` 集合 + 首页标本师模块 | 未接入定制流程（选师 / 签名） |
| 品牌包装 | VI 手册定义品牌卡、天地盖礼盒、箱内卡 | 线上无对应选项与预览 |
| 入口 | 探索 / 馆藏 / 商详分散 | 无统一「标本定制」心智入口 |

**结论**：不重建电商底层，在现有订单链路上增加**定制向导层 + 定制元数据**，把线下「工坊体验」翻译为线上分步选配。

## 3. 产品定位

### 3.1 一句话定位

> **标本定制 = 山海造物的「线上标本工坊」**：像在有光的木柜前选一件标本，再为它选框、选盒、写一张卡片，把「把山海带回家」的仪式延伸到线上。

### 3.2 与相邻模块关系

| 模块 | 关系 |
|---|---|
| **馆藏** | 内容种草 → 「按此物种定制」跳转定制向导（带品类 / 物种预设） |
| **商详** | 标品快速购买；增加「定制这款」入口（预填标本 SKU） |
| **探索** | 活动 Banner / 专题位导流「生日礼盒季」等 |
| **预约** | 高客单 / 复杂定制可引导「到店深度定制」**【待确认】** |
| **联系专员** | 超纲需求（非标准尺寸、企业团购）转人工 |
| **伴宠记忆** | 宠物标本定制独立子链路，见 [宠物标本定制 PRD](./PRD_宠物标本定制.md) |
| **购物车** | 定制单可作为「定制项」与普通 SKU 分开展示 **【待确认：是否允许与普通商品混单】** |

### 3.3 北极星指标（建议）

| 指标 | 说明 |
|---|---|
| 定制向导完成率 | 进入向导 UV → 提交订单 UV |
| 定制单占比 | 定制订单数 / 总订单数 |
| 礼盒选项渗透率 | 选择生日礼盒 / 礼品包装 的订单占比 |
| 手写卡片填写率 | 填写赠言的订单 / 定制订单 |
| 定制客单价 | vs 标品客单价 uplift |

## 4. 设计原则

1. **Atelier, Not Configurator** — 向导像「工坊台面上的一步一步」，不是工业配置器勾选表。
2. **Preview Before Pay** — 支付前必须有「定制预览页」：标本 + 框 + 盒 + 卡片文案摘要。
3. **Museum, Not Marketplace** — 暗底、黄铜点缀、宋体物种名；不出现大促倒计时、满减横幅。
4. **Reuse Commerce Rails** — 计价、库存、优惠券、会员折扣、支付复用 `makeOrder` / `confirm-order`。
5. **Offline-Online Same Language** — 选项命名与门店话术一致（如「天地盖礼盒」「品牌卡片」「手写祝福卡」）。
6. **Graceful Escalation** — 标准选项走自助；非标需求一键「联系专员」并带上当前选配快照。

## 5. 目标用户与核心场景

| 用户 | 场景 | 期望路径 |
|---|---|---|
| 送礼者 | 朋友生日，送蝴蝶标本 | 探索专题 → 定制向导 → 选礼盒 + 手写卡片 → 寄送 |
| 自然爱好者 | 想指定装裱风格 | 馆藏看物种 → 「定制这款」→ 选框型 → 标准包装 → 下单 |
| 复购藏家 | 已有偏好框型 | 我的 → 标本定制 → 从「上次配置」快速复购 **【P1】** |
| 企业客户 | 10 件以上团购定制 | 向导内提示联系专员 → 提交意向单 **【P2】** |
| 到店引流 | 线上看不准实物 | 保存定制方案 → 预约到店确认 **【P2】** |

## 6. 功能范围

### 6.1 定制向导（核心流程）

建议 **5 步向导**（顶部进度条：`标本 → 装裱 → 包装 → 赠礼 → 确认`）：

```
Step 1  选标本
        ├── 按品类浏览（昆虫 / 植物 / 海洋 / 矿石）
        ├── 搜索物种 / 商品名
        └── 支持从商详 / 馆藏带参跳入（productId 预填）

Step 2  选装裱
        ├── 框型（木框 / 金属框 / 简约框…）【与 SKU 维度或 custom_configs 映射】
        ├── 尺寸（若标本支持多尺寸）
        ├── 衬底 / 背景色（若有）
        └── 可选：指定标本师（framers）【P1，需确认是否影响交期与加价】

Step 3  选包装
        ├── 标准包装（品牌手提袋 + 缓冲材）— 默认可含在标价内
        ├── 礼盒升级（天地盖礼盒 + 内衬）— 加价
        ├── 生日礼盒主题（限定腰封 / 贴纸）— 加价 **【待确认物料】**
        └── 快递箱品牌胶带（默认开启，不可取消）

Step 4  赠礼与卡片
        ├── 品牌物种卡（默认随单，VI 标准卡）— 展示背面信息预览
        ├── 手写祝福卡（用户填写赠言，门店代写 / 打印贴于卡片）— **【待确认：代写 or 打印体】**
        ├── 箱内仪式卡（「你手中这件标本来自___」模板，自动填产地）— 可选
        └── 匿名送礼 / 隐藏价格小票 — 开关

Step 5  预览与下单
        ├── 定制摘要（铜牌信息区风格）
        ├── 价格明细（标本 + 装裱差价 + 包装 + 礼盒 + 会员折扣 + 券）
        ├── 预计制作周期 **【待确认 SLA】**
        └── 加入购物车 / 立即定制购买
```

### 7.1 推荐方案：**「探索常驻 + 多场景分流」**

**【待确认 A】** 是否在底部 Tab 增加第 6 个 Tab？

## 9. 数据与计价模型（草案）

### 9.1 定制配置 `custom_configs`（建议集合）

```javascript
{
  _id: 'frame_metal_slim',
  type: 'frame',           // frame | packaging | gift_theme | card
  name: '窄边金属框',
  desc: '黄铜色细框，适合中小型昆虫标本',
  image: 'cloud://...',

  applicableCategories: ['INSECTA', 'PLANTAE'],  // 空=全品类

  status: 'active'

```


### 9.3 计价逻辑 **【待确认】**

| 方案 | 优点 | 缺点 |
|---|---|---|
| **A. 全部映射为虚拟 SKU** | 复用现有 `makeOrder` 最省事 | 后台 SKU 组合爆炸 |
| **B. 主 SKU + customMeta 加价项** | 灵活，选项可配置 | 需扩展 `pricing.js` |
| **C. 独立 `custom_orders` 集合** | 与标品订单解耦 | 支付 / 履约要双轨 |

**推荐：方案 B（MVP）** — 主商品走现有 SKU；装裱 / 包装 / 礼盒作为 `customLineItems[]` 加价，在 `makeOrder` 前合并进 `totalPrice`。
