## 1. 落地页：藏品详情的礼券抽屉

- 线上版本里能「看到可领的券并一键领取」的页面**只有藏品详情**（`subpackages/feature/detail/index`）：
  `getProductCoupons` 列出 `coupons` 里 `active: true`、未到 `endTime`、已过 `startTime`、库存未尽、渠道允许线上的券 →
  「优惠」条显示「去领取」→ 抽屉里点「领取」调 `receiveCoupon`。
- 礼券夹（钱包枢纽 `wallet-hub?tab=coupons`）只列已持有的券，**没有可领列表**；首页也没有。
  复核（产品负责人问「能否在钱包 → 券夹领取」）：券夹面板 `WalletPanelCoupons` 只调 `getUserCoupons`（失败回退直读 `user_coupons`）
  与亮码用的 `getMemberPass`；WXML 只有可用 / 占用中 / 已失效三组，券卡唯一按钮是「去使用」（→ 购物车或到店亮码），空态按钮去注册或积分页，
  **没有任何「可领取」分支，也没有通往领券抽屉的出口**。积分面板的 `exchangeCoupon` 要求积分 > 0、只发现金券且不关联 `coupons` 模板，
  不能承载八折券。→ 不发版做不到；要做须给券夹加「可领取」区块（旁路读接口 + 调 `receiveCoupon`）并上传新版。
- 未注册用户：`receiveCoupon` 只认 openid，**不校验是否注册**，未注册也能领。
- 注意 `getProductCoupons` 取启用券时 `limit(30)` 且不排序 —— 启用中的券超过 30 张时新券可能不出现（当前生产启用券极少）。

## 3. 小程序 URL Link（短信等微信外渠道）

- 脚本：`node miniprogram/scripts/generate-url-link.cjs --via wechat|cloud --path <页面> --query "<参数>" [--expire <ISO 时间>]`。
  - `--via cloud`：走新增的 `generateUrlLink` 云函数（`urllink.generate`，仅超管或 `ADMIN_OPS_KEY`；首次自动补配 `ADMIN_OPS_KEY`）。
    **2026-10-29 实测云环境 openapi token 仍失效**（`-501001 invalid wx openapi access_token`，同 `docs/需求28_马上有祈福墙_交付记录_2026-09-16.md` §30.2），修好云环境关联前走不通。
  - `--via wechat`：直连微信，读 gitignored 的 `miniprogram/scripts/.env.qr`；用 `stable_token`（普通模式）不会让其它服务的 token 失效。
- 微信口径：URL Link 有效期最长 30 天，无永久链接；当前下发域名为 `wxmpurl.cn`。
- 渠道效果：详情页 `product_view` 埋点把入口 `from` 写进 `user_behaviors.properties.source`（同时扁平为 `source`），`scene = 1194` 为 URL Link 打开。
