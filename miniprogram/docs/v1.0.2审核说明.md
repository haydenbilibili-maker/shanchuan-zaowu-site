## 二、审核说明 / 测试路径（面向审核员）

建议粘贴：

```
【小程序简介】
山海造物（Nature's Creations）是自然标本零售与门店服务小程序，提供馆藏浏览、下单购买、门店预约参观、标本定制（标本工坊）、会员积分与消息等能力。

【本版相对 v1.0.1 的可测变更】
1. Tab：探索 / 馆藏 / 标本工坊（居中）/ 购物车 / 我的；门店「这有店」不在 Tab，从「我的 → 这有店」进入。
2. 标本工坊：定制选配、伴宠记忆意向、进度查询。
3. 门店：门店信息、导航/电话、预约参观；可申请定位以展示与门店距离（拒绝定位仍可浏览门店页）。
4. 积分：「我的」资产区进入积分页，可见门店积分规则文案（满 1 元赠 1 分；100 分兑 ¥10 代金券说明）。兑换大厅若有上架兑换项可试兑（依赖运营配置）。
5. 开票：登录后「我的 → 联系专员 → 发票开具」，选择已支付订单填写抬头提交（电子发票由专员线下开具后回传，非即时自动开票）。
6. 地址：我的 → 地址管理 → 手动新增，核对姓名/手机/详细地址输入框文字完整可见。
7. 预约票根：完成预约后「我的预约 / 票务」相关入口查看票根样式。
8. 交易：馆藏选品 → 加购 → 购物车 → 确认订单 → 微信支付（若本环境已开通支付）；优惠券为既有能力，可在「我的优惠券」或结算页选用。

【测试账号】
普通用户：【请填写测试账号】（微信号 / 手机号，需已能登录小程序）
说明：未登录可浏览探索、馆藏、标本工坊介绍与门店基础信息；下单、积分、开票、会员码等需登录。
店员/店长后台（非 C 端必测）：【请填写员工测试账号】；路径「我的 → 店长后台 / 现场工作台」（仅员工身份可见）。发票管理、门店赠分等属管理端，审核可不测；若测请使用员工号。

【权限与收集说明（与页面一致）】
· 位置（getLocation）：计算附近门店距离、推荐可到店门店；用户可拒绝。
· 收货地址（chooseAddress）：下单或地址管理时选用微信地址；亦支持手动填写。
· 摄像头 / 相册（按功能触发）：AI 标本鉴定拍照、AR 试摆、保存分享图/证书等；未使用相关功能可不授权。
· 微信支付：仅在用户主动下单支付时调起，用于标本/定制等商品交易。

【类目与内容说明】
本小程序为实物零售 + 线下门店预约 + 定制服务意向，不含博彩、社交信息交友等违规内容；用户生成内容（社区发帖等）有基础审核链路。客服可在「联系专员」或页面客服入口联系（营业/客服时段以页面展示为准）。

【备注】
上传包请使用本仓库待提审代码对应的体验版；管理端与积分发放依赖云函数环境变量与员工身份配置，不影响普通 C 端浏览与购物主路径审核。
```

## 三、建议填写的空项（提审前核对）

| 空项 | 说明 | 建议填写位置 |
|------|------|----------------|
| 【请填写测试账号】 | 可登录的普通微信测试号；最好预置 1 笔已支付订单便于测开票 | 审核说明「测试账号」 |
| 【请填写员工测试账号】 | 可选；仅当希望审核员看店长/发票管理时提供 | 同上 |
| 支付是否对审核开放 | 若商户/支付未对审核环境开通，注明「支付能力已申请，审核期可用小额商品验证 / 或说明 mock 未开」 | 审核说明「交易」条 |
| 隐私保护指引 | 公众平台《用户隐私保护指引》须与 `app.json` 一致：位置、选地址；相册/摄像头按实际勾选 | 公众平台隐私设置（非本粘贴栏） |
| 限时免邮 | 当前代码默认开启「限时免费邮寄」；若提审前已关闭活动，更新说明中删掉相关句 | 版本更新说明 |
| 积分兑换档位 | C 端文案有 100 分=¥10；兑换大厅具体商品依赖云库 `rewards` 配置，无档位时写「规则文案可见，兑换项以页面为准」 | 已写入审核说明 |
| 类目与资质 | 零售 / 生活服务等与主体、商户号一致 | 公众平台类目 |
