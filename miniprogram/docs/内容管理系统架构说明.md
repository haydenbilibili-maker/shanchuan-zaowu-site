# 内容管理系统架构统一说明

## 📋 架构设计

### 统一内容管理架构

将专题策展（cms_wikis）和知识文章（articles）统一到一个内容管理系统（CMS），两者功能相似，数据结构统一。

### 数据结构统一

#### 共同字段（专题 + 文章）
```javascript
{
  _id: String,
  title: String,           // 标题
  brief: String,           // 摘要/导语
  coverImage: String,      // 封面图
  content: String,         // 富文本内容（HTML）
  tags: Array,             // 标签数组
  type: String,            // 'exhibition' | 'article'
  status: String,          // 'published' | 'draft'
  createTime: Date,        // 创建时间
  updateTime: Date         // 更新时间
}
```

#### 专题特有字段（cms_wikis）
```javascript
{
  latinName: String,       // 副标题/拉丁名
  cover: String            // 兼容字段（同coverImage）
}
```

#### 文章特有字段（articles）
```javascript
{
  category: String,        // 'knowledge' | 'art' | 'craft' | 'story'
  author: String,          // 作者
  videoUrl: String,        // 视频链接（可选）
  stats: {                 // 统计数据
    views: Number,         // 浏览量
    likes: Number,         // 点赞数
    comments: Number       // 评论数
  }
}
```

## 🎯 功能模块

### Web端（统一管理）

**文件**: `shanchuan-admin/src/components/ContentManager.vue`

**功能**:
- ✅ 切换内容类型（专题/文章）
- ✅ 统一的列表展示
- ✅ 统一的编辑弹窗
- ✅ 根据类型显示不同字段
- ✅ 统一的数据保存逻辑

**菜单位置**: 运营配置 > 内容管理

### 小程序端（移动管理）

**文件**: `pages/manager/index.js` 和 `pages/manager/index.wxml`

**功能**:
- ✅ Tab 9: 内容管理
- ✅ 子Tab切换：专题策展 / 知识文章
- ✅ 统一的编辑弹窗
- ✅ 图片上传功能
- ✅ 富文本编辑

**菜单入口**: 功能导航 > 内容

## 🔄 数据流向

### 专题数据流
```
Web端/小程序管理后台
  ↓ 编辑/创建
cms_wikis 集合 (type='exhibition')
  ↓ 云函数读取
getWikiData 云函数
  ↓ 前端展示
专题详情页 / 首页专题模块
```

### 文章数据流
```
Web端/小程序管理后台
  ↓ 编辑/创建
articles 集合 (type='article')
  ↓ 云函数读取
getArticles 云函数
  ↓ 前端展示
文章列表页 / 文章详情页
```

## 📊 数据库集合

### cms_wikis（专题策展）
- **用途**: 存储专题展览内容
- **类型标识**: `type: 'exhibition'`
- **前端展示**: 专题详情页、首页专题模块

### articles（知识文章）
- **用途**: 存储知识文章内容
- **类型标识**: `type: 'article'`（通过category区分）
- **前端展示**: 文章列表页、文章详情页

## 🔧 技术实现

### 云函数
- `getArticles`: 获取文章列表和详情

### 前端组件

## 📝 使用指南

### Web端管理
1. 登录管理后台
2. 进入"运营配置 > 内容管理"
3. 切换"专题策展"或"知识文章"标签
4. 点击"新建"创建内容
5. 填写表单并保存

### 小程序端管理
1. 进入管理后台
2. 点击"内容"按钮（Tab 9）
3. 切换"专题策展"或"知识文章"子Tab
4. 点击"+"按钮创建内容
5. 填写表单并保存

## ✨ 优势

1. **统一架构**: 专题和文章使用相同的管理界面和逻辑
2. **代码复用**: 减少重复代码，提高维护性
3. **用户体验**: 管理员可以在一个地方管理所有内容
4. **数据一致**: 确保数据结构统一，便于扩展
5. **易于扩展**: 未来可以轻松添加新的内容类型
