## 2. 表面体系

小程序有**两种主场**，同一页面里可以并存，但**每个节点只属于一种**：

| 主场 | 底色 | 用在哪 | 文字阶梯 |
|---|---|---|---|
| **夜墨（数字主场）** | `--color-bg` #1A1814 | 默认：所有页面的底 | 标题白 / 正文 / 说明 / 弱化（§3.2） |
| **宣纸（纸品主场）** | `--brass-50` #FAF6ED、#FAFAF5 一族 | **只给"纸品仪式面"**：礼笺、赠予凭证、预约票根、证书、心愿签牌匾、玩法结果纸 | 墨 #2C2C2C / `--brass-700` 起 |

**夜墨的四层表面**（由深到浅 = 由远到近）：

| 层 | 令牌 | 值 | 用途 |
|---|---|---|---|
| 0 展厅 | `--color-bg` | #1A1814 | 页面底 |
| 1 展柜 | `--color-bg-card` | #1F1D1A | 卡片、列表行容器 |
| 2 浮层 | `--color-bg-elevated` | #262320 | 抬升元素、输入框底、骨架条 |
| 3 弹层 | `--pop-surface` | #221F1B → #1C1A17 渐变 | 底部抽屉 / 居中确认框（见弹层规范） |

**面积比**（第 04 页）：夜墨 / 宣纸 ≈ 80% · 文字层 ≈ 15% · 黄铜 ≤ 5%。黄铜越少越贵。

**不要**
- ✗ 在夜墨页面里用宣纸做大面积卡片底（除非它就是纸品：票根 / 证书 / 礼笺）
- ✗ 用夜墨的文字令牌写纸面上的字（`--color-text-secondary` 在宣纸上只有 2.6:1）—— 纸面用墨 / `--brass-700`
- ✗ 冷灰（#333–#eee）当文字色 —— 全站已清（2026-10-14），新写一律用暖调令牌

## 3. 色彩

### 3.1 品牌色

| 令牌 | 值 | 对比（夜墨上） | 用途 |
|---|---|---|---|
| `--color-primary` = `--brass-400` | #C4A76C | 7.6:1 | **唯一品牌色**：标志、眉题、发丝线、主按钮、L1 主视觉 |

### 3.2 文字阶梯（夜墨主场）

| 层级 | 令牌 | 值 | 对比 | 用途 | 不要 |
|---|---|---|---|---|---|
| 标题白 | `--color-text-primary` | #FFFFFF | 17:1 | 标题、价格、L1 | 大段正文（太刺） |
| 正文 | `--color-text-body` | #D5D1C8 | 12:1 | 正文段落 | — |

| 弱化 | `--color-text-muted` | #6B6560 | 3:1 | **仅**装饰 / 禁用 / 占位 / 失效态 / 分隔 | ✗ 承载说明（🔒 `check:mp-caption-color`） |
| 拉丁 | `--color-text-latin` | #C4A76C | — | 拉丁学名（配 `--font-latin` 斜体） | — |

### 3.3 功能色

| 令牌 | 值 | 语义 | 在淡底上写字用 | 作实心底承载白字用 |
|---|---|---|---|---|
| `--color-success` | #52B788 | 成功 / 健康 / 上升 | 原色可用 | ✗ 白字 2.5:1 → **墨字**（`--color-bg`） |
| `--color-warning` | #E9A23B | 需关注 / 待办 | 原色可用 | 墨字 |
| `--color-error` | #D13C41 | 错误 / 危险 | **`--color-error-on-tint`** #EE8A8D | **`--color-error-solid`** #C9373C（第 04 页「错误红承载白字须 #C9373C 以上深度」） |
| `--color-info` | #5B8FB9 | 信息 / 进行中 | **`--color-info-on-tint`** #8DB4D4 | 墨字 |

> **为什么要 on-tint**：红字压在 12–16% 红底上只有 3.0–3.8:1（2026-10-14 实测 34 处）。同色相提亮一档后三种深色面 4.75–6.8:1。
> **规则**：同色淡底徽标 / 状态 pill 的文字，一律用 `*-on-tint`；不要用原色。

### 3.4 品类色

| 品类 | 令牌 | 值 |
|---|---|---|
| 昆虫 | `--color-insecta` | #52B788 |
| 植物 | `--color-plantae` | #6DA34D |
| 矿物 | `--color-minerals` | #7B68AE |
| 海洋 / 化石 | `--color-marine` | #5B8FB9 |
| 木作 / 大地 | `--color-wood` | #8B6F47（淡底写字用 `--color-wood-on-tint` #C9AE84） |

**规则**（第 04 页）：品类色**只用于品类标识与图标**（6px 色点、`.tag-category`），不做大面积底色。
⚠️ `#52B788` 同时是「昆虫」与「成功」，`#5B8FB9` 同时是「海洋」与「信息」—— **按语义选令牌名**，不要按值。
⚠️ `--color-forest` #2D5A3F 是**信号灯色**，不是第 04 页的「山林绿」#2D6A4F（后者暂无令牌，纸面绿章用字面量）。

## 4. 金的用法（纪律 02「克制的金」）

> 金色以**发丝线（1rpx）**出现；印章是**细线描边**，不是金属徽章。

### 4.1 金可以出现在

| 位置 | 写法 |
|---|---|
| L1 主视觉（每屏 1–3 个） | `color: var(--color-primary)` |
| 英文眉题 | `.mu-en` |
| 发丝线 / 描边 | `1rpx solid` + 黄铜色（🔒 1px 已全站改 1rpx） |
| 主按钮实心底 | `.btn-primary` |
| 选中态 | **金线环** `box-shadow: var(--ring-brass)`（blur 0） |
| 卡面内描 | `box-shadow: var(--hairline-brass-inset)` |
| 减免金额 | 只染**数值**，标签保持说明色（§8.3） |

### 4.2 金不可以

- ✗ **发光**：任何金色阴影 blur > 4rpx 🔒 `check:vis3-rules` R2（2026-10-14 起硬判据）
- ✗ 文字辉光（`text-shadow` 金晕）
- ✗ 按钮光晕 —— 浮起用**中性**投影 `--shadow-lift` / `--shadow-lift-press`
- ✗ L2 / L3 用品牌亮金（契约 C7 §3：「L1 之外不得出现品牌亮金」🔒 `check:detail-visual-tiers`）

### 4.3 唯一例外：光源

**本身是光源**的元素（灯、烛、火花、星点、信号灯、落愿瞬间的回响）—— 光就是它的内容。
登记在 `scripts/audit-vis3-rules.mjs` 的 `R2_LIGHT_SOURCE`（文件 → 选择器正则 + **理由**），**表外发光一律红**。
⚠️ 纸品面的"微光"**不是**光源；想保留请找产品负责人改口径，不要往豁免表里塞。

## 5. 字体与字阶

### 5.1 五族（第 05 页）🔒

| 字族 | 令牌 | 用于 | 不要 |
|---|---|---|---|
| 品牌宋 | `--font-brand` | 标题、品牌名、分区主标（`.mu-cn`） | ✗ 正文段落 |
| 人文黑 | `--font-body`（= `--font-heading`） | 正文、说明、按钮、左标签 | — |
| 拉丁衬线 | `--font-latin` | **拉丁学名 / 英文名，一律斜体** | ✗ 正文无衬线伪斜体当学名 |
| 等宽 | `--font-mono` | **数字 / 金额 / 编号 / 英文眉题** | — |
| 手写 | `--font-hand` | **仅用户亲笔**：心愿签、祈福墙弹幕 | ✗ 品牌文案、按钮 |

- **一屏最多三种字族**（第 05 页）。
- **不要手写字体名**（`'DIN'`、`Georgia`、`'Source Han Serif SC'`…）—— 2026-10-14 全站已收 250 处；
  ⚠️ `--font-din` **从未定义过**（曾被用 75 次、真机全部回落正文字体）→ 数字一律 `--font-mono`（其回退链已含 DIN / DIN Alternate）。
- `--font-*` 令牌值**必须单行**（多行自定义属性在 iOS WXSS 编译器上出过事）。

### 5.2 字阶（契约 C7，14 档冻结）

`--fs-16 18 20 22 24 26 28 30 32 34 36 40 44 48`（命名即尺寸，rpx）。语义档：

| 语义 | 档 | 示例 |
|---|---|---|
| 页面大标题 | `--fs-48` | 博物藏品室 |
| 区块标题 | `--fs-36`（分区主标 `.mu-cn` 用 38，属历史装饰档） | 为你推荐 |
| 商品名 / 价格 | `--fs-32` | 蓝闪蝶 · 原木标本框 |
| 正文 | `--fs-28`（`page` 默认 28rpx / 行高 1.6） | — |
| 说明 / 小注 | `--fs-24`（行内小注 22） | 产自南美亚马逊流域 |
| 眉题 / 角标 | `--fs-20`（`.mu-en` 18） | SPECIMEN · LEPIDOPTERA |

**写 `var(--fs-*)`**（2026-10-15 存量已全部令牌化，P3）。档外字号（38 / 56 / 64…）只给装饰大字，新增前先问能否落到档内。

### 5.3 排版约定（从代码里抽出来的现行值）

| 元素 | 字号 | 行高 | 字距 | 其它 |
|---|---|---|---|---|
| 英文眉题 `.mu-en` | 18rpx | 26rpx | **0.32em** | 等宽、黄铜、全大写 |
| 分区主标 `.mu-cn` | 38rpx | 50rpx | 0.12em | 品牌宋、500、**nowrap** |
| 分区副标 `.mu-sub` | 22rpx | 1.45 | 0.04em | 说明色 |
| 按钮 | — | 1.2 | 0.04em | 500、**nowrap** 🔒 |
| 正文 | 28rpx | 1.6 | 0.02em | — |

**纪律 04「英文眉题 + 中文标题」**🔒：分两行（`.mu-en` + `.mu-cn`），**不写成「EN / 中」一行**。
**纪律 08「不折行、不孤字」**🔒：按钮与标题按内容定宽 + `nowrap`。

## 6. 空间、圆角与线

### 6.1 间距（8 的倍数）

`--space-1 … 8` = 8 / 16 / 24 / 32 / 40 / 48 / 64rpx。

| 用途 | 值 |
|---|---|
| 页面左右留白 | **32rpx**（`--space-4`，现行最常见；弹层内 `--pop-pad-x` 40rpx） |

| 同组元素间距 | 16–24rpx |
| 区块间距 | 48–64rpx |
| 底部让位 | Tab 页一律留 `--tabbar-offset`（= 120rpx + 安全区） |

### 6.2 圆角四档（第 06 页）🔒 已全站令牌化

## 7. 层级与阴影

### 7.1 阴影令牌

| 令牌 | 值 | 用于 |
|---|---|---|
| `--shadow-museum-warm` | 0 8 24 rgba(26,24,20,.45) | 卡片静置 |
| `--shadow-lift` | 0 8 24 rgba(0,0,0,.36) | 浮起（FAB、悬浮按钮） |
| `--shadow-lift-press` | 0 4 12 rgba(0,0,0,.32) | 浮起元素按下 |
| `--pop-shadow-dialog` / `-sheet` | 见弹层规范 | 弹层 |
| `--ring-brass` / `--ring-brass-soft` | 0 0 0 2rpx / 1rpx 黄铜 | 选中 / 聚焦 |
| `--hairline-brass-inset` | inset 0 0 0 1rpx 黄铜 .22 | 卡面内描 |

**阴影只用中性墨色；金只以环 / 线出现**（§4）。

### 7.2 z-index 阶梯

| 层 | 值 | 内容 |
|---|---|---|
| 页面内叠层 | 0–10 | 图上叠字、角标、渐隐罩 |
| 吸顶 / 吸底栏 | 20–100 | 吸顶 tab、结算栏（购物车 100） |
| 弹层 | **800**（`.ui-pop-mask`） | 所有 ui-pop-* |
| 全局 TabBar | **9999**（`custom-tab-bar`） | ⚠️ **比弹层高** |

> ⚠️ **Tab 页上的底部抽屉必须给 TabBar 让位**：`.ui-pop-sheet` 贴屏幕底，TabBar 会盖住它底部约 120rpx，
> 列表末段及其触摸区落在 TabBar 下 —— 表现为「滑不动」（2026-10-15 购物车选择礼券实际踩到）。
> **写法**：给该遮罩加一个页面类，`.xxx-mask .ui-pop-sheet { padding-bottom: var(--tabbar-offset); }`。
> Tab 页 = 首页 / 馆藏 / 标本工坊 / 购物车 / 我的。

## 9. 交互

### 9.1 按压反馈 🔒（全站已补 686 处）

| 规则 | 写法 |
|---|---|
| 可点的 `view` 一律有按压态 | `hover-class="tap-press" hover-stay-time="80"`（小控件，opacity .72） |
| 整卡 / 整行 | `hover-class="tap-press-soft" hover-stay-time="80"`（opacity .86） |
| ⚠️ **不要依赖 `:active`** | 小程序 `view` 上 `:active` 真机不稳 |
| 样式隔离的组件 | 组件 wxss 自带同值 `.tap-press` / `.tap-press-soft`，或 `options.addGlobalClass` |
| **不给**按压态 | 遮罩点关、弹层壳、`catchtap="noop/true"` 吞事件壳、透明 blocker 区 |
| 嵌套可点 | 内层加 `hover-stop-propagation`，避免按子按钮时整卡一起暗 |

### 9.2 触区

最小 **72×72rpx**（返回键现行值）；小图标按钮用透明 padding 撑到 72，不放大图标本身。相邻可点元素间距 ≥ 16rpx。

### 9.3 反馈节奏

| 动作 | 反馈 |
|---|---|
| 点按 | 80ms 压暗（`--dur-instant`） |
| 切换 / 选中 | 160ms 描边 / 底色过渡 + 金线环 |
| 提交 | 按钮进入「…中」并禁用；成功用 AppToast；失败就地说明 + 可重试 |
| 危险操作 | AppModal 确认，危险按钮在右；理由必填的写进弹层内 |

### 9.4 弹层手势

底部抽屉：点遮罩关、右上 ✕ 关；列表区 `scroll-view` 定高（按条数，封顶 50–56vh）；Tab 页让位 TabBar（§7.2）。

## 10. 动效

### 10.1 令牌（第 06 页 MOTION）🔒

| 令牌 | 值 | 语义 |
|---|---|---|
| `--dur-instant` | 80ms | 按压 |
| `--dur-fast` | 160ms | 描边、颜色、小切换 |
| `--dur-base` | 240ms | 弹层进出、卡片位移 |
| `--dur-slow` | 400ms | 整屏 / 大块入场 |
| `--ease-standard` | cubic-bezier(.4,0,.2,1) | 默认 |
| `--ease-out-soft` | cubic-bezier(.22,.61,.36,1) | 进场、弹层升起 |

2026-10-14 已收 224 处 transition；新写**不要写时长字面量**（> 0.6s 的叙事动画除外）。

### 10.2 只动这些属性

`opacity` / `transform` / `color` / `background-color` / `border-color` / `box-shadow`。
✗ `transition: all`（会动到宽高、内边距 → 重排卡顿）。需要动高度的（如规格 swiper）**单独写 `height`**。

### 10.3 无限动画与减弱动效 ◻

- 无限动画只给：骨架脉动、信号灯 `.blink`、光源（灯 / 星点）、直播 ON AIR。**装饰性无限动画不要新增。**
- **契约 C7 §5.3** 🔒：带 `infinite` 的选择器必须在同文件 `@media (prefers-reduced-motion: reduce)` 里写 `animation: none` —— 2026-10-15 已全站补齐，`check:wxss-syntax` A8 拦新增。

### 10.4 仪式感动效

纸品仪式面（落愿、开笺、印章落下）允许 > 400ms 的叙事动画，但：一次性、不循环、不阻塞操作，完成后静止。

## 17. 变更流程

1. **改数值** → 先改 `app.wxss` 令牌，再改本文对应表格；同一提交里完成。
2. **加令牌** → `page{}` 里与同族令牌相邻、单行、带一句「用于什么 / 依据哪页」的注释；先跑 `check:main-package-size`。
3. **加组件零件** → 写进 `app.wxss` 对应分区；本文 §8 加一行；配一条守卫断言（必须能证明自己会红）。
4. **新规则** → 能机器判的进守卫（参考 `audit-vis3-rules.mjs` 纯函数 + 合成样本自检形态）；判不了的在本文标 ◻。
5. **与 VIS 3.0 原文冲突**（如方印）→ 必须有产品负责人拍板记录，写进 §1 / §16.3，并在 `VIS3落地规范` 台账留档。
6. 版本：本文为 **v1**；结构性改动（新增章节、改主场 / 标志口径）升 v2，并在 `docs/README.md` 索引更新。
