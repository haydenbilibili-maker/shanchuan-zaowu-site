## 2. 口径

1. **每月固定**：每张工资条都扣同样的月度个人部分 养老 351.46 + 医疗 87.86 + 失业 13.18 = **452.50**；
   公司为你缴纳 养老 527.18 + 医疗 338.28 + 失业 30.75 + 工伤 14.06 = **910.27**，只展示，不从实发里扣。工资条上不展示所属月。
2. **标准有版本**：每版写「自哪个工资月起生效」（`effectiveFrom`），某月工资条用不晚于该月的最近一版 —— 没有新版就按上一版金额扣。
   当前版 `si-2026-08` 自 2026-08 起生效。费率变了在 `SI_STANDARDS` 追加新版，不要改已用过的版本。
3. **折算人数只用于折算**：截图是两人合计，每人 = 合计 ÷ 2（按分取整）；所有参保员工（目前三人）都扣，不受这个 2 限制。
4. **工伤个人不扣**，只由公司缴纳。
5. **大额医疗互助一年只扣一次**：2026 年度已于 8 月工资（系统外）扣缴 → 配置 `SI_EXTERNAL_CHARGES`，2026 年不再扣，
   工资条注明「大额医疗互助 2026 年度已于 8 月工资扣缴」，超管强行勾选也会被拒；下一年度当年第一张工资条扣 100，之后不再扣。

## 5. 改了什么

- **云函数 `manageStaffWorkspace`**（新增旁路，旧入参结果逐字不变）：
  - `payslipUpsert` 可选入参 `socialInsurance: { apply: true, includeAnnual? }`：按工资月取适用版本，保存快照 `socialInsurance`
    （个人 / 公司分项、合计、版本、说明）与 `otherDeduction`；`deduction = 其他扣款 + 个人社保`，`net = 应发 − deduction`。
    大额医疗互助：读该员工本年其他工资条是否已扣，已扣或系统外已扣 → 不扣，强行要求扣 → 拒绝。
  - `payslipSiPreview`（仅超管）：与保存同算法的预览快照。
- **小程序 超管「工资维护」**：「套用社保扣缴标准」开关、「含大额医疗互助（全年一次）」开关（本年度不能扣时隐藏）；
  预览逐项列出个人 / 公司、说明、预计实发，写明当前版本。
- **小程序「工资条明细」**：扣款区逐项（养老 / 医疗 / 失业），说明行；「公司为你缴纳（不从工资里扣）」卡片注明工伤与折算口径。旧工资条原样显示。
- **ERP 员工薪酬管理**：标准表（频次、每人金额、生效月）+ 参保员工；生成 / 重算按同一规则（含大额医疗互助年度一次）。
- **守卫** `npm run test:payslip-social-insurance`（manager 域，87 项；`--selftest` 20 个内存注入）。
