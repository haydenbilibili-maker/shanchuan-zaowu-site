# 首页优化完成说明

## ✅ 已完成功能

### 1. 性能优化
- **数据缓存系统** (`utils/cache.js`)
  - 支持设置/获取/清除缓存
  - 不同数据类型设置不同的过期时间
  - 轮播图、专题展览、新品等数据支持缓存
  - 后台静默更新缓存，提升用户体验

- **加载优化**
  - 首屏优先加载关键内容（轮播图、分类）
  - 其他内容异步加载，不阻塞首屏渲染
  - 减少 `setData` 调用次数
  - 下拉刷新时清除缓存，强制更新

### 2. 智能推荐系统
- **推荐云函数** (`cloudfunctions/getRecommendations/index.js`)
  - 基于用户行为数据的个性化推荐
  - 支持新用户的热门推荐降级方案
  - 推荐理由展示（"因为你浏览过XX"、"基于你的收藏偏好"等）

- **用户行为追踪** (`cloudfunctions/trackUserBehavior/index.js`)
  - 记录用户浏览、收藏、购买、分享等行为
  - 异步记录，不阻塞主流程
  - 数据存储在 `user_behaviors` 集合

- **推荐模块UI**
  - 黑金质感设计，与整体风格一致
  - 卡片式布局，支持横向滚动
  - 显示推荐理由标签
  - 骨架屏加载状态

### 3. 错误处理
- **重试机制**
  - `loadWithRetry` 函数支持自动重试（最多2次）
  - 推荐内容加载失败时优雅降级

## 📋 需要部署的云函数

在微信开发者工具中，需要上传以下云函数：

1. **getRecommendations** - 智能推荐
   - 路径：`cloudfunctions/getRecommendations/`
   - 依赖：需要 `user_behaviors` 集合

2. **trackUserBehavior** - 用户行为追踪
   - 路径：`cloudfunctions/trackUserBehavior/`
   - 依赖：需要 `user_behaviors` 集合

## 🗄️ 数据库集合

需要创建以下集合：

### user_behaviors
用于存储用户行为数据，字段结构：
```javascript
{
  userId: String,        // 用户OpenID
  action: String,         // 'view', 'collect', 'purchase', 'share', 'search'
  targetType: String,     // 'product', 'collection', 'activity', 'framer'
  targetId: String,       // 目标ID
  timestamp: Number,      // 时间戳
  createdAt: Date,        // 创建时间
  category: String,       // 分类（可选）
  tags: Array,            // 标签（可选）
  ...extra                // 其他额外信息
}
```

## 🎨 UI展示

- 位于"最新入库"模块之前

- 支持横向滚动浏览

### 推荐卡片设计
- 卡片尺寸：280rpx × 400rpx
- 图片区域：280rpx × 280rpx
- 信息区域：标题、拉丁名、价格
- 推荐理由标签：左上角显示

## 🔧 使用说明

### 缓存使用
```javascript
const { setCache, getCache, clearCache } = require('../../utils/cache');

// 设置缓存
setCache('BANNERS', banners);

// 获取缓存
const cached = getCache('BANNERS');

// 清除缓存
clearCache(); // 清除所有
clearCache('BANNERS'); // 清除指定缓存
```

### 用户行为追踪
```javascript
// 在页面中调用
this.trackUserBehavior('view', 'product', productId);
this.trackUserBehavior('collect', 'product', productId);
```
