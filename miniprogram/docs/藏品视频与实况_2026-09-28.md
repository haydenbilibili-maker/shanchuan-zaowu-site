# 藏品视频与实况（Live）· 2026-09-28

> **产品负责人点名**：「超管-藏品库-商品图片上传支持 Live/视频」。
> 2026-10-18 续：ERP 藏品档案库上传入口 + 外平台视频（视频号 / B站等）见 `藏品视频_外平台与云存储评估_2026-10-18.md`。
> 本文是点名范围内的施工说明；电商链路属稳定期模块，本次只做**向后兼容扩展 + 新增旁路**，不改购买/规格/价格逻辑。

## 1. Live Photo 支持现状（结论）

| 能力 | 现状 | 依据 |
|---|---|---|
| `wx.chooseMedia` 能否拿到 Live Photo | **不能**。`tempFiles[].fileType` 只有 `image` / `video`；相册里的实况照片选出来是**静态图** | [wx.chooseMedia 官方文档](https://developers.weixin.qq.com/miniprogram/dev/api/media/video/wx.chooseMedia.html) |
| 是否有 `live-photo` 组件 | **没有**。媒体组件只有 audio / camera / channel-live / channel-video / image / live-player / live-pusher / video / voip-room（`live-player` 是实时音视频直播，与实况照片无关） | [组件总览](https://developers.weixin.qq.com/miniprogram/dev/component/) |
| 视频压缩 | `wx.compressVideo`（基础库 2.11.0+），`quality: low/medium/high` | [wx.compressVideo](https://developers.weixin.qq.com/miniprogram/dev/api/media/video/wx.compressVideo.html) |
| 选视频时顺带压缩 | `chooseMedia` 的 `sizeType` 在基础库 **2.25.0+ 对视频也生效**（本项目 3.11.2 满足）；本次保持默认值，不强制压缩图片 | 同 chooseMedia 文档 |

**因此**：本次把「实况」按 **短视频 + 封面帧** 处理 —— 店长上传一段短视频（iPhone 可在相册里把实况「存储为视频」），
在编辑区标成「实况」；详情页按实况方式展示：静音、循环、**轻点播放 / 再点暂停**、无进度条，左下角 `LIVE` 角标。
普通「视频」则带原生控件（静音起播、点击播放）。

## 2. 数据契约（向后兼容扩展，**单列报备**）

- `products.images`：**语义不变，只放图片**；`images[0]` 仍是全站封面（列表 / 首页推荐 / 购物车 / 订单 / 分享卡 / 祈福墙都读它）。
- 新增**可选** `products.media`：

```js
media: [{ type: 'video' | 'live', url, poster, duration, width, height, size }]
```

| 键 | 说明 |
|---|---|
| `type` | `video` 普通视频；`live` 实况（短视频按实况展示） |
| `url` | 云存储 fileID（`cloud://…/products/video_*.mp4`）；必须是视频扩展名 |
| `poster` | 封面帧（chooseMedia 的 `thumbTempFilePath` 一并上传）；不得是视频地址 |
| `duration` / `width` / `height` / `size` | 秒 / 像素 / 字节，仅作展示与校验 |

- 上限：**≤ 3 段、每段 ≤ 60 秒、≤ 50MB**。理由：60 秒与 `chooseMedia.maxDuration` 上限一致；50MB 在 4G 下上传约 1 分钟，
  详情页首帧只加载 poster，不影响首屏；3 段足以覆盖「整体 / 细节 / 实况」，再多会稀释主图。
- 服务端 `manageProducts`：`ALLOWED_FIELDS` 加 `media`；`prepareProductData` 里 `sanitizeProductMedia` 净化（非法项**丢弃**，
  与 tags/blessTags 同口径）；另加两道防线：`images` 里的视频地址被剥掉、`coverImage` 是视频地址时不写。
  **入参出参语义不变**（`success`/返回形状一致）；不送 `media` 的调用（如 ERP 保存）不会动库里已有视频。
- 客户端副本：`subpackages/manager/utils/productMedia.js`；服务端：`cloudfunctions/manageProducts/productMedia.js`；常量由守卫比对。

## 3. 店长端上传（藏品库 → 录入/编辑 → 基础 → 轮播图）

- 「+ 图片/视频」改用 `wx.chooseMedia` 混选（`sizeType` 保持默认 `['original','compressed']`，与原 `chooseImage` 一致，「原图」开关仍由店长选；拍摄 `maxDuration: 60`）；
  图片照旧走 `imageUploadGuard` 尺寸/体积核验进 `images`；**视频只进 `tempProduct.media`**。
- 视频校验：超 60 秒直接拒；超 50MB 先 `wx.compressVideo({ quality: 'medium' })` 再判，仍超则拒并说明原因。
- 编辑区缩略图：封面帧 + 播放角标 + 「视频/实况 时长」；支持删除、左右排序、「转实况 / 转视频」；
  **没有「封面」按钮** —— 视频不能被设为列表封面。
- 保存时上传：`wx.cloud.uploadFile` 带进度（`上传视频 N · xx%`）；失败**自动重试 3 次**（退避 0.8s/1.6s，提示「网络不稳，重试 n/2」），
  仍失败则**中止保存**并明确提示（不静默丢视频）；每传完一段立刻回写表单，再点保存时已传的不重复上传。
  （不用系统 `wx.showModal` 让人点「重试」：本页未挂 AppModal 宿主，且全站弹窗棘轮 `check:dialog-ratchet` 禁止新增原生弹窗；校验不通过的原因走页内轻提示。）
- 载荷规则：只在「有视频」或「原本有视频、被删光」时才送 `media`，避免未载入 `media` 的入口一保存就清空库里视频。

## 4. 详情页展示（新增旁路）

- 无 `media`（或空数组）：`heroSlides = []`，渲染**原来那条** `product.images` 轮播（`wx:if="{{!heroSlides.length}}"`），行为与改动前完全一致。
- 有 `media`：渲染旁路轮播 —— **首位仍是封面图**（首屏、分享图、敏感遮罩都不变），视频/实况紧随其后，其余图片在后。
  - `<video>`：`muted`、`autoplay=false`、不自动全屏（用户可手动点全屏按钮）；`object-fit: contain`。
  - 切换幻灯（`onHeroMediaChange`）与页面 `onHide` 时暂停全部视频。
  - 计数器 `imageTotal` = 幻灯数（无视频时仍等于 `images.length`）。
- 纯函数：`subpackages/feature/utils/heroMedia.js` 的 `buildHeroSlides(images, media)`。
- 不改：购买 / 规格 / 价格 / 分享 / 缓存 / `utils/imageUrl` / `utils/cache` / 埋点。

## 5. ERP

ERP 商品表单（`admin/src/App.vue`）有图片区；其保存载荷是**显式字段列表、不含 `media`** → 在 ERP 里保存藏品**不会**清掉小程序上传的视频。
只读展示视频列表本次**未做**：`App.vue` 正被多条流同时改（高冲突），且 ERP 属稳定期后台；列为待点名项。

## 7. 守卫

`npm run check:product-media`（order 域）+ `--selftest`（13 个注入在**内存副本**上做、不写盘，另加 1 个虚拟读者注入）：
images 不含视频 / 封面不取视频 / 两端常量同口径 / 编辑区视频不进 images / 载荷条件送 media /
无视频时详情页走原轮播且原轮播无 `<video>` / 首位是封面图 / 离页与切换暂停 / 全仓 `.media` 读者登记。

## 8. 真机验收清单

1. 新建藏品：只选图片 → 保存 → 详情页与改动前一致（无视频、无 LIVE 角标、计数器正确）。
2. 混选 3 图 + 1 段 20 秒视频 → 编辑区图片 3 张、视频 1 条（有封面帧、时长、播放角标、无「封面」按钮）。
3. 选一段 > 60 秒相册视频 → 被拒并提示原因；选 > 50MB 视频 → 先显示「压缩视频中…」，压完仍超则拒。
4. 保存时观察「上传视频 1 · xx%」进度；断网保存 → 出现「网络不稳，重试 1/2、2/2」→ 最终提示上传失败、表单内容仍在；恢复网络再点保存 → 成功且不重复上传已传段。
5. 详情页：首位是封面图，第 2 位是视频；静音、不自动播放、点击播放不进全屏；左右滑走即暂停；返回上一页即暂停。
6. 「转实况」后保存：详情页该项显示 `LIVE · 轻点播放`，点一下静音循环播放，再点暂停；无进度条。
7. 列表 / 首页推荐 / 购物车 / 下单 / 订单 / 分享卡封面仍是图片（不是视频、不是空白）。
8. 删掉全部视频再保存 → 详情页恢复原轮播。
9. ERP 打开该藏品改个价保存 → 回小程序详情页，视频仍在。
10. iOS / Android 各测一次；敏感模糊藏品（蛇等）遮罩下视频不可见、揭开后可播。

## 9. 需产品负责人点名的项

- **ERP 只读展示视频列表**（成本低但 `App.vue` 高冲突、属稳定期后台）。
- 视频在详情页的**位置**：本次固定「封面之后」；如需「首位」或可指定位置，需再点名（会影响首屏与分享图口径）。
- 是否允许在**规格（SKU）图**里放视频：本次不支持（SKU 图参与下单/订单快照，属电商核心链路）。
