### 改动

1. **【P0 单列报备】馆藏筛选卡死**：`pages/category/index.js` `onFilterConfirm` 的 `const applied` → `let applied`（一词改动，行为即原本意图）。
   新守卫 **`check:mp-const-assign`**：esbuild 逐个转译小程序全部 JS，出现「必然抛错的 const 赋值」即红；esbuild 不可用 exit 2。自检 3 注入 + 2 不误报。
2. **主包回到推荐线内**：把 5 个主包文件（`utils/wishWall.js`、`components/WishWallEntry/index.js`、`utils/productStats.js`、`utils/easterEgg.js`、`pages/index/index.js`）里超长块注释的**原文**迁到 `miniprogram/docs/源码注记_A流主包.md`（docs 不入包），源码保留首行摘要、全部「⚠️」约束行和「注记 编号」指针。
   核对：迁移脚本对每个文件比较 esbuild 压缩产物，**前后逐字节一致**（代码零改动）。`test:sold-display` 断言源码注释里要写明 `b2bFulfillment` 契约 → 该契约两行保留在源码。
   只迁「无逐字节副本」的文件：`config/blessTags.js`、`config/productTaxonomy.js`、`utils/wishTextCount.js` 有云函数 / ERP 副本，不动。
3. **首页 scroll-view 下拉刷新**：`refresher-enabled`（单页模式关）+ 暗底白色指示器；回调 `onHomeRefresherRefresh` 复用 `onPullDownRefresh` 同一套重置（清缓存 + 重拉），防重入，8 秒兜底收起；`onPullDownRefresh` 改为返回 Promise。
4. **首页去占位文案**：banner 副标题、专题简介为空时整行不渲染。
5. **馆藏筛选无结果空态**：「没有符合这些条件的藏品 / 放宽价格或工艺试试，或回到本馆全部 / 【清除筛选】」，按钮等同面板里「重置 → 确定」；未筛选时的空态文案改为「这一类藏品正在整理中」。
6. **工坊**：伴宠描述改为「为陪伴过的伙伴留存纪念，专员评估工艺周期」（两行收住）；进度磁贴补 `hover-class`。
7. **首页活动定位图标**改为 `--color-text-secondary` 同色 `#A09A90`。

### 真机验证点

- 首页：顶部向下拉 → 出现白色转圈、松手后内容刷新、转圈自动收起；连续快速下拉不重复请求。单页模式（朋友圈打开）不出现下拉。
- 馆藏：「全部」tab → 筛选 → 选「昆虫」→ 确定：面板关闭、顶部切到昆虫、底栏恢复（P0 回归点）。
- 馆藏：筛到 0 件 → 点「清除筛选」→ 回到本馆全部并提示「已清空筛选」。
- 工坊：按住「伴宠工单 / 定制订单」有压暗反馈。
