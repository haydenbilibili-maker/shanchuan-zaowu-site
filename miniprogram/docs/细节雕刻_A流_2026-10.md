### 1. 全局按压态（`app.wxss`）

```css
.tap-press, .wb-press { opacity: 0.72 !important; }   /* 按钮 / 图标 / 链接 */
.tap-press-soft { opacity: 0.86 !important; }         /* 卡片 / 整行 / 大面积块 */
```

- 用法：`<view bindtap="…" hover-class="tap-press" hover-stay-time="80">`。view 上的 `:active` 真机不稳，**新代码一律 hover-class**。
- `!important` 是必要的：页面里 `.x:active` 特异性 (0,2,0) 高于单类，不加压不住。
- `wb-press` 是 C 流工作台的旧名（8 份同值副本），作为别名收进全局，C 流删副本后页面不用改。
