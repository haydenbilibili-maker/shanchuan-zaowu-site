## 一、品牌精神

### 1.1 品牌定位

山海造物是一个自然美学生活方式品牌。我们在自然与人之间建立联系，让自然之美通过标本这个介质、以美学的方式进入普通人的生活。

**核心递进**

自然 → 标本 → 美艺 → 生活

**品牌心智**

「把山海带回家」

### 1.2 品牌调性矩阵

以下矩阵定义了山海造物在各个维度上的气质定位，所有视觉和文字输出都应落在这个范围内。

| 维度 | 我们是 | 我们不是 | 参照 |
|------|--------|----------|------|
| 温度 | 温和、亲切、有人情味 | 冰冷、科技感、机械 | 观夏的温度感 |
| 分寸 | 克制、留白、少即是多 | 繁复、过度装饰、叫嚣 | 无印良品的克制 |
| 深度 | 有知识底蕴、值得细看 | 花哨、网红感、快消费 | 国家地理的权威感 |
| 材质感 | 自然、纹理、触感丰富 | 塑料感、光滑、工业化 | 手工实木家具的质感 |
| 话语 | 朋友在分享美的东西 | 老师在授课/销售在推销 | 李子柒的写作语感 |

### 1.3 品牌名称规范

| 项目 | 规范 |
|------|------|
| 中文全称 | 山海造物 |
| 英文全称 | Nature's Creations |
| 英文大写（用于标志） | NATURE'S CREATIONS |
| Tagline 中文 | 把山海带回家 |
| Tagline 英文 | Bring Nature Home |
| 品牌理念线 | 自然 · 标本 · 美艺 · 生活 |

**禁止用法**

- 不得缩写为「SCRW」「山海」。
- 不得将中英文名混用于同一行（如「山海造物 Nature's Creations」），应分行排列。

## 二、品牌标志

### 2.1 主标志：山海印章

主标志采用圆形印章形态，内部为几何化的山峰轮廓与河流弧线。气质偏东方、偏人文，在不同尺寸下均可识别。

标志有四个版本：**标准版**（印章+文字）、**纯图形版**（仅印章）、**反白版**（用于深色背景）、**单色版**（用于烫印/雕刻）。

### 2.2 标志使用规范

**最小尺寸**

- 标准版：印章直径 ≥ 12mm。
- 纯图形版：印章直径 ≥ 8mm。
- 小于 8mm 时禁止使用标志。

**安全区域**

标志四周预留不小于印章直径 **1/4** 的空白。安全区域内不得放置任何其他元素。

**可用背景**

白色 / 微暖白 `#FAFAF5` / 其他素色浅色背景。深色背景必须使用反白版。禁止在复杂图案或照片上直接叠加。

**对齐方式**

印章与文字始终垂直居中对齐。文字位于印章下方，间距为印章直径的 **1/6**。

### 2.3 标志禁止用法

| ✓ 正确用法 | ✗ 禁止用法 |
|------------|------------|
| 保持原始比例，不拉伸不变形 | 拉伸、压缩、旋转、斜切标志 |
| 素色背景上使用标准色版本 | 在花纹/照片上直接叠加标志 |
| 深色背景上使用反白版 | 改变标志颜色（如变为红色、金色） |
| 保持安全区域内无其他元素 | 给标志加投影、发光、立体效果 |
| 标本框角落烫印用单色版 | 在标志旁边添加装饰元素 |
| 与产品名并排时，标志在左/上 | 将标志作为文字的一部分嵌入句子中 |

### 2.4 辅助标志：品类纹理图案

每个产品品类拥有一个从自然纹理中提取的抽象图案，用于包装内的品类标签和小程序分类图标。

| 品类 | 纹理意象 |
|------|----------|
| 昆虫类 | 羽翼鳞片排列纹理 |
| 矿石类 | 矿石断面/晶体结构 |
| 植物类 | 年轮同心圆/叶脉 |
| 海洋/化石类 | 螺旋纹理/水波纹 |

## 三、品牌色彩

### 3.1 主色彩体系

| 角色 | 名称 | HEX |
|------|------|-----|
| 自然绿（主色） | Primary | `#2D6A4F` |
| 大地棕（辅助） | Earth | `#8B6F47` |
| 矿物紫（点缀） | Mineral accent | `#7B68AE` |
| 微暖白（底色） | Warm white | `#FAFAF5` |
| 墨绿黑（文字） | Text dark | `#2C2C2C` |

### 3.2 用色规则

- **自然绿**：用于标志、标题、强调元素、按钮。占视觉面积 ≤ 30%。不大面积填充背景。
- **大地棕**：用于副标题、拉丁学名、温暖感点缀。传达手工与大地的联系。不作为主色单独使用。
- **矿物紫**：仅用于矿石品类标识和少量视觉强调。不在非矿石产品的包装或宣传中使用。
- **微暖白**：所有背景的默认色。**禁止使用纯白 `#FFFFFF` 作为背景**，微暖白更自然、更有纸张质感。

### 3.3 品类专属色

| 品类 | HEX |
|------|-----|
| 昆虫 | `#52B788` |
| 矿物 | `#7B68AE` |
| 植物 | `#6DA34D` |
| 海洋/化石 | `#5B8FB9` |

## 四、字体规范

### 4.1 字体选择

品牌字体追求「有手感的现代宋体或人文无衬线」。参照观夏、三顿半的字体气质：既有文化厚度又不老气，既克制又不冰冷。

### 4.2 字体层级与场景（印刷/物料基准）

| 层级 | 应用场景 | 字号 | 字重 | 色彩 |
|------|----------|------|------|------|
| 品牌名 | 门店招牌、包装主视觉 | 根据场景 | Medium | 自然绿 `#2D6A4F` |
| 主标题 | 系列名、类别名 | 16–20pt | Medium | 墨绿黑 `#2C2C2C` |
| 物种中文名 | 品牌卡片、产品页 | 13–16pt | Medium | 自然绿 `#2D6A4F` |
| 拉丁学名 | 品牌卡片、产品页 | 9–11pt | Regular Italic | 大地棕 `#8B6F47` |
| 正文 | 科学冷知识、品牌故事 | 9–11pt | Regular | 墨绿黑 `#2C2C2C` |
| Tagline | 包装、门店、物料 | 7–9pt | Regular | 浅灰 `#A0A0A0` |

## 五、产品摄影规范

产品摄影是品牌视觉的核心载体。线上商城、社交媒体、印刷物料中的产品图片必须遵守以下规范。

### 5.1 主图（电商/小程序商城）

| 项目 | 要求 |
|------|------|
| 背景 | 统一微暖白 `#FAFAF5` 纯色背景。禁止使用渐变、纹理、场景化背景。 |
| 光线 | 柔和自然光，从左前方主光源。避免硬光、避免强反光（特别是玻璃罩产品）。追求「窗边自然光」的感觉。 |
| 角度 | 玻璃罩产品：正面微俯视 15°；相框产品：正面平视；首饰：45° 俯拍。 |
| 留白 | 产品占画面约 60–70%，四周留有充足的呼吸空间。不要填满画面。 |
| 投影 | 保留自然柔和投影，不要完全去除。 |

### 5.2 场景图（社交媒体/内容营销）

- **场景选择**：书房、窗台、客厅架子、办公桌、咖啡店。必须传达「标本在生活中」，而非博物馆货架感。
- **配饰元素**：允许绿植、书籍、咖啡杯、原木家具、棉布纹理。禁止塑料制品、光滑金属、鲜艳色块、与品牌调性不吻合的物件。
- **色调**：整体偏暖调，饱和度轻微降低。禁止高饱和、高对比的「网红风」修图。
- **人物出镜**：允许手部入镜；不需露脸，保持产品主体地位。

### 5.3 门店环境摄影

追求「自然博物馆奇妙柜」氛围：视觉密度高、物件丰富、光线温暖。保留绿植、木质家具、纹理墙面等环境元素。

## 六、文案语气规范

适用于：产品描述、社交媒体、小程序、印刷物料、门店标识。

### 6.1 语气原则

| ✓ 山海造物的语气 | ✗ 不是山海造物的语气 |
|------------------|----------------------|
| 像朋友在分享一个有趣的发现 | 像老师在考你的知识 |
| 「你知道吗，这只蝶的蓝其实不是颜料」 | 「光的衍射原理表明纳米级鳞片结构…」 |
| 用具体的感官细节建立画面 | 用抽象的形容词堆砌情感 |
| 「放在窗台边，午后的光会穿过羽翼」 | 「绝美的自然艺术品，限量收藏！」 |
| 克制、留白、说一半留一半 | 过度推销、逼单、制造紧迫感 |

### 6.2 产品描述模板（三层结构）

| 层级 | 内容 | 示例（蓝闪蝶） |
|------|------|----------------|
| 第一层：事实 | 物种名 + 产地 + 一句话科学事实 | 「蓝闪蝶 Morpho menelaus，产自南美亚马逊流域。羽翼不含任何蓝色色素。」 |
| 第二层：感受 | 这件产品在你生活中的画面 | 「放在书架上，午后的光穿过羽翼，每个角度的蓝都不一样。」 |
| 第三层：连接 | 你和这件自然之物的关系 | 「一座雨林里的光，现在就在你手边。」 |

### 6.3 社交媒体文案规范

- **开头禁止**：禁止以 emoji 开头；禁止以叹号、问号开头；禁止「亲们」「宝子们」等电商话术。
- **推荐开头**：以具体事实或画面开头。
- **标签**：固定 `#山海造物` `#把山海带回家` `#NaturesCreations`；可选 `#标本艺术` `#自然美学` + 物种标签。
- **水印**：发布图片须带品牌水印（印章 logo，右下角，白色，透明度 20%）。

## 七、产品命名体系

### 7.1 标品命名规则

**结构**：系列名 + 产品类型 + 规格。

- 系列名：「蓝」「翠」「彩」「奇」
- 产品类型：玻璃罩 / 相框 / 冰箱贴
- 规格：S / M / L

示例：「蓝·玻璃罩·M」= 蓝闪蝶系列中号玻璃罩。「奇·相框·S」= 甲虫/非蝶类小号相框。

### 7.2 集合框命名

三个主题：「山林·集」「海岸·集」「四季·集」。不用「集合框」「标本画」等通用名称。

### 7.3 展陈线高端标本命名

每件高端标本应有独立名字（角色名/意象名），而非仅物种名。手册示例包括「绅士先生」「暗夜女伯爵」「守夜人」等。

## 八、包装规范

### 8.1 品牌卡片

- **尺寸**：90 × 54mm（标准名片）
- **纸张**：350 克棉纸或自然纹理特种纸，无涂布
- **正面**：山海印章 logo（可凹印）+「山海造物」+「把山海带回家」。单色印刷（自然绿 `#2D6A4F`）。
- **背面**：中文物种名（13pt、品牌绿）+ 拉丁名（9pt、大地棕斜体）+ 产地 + 一句话科学冷知识。四色印刷。
- **工艺**：印章区可做凹印（blind deboss），强化触觉。

### 8.2 内包装规范

- **盒型**：天地盖；灰板裱糊特种纸，表面细微纹理。
- **盒面**：仅 logo + 产品名，不印产品图；颜色暖灰或亚麻色。
- **内衬**：深墨绿绒布或定制 EVA 泡棉；标本框嵌入，旁放品牌卡片。
- **开箱**：「外素内美」反差，兑现「把山海带回家」。

### 8.3 外包装

- **手提袋**：牛皮纸袋，印 logo，底部「把山海带回家」；提手棉绳或麻绳。
- **快递箱**：瓦楞箱 + 品牌胶带（NATURE'S CREATIONS），可降解缓冲材。
- **箱内卡片**：「你手中这件标本来自____（产地），经过____道手工工序制作。感谢你给它一个新家。」

## 九、门店视觉规范（SI）

### 9.1 门头

- **材质**：原木（白橡或胡桃木）或暗色金属（黑/古铜）。禁止 LED 灯箱、亮色丙烯、发光字。
- **内容**：山海印章 logo +「山海造物」+「NATURE'S CREATIONS」。不加其他信息。
- **灯光**：暖白光 3000–3500K。不用冷白光或彩色灯光。

### 9.2 店内环境

- **氛围**：「自然博物馆奇妙柜」——视觉密度高、温暖、探索感。
- **家具**：原木展柜、黄铜拉手、麻布/棉布衬底。禁止不锈钢、白色烤漆、亮面塑料。
- **绿植**：必须有活体绿植（如蕨类、文竹、龟背竹、阔叶植物等）。禁止塑料假花。
- **音乐**：低音量环境乐或自然白噪音。禁止流行、电子。
- **气味**：柑橘/雪松/木质等自然系香氛，淡而不浓。
- **价签**：与品牌卡片同风格纸张；可手写黑笔。
- **员工着装**：素色围裙或工作服，左胸印章 logo；色限墨绿、灰棕、亚麻。

### 9.3 门店即博物馆：六区体验动线（摘要）

设计哲学：服务「发现」而非单纯「交易」；目标停留 15–30 分钟。

1. **入口惊奇**（0–10 秒）：店外可见大型锚定标本；灯光与材质从商场过渡到暖色与木质。
2. **发现台**（1–3 分钟）：腰高中央展台，低价位可触摸 SKU。
3. **画廊墙**（3–8 分钟）：整墙框装标本，轨道射灯，铜牌信息。
4. **奇珍柜**（5–15 分钟）：玻璃门木柜臻品，需店员开柜。
5. **自然物料吧**（5–20 分钟）：散装天然物触摸区，棉布袋自选。
6. **出口赠礼**（最后 2 分钟）：包装仪式与交接话术。

### 9.4 感官设计系统（摘要）

视觉：暖色灯光，木+绿+黄铜，禁止荧光灯/白层压板/塑料。触觉：原木、亚麻、无涂布纸。嗅觉：统一淡香。听觉：自然声或安静器乐。

### 9.5 内容自生成设计（摘要）

每区可有「拍照时刻」，但应自然发生；显性品牌触点控制在入口背景板与结账手提袋等少数位置。
