## 2. 规则改动（本次落地）

### 2.1 `receiveCoupon`（已部署，部署前线上 = origin/main，部署后复比一致）

- **新增可选字段 `fixedExpireTime`**：有它 → 用户券到期 = `min(fixedExpireTime, 领取时刻 + expireDays 天)`（`expireDays` 为 0 时只看固定到期）。

## 3. 三种场景的行为（取证 + 守卫实跑）

| 场景 | 能否用 | 怎么算 / 怎么用 |
|---|---|---|
| 线上普通单 | ✅ | 商品详情页「礼券」抽屉 →「可领取」→ 领取；结算页自动选**本单最省**的一张（与新客礼券互斥，一单一张） |
| 礼赠单 | ✅ | 与普通单同一计价 + 同一锁券流程（`makeOrder` 礼赠分支不屏蔽礼券） |
| 门店核销 | ✅（人工按折扣收款） | `verifyStoreCoupon` 校验状态 / 到期 / 渠道后核销；**折扣不由系统计算**，店员按 8 折收款，**门店不执行 75% 地板** |

- **到账方式**：10-30 00:00 起自动发到注册会员券夹（§6）。**备用领取入口**：商品详情页的礼券抽屉（`getProductCoupons` 的「可领取」）——
  未注册 / 自动发放前就进来的人可在这里领；已到账的人在抽屉里看到「已领取」（券锁在待付单期间会短暂显示「领取」，点了提示「每人限领1张」，属展示差异）。
- 退款 / 取消 / 支付超时：锁定或已用的券按原流程退回为「未使用」（到期仍是 11-15 23:59:59）。
