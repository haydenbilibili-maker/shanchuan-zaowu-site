# 山海图鉴 · 卷一重设计（2026-10-17）

> 产品负责人：「大开大阖重新规划与设计生成山海图鉴模块」。
> 范围：图鉴首页 `feature/collection`、图版详页 `collection/detail`、采集日志 `collection/log`。
> **不动**：`manageAtlas` 云函数与出入参、图鉴目录内容与解锁规则、路由与深链（`?spot=` 印记进页）、埋点事件名、分享路径、解锁仪式弹层。

## 1. 改前诊断

| 问题 | 证据 |
|---|---|
| **一本没有图的图鉴** | 目录（`atlasCatalog.js` / 云端 `catalog.js`）不带任何图片；卡面图版区只写一行「SPECIMEN」 |
| 筛选比内容还重 | 系列 / 门类 / 稀有度三行筛选叠在卡片上方，首屏几乎看不到一张卡 |
| 进度没有「书」的感觉 | 一条百分比进度条 + 两列瀑布流；点亮的卡被往前排，「缺哪几页」看不出来 |
| 语言不统一 | 深色卡 + 门类色条 + 稀有度点阵，与全站新语言（博物黑 + 纸质标本签）脱节 |

## 2. 新结构：一本「博物志 · 卷一」

1. **卷首**：眉标「ATLAS · VOL. I · 卷一」+ 宋体大标题；进度写成大号数字「6 / 16 页已翻开」+ **每页一格的刻度条**（顺序 = 编号顺序，亮 = 已翻开）；一句事实性的下一步（「还差 10 页，其中 3 页藏在馆内印记里」），不催。
2. **卷章**：三个系列（霜降守望 / 越冬者 / 守山者）= 三章，发丝线行 + 各自进度 / 「已齐」；点一章只看这一章。
3. **图版**：一行门类（带各自进度 3/10）+ **三列标本册**。
   - 已点亮 = 浅纸标本签（顶边铜别针 + 内发丝框 + 刻版线描 + 名称 / 学名 + 编号；稀有 / 传奇写在角上，传奇加铜色内框）；
   - 未点亮 = 虚线空位，只露编号（+「馆内可寻」）；
   - **按编号固定位置**：点亮的页就地亮起、不往前挤 —— 「缺的那几格」本身就是收集的动力。
4. **近期足迹**：最近三笔，「全部 ›」进采集日志。
5. **底栏**：发现印记（描边）+ 拍照采集（本屏唯一实心金）。

门类与卷章互斥（叠在一起时空页的原因说不清）；稀有度筛选行退场（稀有度已在图版角上）。

## 3. 刻版线描（`subpackages/feature/utils/atlasPlates.js`）

图鉴没有实拍图，用**博物志铜版画口吻**的单色线描补上：九种版式按物种形态分 ——
闪蝶（圆翅）/ 凤蝶（尾突）/ 蛱蝶（折角，含枯叶蛱蝶）/ 银杏 / 莲 / 鹦鹉螺（对数螺线 + 隔壁，几何由方程生成）/ 唐冠螺 / 水晶簇 / 萤石。

- 物种 → 版式只登记在本地（`SHAPE_BY_SPECIES`），新物种未登记时按门类回落；**不改云端契约**；
- 只给**已点亮**的页（未点亮不剧透形态）；
- 微信 `<image>` 不渲染 .svg 文件 → 用 `data:image/svg+xml` URI；九张合计约 6 KB，落在 feature 分包。

## 4. 图版详页 / 采集日志

- 详页：一整张浅纸标本签（PLATE No. + 稀有角标 + 大幅线描 + 宋体名称 + 斜体学名 + 门类 · 卷章 · 馆内印记）；那段话改宋体宽行距；产地 / 习性 / 柜位 / 印记码改发丝线两栏行；关联藏品与采集记录去卡片；底栏改实底。未点亮 = 大号编号虚线空位。
- 日志：眉标 + 宋体主标；「鉴定记录 / 采集笔记」改下划线页签（原来是两块实心金按钮）；统计改两个大数字。

## 5. 守卫

`check:atlas-plates`（home 域，169 → 170）：每个物种（小程序副本 + 云端 catalog）都有版式且为合法 SVG data URI；未点亮不给图、WXML 未点亮分支不渲染名称 / 学名 / 图版；真跑 `applyPack` 标本册按编号固定位置、刻度一一对应；门类与卷章互斥。7 个内存注入，不写盘。
离线预览：`render-core-flows-preview.mjs --only atlas,atlas-detail,atlas-locked`。

## 6. 真机验证点 / 后续

- data URI SVG 在 iOS / 安卓 `<image>` 上的线宽与清晰度；
- 三列图版在小屏（320 宽）名称是否需要再收字号；
- **后续可选**：给目录补实拍（云端 catalog 加 `image` 字段 + 后台维护）后，点亮页可在线描下叠实拍 —— 需改云端契约，本轮不做。
