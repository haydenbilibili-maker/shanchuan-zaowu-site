## ⚠ 分享卡片封面：不能用 `cloud://`（2026-09-16 用户反馈修复）

**现象**：分享到微信会话时，卡片**图片区域是黑块**（标题正常，如「山海造物 · 把山海带回家」）。

**根因**：微信分享卡片的 `imageUrl` **只接受本地路径或 https 地址**，**不接受 `cloud://` fileID**。
`subpackages/business/about/index.js` 当时直接把 `cdnPath('banners/DSC00115.JPG')`
（返回值形如 `cloud://cloud1-…/banners/DSC00115.JPG`）当 `imageUrl` 传出去 → 渲染成黑块。

**关键取舍**：省略 `imageUrl` 时微信会**退回页面截图**作封面，比黑块好看得多。
所以**「传一个加载不出来的地址」比「不传」更差** —— 解析失败必须留空，不能兜底成 fileID。

**修法**：统一走 `utils/util.js` 的 `resolveShareImage(src)`

| 输入 | 返回 |
| --- | --- |
| https / 本地路径 | 原样返回 |
| `cloud://…` | 解析成 https（复用 `batchTempFileURLs` 的 50 分钟内存缓存） |
| 解析失败 / 空 | `''` → 微信自动截图（**不要**回退成 fileID） |

因 `onShareAppMessage` 不应依赖异步（分享面板是同步取值），采用**预解析**：
页面数据加载完成后 `this.hydrateShareImage(coverField)` 解析好存进 `data.shareImageUrl`，
分享处理里**同步**取用；没有就不带 `imageUrl`。

已修页面：`business/about`（用户反馈的那页）、`business/framer`、`feature/articles/detail`、
`feature/collection/detail`。另有 `business/framer-recruit` 早已自行 `getTempFileURL`（正确范式），
`feature/collection/log`、`feature/live/watch`、`feature/identify/result` 在数据层就解析过（安全）。

**守卫**：`npm run check:share-image`
- 硬失败：任何分享 `imageUrl` 直接是 `cdnPath(...)` 或裸 `cloud://` 字面量；
- 待复核棘轮：静态无法确认来源的表达式进 `scripts/share-image-baseline.json`，**只拦新增**；
- `--selftest` 11 项（含「未知表达式不得误判为硬失败」「同一文件两个分享函数不重复报」）。

**仍需人工**：分享卡片无法在无头环境触发，**卡片实际观感必须真机分享一次确认**
（本守卫只能保证「不再传 `cloud://`」）。

## 🎯 功能说明

### 分享方式

1. **微信好友分享**
   - 用户点击底部"分享"按钮
   - 或点击右上角菜单 → 转发给朋友
   - 自动记录分享行为
   - 分享成功获得5积分

2. **朋友圈分享**
   - 用户点击右上角菜单 → 分享到朋友圈
   - 自动记录分享行为
   - 分享成功获得5积分

### 分享内容

- **标题**：`{商品名称} | 山海造物`
- **路径**：`/pages/detail/index?id={商品ID}`
- **图片**：商品主图

### 分享奖励

- 每次分享成功获得 **5积分**
- 积分通过 `earnPoints` 云函数发放
- 奖励原因：`分享藏品`

## 📊 数据记录

### 分享行为记录

分享行为会记录到 `user_behaviors` 集合：

```javascript
{
  userId: String,        // 分享用户ID
  action: 'share',      // 行为类型
  targetType: 'product', // 目标类型
  targetId: String,     // 商品ID
  shareType: 'wechat' | 'timeline', // 分享类型
  timestamp: Number      // 时间戳
}
```

### 分享统计

可以通过查询 `user_behaviors` 集合统计：
- 总分享次数
- 各商品分享次数
- 用户分享排行
- 分享转化率（分享 → 查看 → 购买）

## ⚠️ 注意事项

1. **分享权限**
   - 需要在 `pages/detail/index.json` 中启用：
     ```json
     {
       "enableShareAppMessage": true,
       "enableShareTimeline": true
     }
     ```

2. **分享图片**
   - 分享图片需要是网络图片（https）
   - 云存储图片需要转换为临时URL

3. **分享统计**
   - 分享行为异步记录，不阻塞分享流程
   - 记录失败不影响分享功能

4. **积分奖励**
   - 积分奖励异步发放
   - 可能存在重复奖励的情况（需要去重逻辑）
