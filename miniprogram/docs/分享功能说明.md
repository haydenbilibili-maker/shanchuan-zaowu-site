# 分享功能说明

## ✅ 已完成功能

### 1. 基础分享功能
- ✅ 微信好友分享（`onShareAppMessage`）
- ✅ 朋友圈分享（`onShareTimeline`）
- ✅ 分享行为记录
- ✅ 分享奖励（积分）

### 2. 分享统计
- ✅ 记录分享类型（微信好友、朋友圈）

- ✅ 记录分享用户

## 📋 部署步骤

### 1. 部署云函数（可选）

如果需要生成分享卡片，需要部署：
```
cloudfunctions/generateShareCard
```

**注意**：当前版本使用微信原生分享，不需要此云函数。

### 2. 确保用户行为追踪已部署

分享功能依赖 `trackUserBehavior` 云函数，确保已部署。

### 3. 确保积分系统已部署

分享奖励依赖 `earnPoints` 云函数，确保已部署。

## 🎯 功能说明

### 分享方式

1. **微信好友分享**
   - 用户点击底部"分享"按钮
   - 或点击右上角菜单 → 转发给朋友
   - 自动记录分享行为
   - 分享成功获得5积分

2. **朋友圈分享**
   - 用户点击右上角菜单 → 分享到朋友圈
   - 自动记录分享行为
   - 分享成功获得5积分

### 分享内容

- **标题**：`{商品名称} | 山海造物`
- **路径**：`/pages/detail/index?id={商品ID}`
- **图片**：商品主图

### 分享奖励

- 每次分享成功获得 **5积分**
- 积分通过 `earnPoints` 云函数发放
- 奖励原因：`分享藏品`

## 📊 数据记录

### 分享行为记录

分享行为会记录到 `user_behaviors` 集合：

```javascript
{
  userId: String,        // 分享用户ID
  action: 'share',      // 行为类型
  targetType: 'product', // 目标类型
  targetId: String,     // 商品ID
  shareType: 'wechat' | 'timeline', // 分享类型
  timestamp: Number      // 时间戳
}
```

### 分享统计

可以通过查询 `user_behaviors` 集合统计：
- 总分享次数
- 各商品分享次数
- 用户分享排行
- 分享转化率（分享 → 查看 → 购买）

## 🔧 代码实现

### 详情页分享

```javascript

  // 记录分享行为
  // 返回分享配置

// 朋友圈分享

  // 记录分享行为
  // 返回分享配置
}

// 触发分享

  // 显示提示，引导用户使用系统分享

```

### 分享按钮

在 `pages/detail/index.wxml` 中：

```xml
<view class="icon-btn" bindtap="triggerShare">
  <view class="bar-icon">📤</view>
  <text class="bar-txt">分享</text>
</view>
```

## ⚠️ 注意事项

1. **分享权限**
   - 需要在 `pages/detail/index.json` 中启用：
     ```json
     {
       "enableShareAppMessage": true,
       "enableShareTimeline": true
     }
     ```

2. **分享图片**
   - 分享图片需要是网络图片（https）
   - 云存储图片需要转换为临时URL

3. **分享统计**
   - 分享行为异步记录，不阻塞分享流程
   - 记录失败不影响分享功能

4. **积分奖励**
   - 积分奖励异步发放
   - 可能存在重复奖励的情况（需要去重逻辑）
