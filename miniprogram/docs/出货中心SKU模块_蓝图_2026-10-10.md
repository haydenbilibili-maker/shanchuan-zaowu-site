> 产品负责人原话：「出货中心新增SKU维护模块，将目前的资料、新建SKU等模块进行一次大的整合，建立新的SKU模块；」
> 范围：小程序 超管工作台 → 出货中心（`miniprogram/subpackages/extra/shipment-ops`）。守卫：`check:shipment-sku-page` 第 I 节（settlement 域）。
> 前序：`admin/docs/出货中心_融合_2026-09-28.md`（四页签合并）、`miniprogram/docs/出货中心首批SKU导入_2026-10-09.md`（首批 15 个 SKU、草稿箱）。

## 1. 现状盘点（改前）

### 1.1 入口与页面

| 入口 | 位置 | 能做什么 | 问题 |
|---|---|---|---|
| 「资料」页签 | 出货中心第 4 个页签（店长只读） | 原材料 / 包装方式：搜索、新增、编辑、上传图片、启用 / 停用、上下排序、删除（有引用即拒） | 改价时**看不到会影响哪些 SKU** |
| 「新建 SKU」弹层 | 开单 → 选 SKU → 「新建 SKU」 | 选原材料 + 包装 + 手工费 + 造景 → 试算 → 建好后直接加进本单 | **只能新建，不能编辑**；不能写备注；不能从已有 SKU 复制 |
| 「选已有 SKU」弹层 | 开单 → 选 SKU | 只列启用的 SKU，带「待复核」标签与「只看待复核」筛选 | 只能选，**不能管** |
| 草稿箱 | 单据 → 草稿箱 | 草稿每行选 / 换 SKU（同一个选 SKU 弹层） | — |
| 旧 `shipment-sku` 页 | 旧书签 / 旧消息 | 重定向壳 → 开单「选 SKU」 | — |
| ERP「出货 SKU 目录」 | `admin/src/components/StudioSkus.vue` | 列表（含停用）、新建、编辑、停用 / 启用、删除 | 删除**不查引用**（见 §7 待决定） |

**小程序里此前没有任何地方能：** 编辑 SKU、停用 / 恢复 SKU、处理「待复核」、看 SKU 被哪些单据引用、删除 SKU。这些只能去 ERP 或跑脚本。

### 1.2 数据与云函数（**ERP 与小程序是同一份数据**）

| 数据 | 集合 | 写入方 | 说明 |
|---|---|---|---|
| SKU | `studio_shipment_skus` | `manageStudioSettlement` 的 `sku.create / sku.update / sku.remove`（仅超管） | ERP 与小程序调同一个云函数、同一个集合；**ERP 能看到停用 SKU 是因为 ERP 列表默认「全部状态」**，不是两份数据 |
| 原材料价 | `studio_material_prices` | `manageStudioSettlement` 的 `priceBook.*` | |
| 包装价 | `studio_packaging_prices` | 同上 | |
| 正式出货单 | `ops_shipments` | `manageStoreShipment` | 明细 `items[].skuId` 引用 SKU（开单时快照名称与价格，之后改 SKU 不影响旧单） |
| 草稿 / 历史备忘 | `ops_shipment_memos` | `manageStoreShipment`（`shipmentMemos.js`） | 行 `lines[].skuId` 引用 SKU；**不进任何统计** |

SKU 字段：`skuName / materialId / materialName / materialGrade / packagingId / packagingName / packagingSize / hasScene / sceneCost / laborRatePct(null=全局) / status(active|inactive) / note / sort / skuKey / deleted / createdAt|By / updatedAt|By`；
导入批次另有 `importBatch / needsReview / importRef`。

**定价不变**：SKU 不存价；单价 =（原材料 + 包装）×（1 + 手工费率）+ 造景成本，全局费率 30%，开单时快照进单据（`pricingCore.js`，两份副本逐字一致）。

## 3. 页面

### 3.1 SKU 目录（仅超管）
- 顶部：搜索（名称 / 原材料 / 包装 / 备注）+「＋ 新建」。
- 状态筛选：全部 N · 启用 N · 停用 N · 待复核 N（数字随数据）；分类下拉（取原材料的分类，数据驱动）。
- 每行：SKU 名 + 标签（待复核 / 已停用）、组成摘要（原材料·等级 × 包装·尺寸 · 造景成本 / 手工费 · 分类）、右侧系统算价（取不到显示「待核价」并给原因，不编价）。
- 点行 → SKU 详情 / 编辑弹层。

### 3.2 SKU 详情 / 编辑（同一个底部弹层；新建 / 复制 / 开单里的「新建 SKU」共用）
- 状态区：启用 / 停用、待复核、导入批次；最近修改人与时间（编辑时读取）。
- 字段：SKU 名（留空自动生成）、原材料、包装方式、手工费（全局 / 单独 %）、造景（成本）、备注。
- 实时算价：单价 + 构成（原材料 ¥ · 包装 ¥ · 手工费 ¥（费率）· 造景 ¥），与开单同一个算价接口。
- 被引用：正式单 N 张（另列已作废 / 已删除）、草稿 N 张、历史备忘 N 张。
- 操作：保存修改 · 停用 / 启用 · 标记已复核 · 复制为新 SKU · 删除（两次确认，行内提示，不弹原生对话框）。
  - **有任何引用（含作废 / 已删除单、草稿）→ 不能删，只能停用**（服务端判定，页面同时置灰提示）。
- 弹层规范：scroll-view `flex: 0 1 auto; min-height: 0` + 内联高度，整层最大 80%，`page-meta` 锁背后页面。

### 3.3 原材料 / 包装方式
- 功能与原「资料」页签逐项一致（含图片、排序、有引用拒删）。
- 编辑已有条目时显示：「影响 N 个 SKU 的算价（其中启用 M 个）；已开的单据不受影响」。停用条目的提示同样带 N。

## 4. 云函数

不改既有 action 的入参 / 出参 / 语义。新增（`manageStoreShipment`，**全部仅超管**，沿用文件内既有 `requireSuperAdmin` → `staffGuard.assertStaff({ requireSuperAdmin: true })`，不改共享件）：

| action | 入参 | 出参 / 行为 |
|---|---|---|
| `skuAdmin.refs` | `{ id }` 或 `{ ids: [] }`（≤ 200） | `refs[id] = { shipments, cancelledShipments, deletedShipments, drafts, otherMemos, total }`；单个 `id` 时另回 `meta`（创建 / 修改 / 复核人与时间） |
| `skuAdmin.removeIfUnused` | `{ id }` | 有任何引用 → `success:false, code:'IN_USE', refs`，零写入；无引用 → 软删（`deleted / deletedAt / updatedAt / updatedBy`，与 `sku.remove` 同形态） |
| `skuAdmin.markReviewed` | `{ id }` | `needsReview:false` + `reviewedAt / reviewedBy / updatedAt / updatedBy`；其它字段不动；已复核则 `noop` |

- 放在 `manageStoreShipment`：草稿集合按约定只允许 `shipmentMemos.js` 读写（防止进统计），引用计数需要读草稿，所以计数函数写在 `shipmentMemos.js` 里导出、由新文件 `skuAdmin.js` 调用。
- 编辑 / 新建 / 停用仍走 `manageStudioSettlement` 的 `sku.create / sku.update`（已是仅超管、已记 updatedBy / updatedAt、部分更新不冲掉待复核）。
- 小程序**不再调用** `sku.remove`（无引用检查）。

## 5. 兼容策略

- **不改生产数据**，不批量改库；上线后由人工在界面里维护。
- 读时兜底：旧 SKU 没有 `note / needsReview / createdBy` 等字段 → 显示为空，不报错；`laborRatePct` 为 null 显示「用全局 N%」。
- 停用 SKU：开单「选 SKU」只取 `status:'active'`（不变）；草稿选 SKU 同一弹层；已开单据显示快照，不受影响。
- 删除后的 SKU：旧单仍显示快照名称；草稿里引用的 SKU 不允许删（只能停用）。
- 小球玻璃罩 5 个停用 SKU 在「停用」筛选里可见，可在界面直接「启用」（等价于 `--unhold-ball` 的启用部分，备注需手工去掉「玻璃罩尺寸待确认」）。

## 6. 守卫（`check:shipment-sku-page` 第 I 节，条目不增）

- 停用 SKU 不进开单选择器：`sku.list` 运行时 `status:'active'` 排除停用；页面选择器必须传 `status:'active'`。
- 被引用 SKU 不可删除：正式单 / 已作废单 / 已删除单 / 草稿任一引用 → `IN_USE` 且零写入；无引用才软删；页面删除只走 `skuAdmin.removeIfUnused`，不得调 `sku.remove`。
- 新 action 有超管校验：静态（分发走 `requireSuperAdmin`）+ 运行时（店长调用被拒、零读写）。
- 算价公式未变：运行时 `quotePrice`（10 + 5）× 1.3 + 2 = 21.50 元 / 件、2 件 43.00 元；两份 `pricingCore.js` 逐字一致。
- 每条判据都有注入自检（`check:shipment-sku-page:selftest`，本节新增 17 条，合计 74 条）。
- 写操作记录更新人 / 时间；`markReviewed` 不动其它字段；页面不用原生弹窗。
