## 🎨 样式特点

### 搜索建议下拉框

**视觉效果**：
- 深色渐变背景（`rgba(0,0,0,0.98)` → `rgba(15,15,15,0.95)`）
- 金色边框（`rgba(212,175,55,0.35)`）
- 多层阴影 + 金色光晕
- 模糊背景（`blur(20px) saturate(180%)`）

**交互效果**：
- 滑入动画（从上方淡入）
- 左侧金色指示条（点击时显示）
- 文字变金色（点击时）
- 右移动画（点击时）

### Chip按钮（热门/历史）

**视觉效果**：
- 深色渐变背景
- 金色边框（热门搜索更亮）
- 多层阴影 + 金色光晕
- 模糊背景效果

**特殊效果**：
- 热门搜索：右上角"HOT"标签
- 流光动画（背景渐变流动）
- 点击时：背景变金色、文字变黑色、缩放效果

### 标题区域

**视觉效果**：
- 左侧6rpx金色边框（带呼吸动画）
- 底部金色下划线
- 文字阴影增强

**动画效果**：
- 边框呼吸动画（`borderGlow`）
- 下划线渐变效果

### 搜索结果卡片

**视觉效果**：
- 深色渐变背景
- 金色边框
- 多层阴影 + 金色光晕
- 模糊背景效果

**交互效果**：
- 流光扫过（点击时从左到右）
- 缩放和上移（点击时）
- 边框和阴影增强（点击时）

## 🔧 技术实现

### 动画效果

```css
/* 滑入动画 */
@keyframes slideDown {
  from { opacity: 0; transform: translateY(-10rpx); }
  to { opacity: 1; transform: translateY(0); }
}

/* 呼吸动画 */
@keyframes borderGlow {
  0%, 100% { opacity: 0.8; }
  50% { opacity: 1; }
}

/* 浮动动画 */
@keyframes iconFloat {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-10rpx); }
}
```

### 视觉效果

- **多层阴影**：营造深度感
- **金色光晕**：突出重要元素
- **模糊背景**：增强层次
- **渐变效果**：提升质感
