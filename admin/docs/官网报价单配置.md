# 官网报价单配置（Admin ↔ /price-list）

## 背景

官网 [`/price-list/`](https://shanhaizaowu.com/price-list/) 原为 Astro 静态页，数据硬编码于 `src/data/priceList.ts`（约 43 SKU），客户端筛选 + 采购篮写入 `purchase_intents`。

现对齐到 Admin，使报价可 CRUD / 上下架，并在官网运行时覆盖静态种子。

## 数据

| 层 | 说明 |
|----|------|
| 集合 `price_list_items` | 一 SKU 一文档；字段对齐 `PriceListItem` + `sort` + `status` |
| 规则 | `cloudbase/rules/price_list_items.json`（`auth != null` 读写；匿名登录可读） |
| 静态种子 | `src/data/priceList.ts`（SSR / SEO / 云端空或失败时回退） |
| Admin 种子 | `admin/src/utils/priceListSeed.json`（「同步官网种子」；图片已规范为 `https://shanhaizaowu.com/images/price-list/…`） |
| 图片字段 | `image` 主图 + `images[]` 多图；可为官网绝对 URL、相对路径或 `cloud://` 上传 fileID |

## 图片路径解析

| 形态 | 存储示例 | Admin 预览 | 官网渲染 |
|------|----------|------------|----------|
| 官网绝对 | `https://shanhaizaowu.com/images/price-list/xxx.jpg` | 直链 | 直链 |
| 相对路径 | `/images/price-list/xxx.jpg` | 拼官网 origin | 当前站 origin（或官网） |
| 云存储 | `cloud://…` | `getTempFileUrl` | 匿名 `getTempFileURL` |

同步种子默认：文字字段始终更新；**仅当 image/images 皆空时补图**。勾选「强制覆盖图片」才用种子图覆盖（含已上传的 cloud://）。

上传：编辑弹窗「上传主图 / 上传多图」→ `uploadAdminBinary(..., 'price-list')` → 写回 `cloud://`。

三处同步：`admin/src/cloud.js` → `COLLECTIONS.PRICE_LIST_ITEMS` ↔ rules ↔ schema。

## Admin

- 菜单：**业务运营 → 货 · 资产 → 报价单配置**（tab `57`）
- 组件：`admin/src/components/PriceListManager.vue`
- 能力：列表筛选、新建/编辑/删除、上下架、同步官网种子、**发布到订货价目**（`configs/b2b_catalog`）

## 官网同步链路

```
Admin 保存 price_list_items (status=active)
        ↓
用户打开 /price-list/（SSR 先渲染静态种子）
        ↓
客户端匿名登录 → where status=active → 替换表格 DOM
        ↓
失败 / 空集合 → 保留静态种子（无需重新部署即可改价；空云端则仍看种子）
```

实现：`src/lib/priceListCloud.ts` + `price-list.astro` 的 `hydratePriceListFromCloud()`。

**无需**为改价重新跑 Astro build；部署 Admin 后刷新官网即可。若从未「同步官网种子」且云端为空，访客仍见静态种子。

## Provision

```bash
cd admin && npm run provision:price-list
# 或
cd admin && npm run provision:all
```

密钥：`admin/.env` 中 `TCB_SECRET_ID` / `TCB_SECRET_KEY`。

## 验收

1. Admin 打开「报价单配置」→「同步官网种子」→ 出现约 43 条，缩略图可预览（官网图）
2. 编辑一条 → 上传主图 → 保存 → 列表与弹窗 `preview-teleported` 可看
3. 官网刷新 `/price-list/` → 云端条目带图（含多图 lightbox）
4. 改价并保持上架 → 官网刷新后价格变化（`data-price-source=cloud`）
5. 「发布到订货价目」→ 订货履约选品可读 `configs/b2b_catalog`
