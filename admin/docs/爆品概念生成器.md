# 爆品概念生成器（独立模块）

> 菜单：战略与知识 → **爆品概念生成器**（`currentTab = 58`）  
> 组件：`admin/src/components/ProductConceptGenerator.vue`

## 背景

原嵌在战略调研看板（`StrategyResearch.vue`）的「爆品生成」Tab，已拆为独立模块并升级。看板「产品金字塔」页仅保留跳转入口与经典三层金字塔；独立模块为唯一完整能力。

## 能力

1. **工作台分区**：输入条件 / 生成结果 / 历史概念 / 批量导出  
2. **定位类型（7）**：利润款、引流款、形象款、礼赠款、教育款、订阅款、联名限定（绿金可选中卡片，桌面 2–3 列网格）  
3. **筛选项**：产品类别、创新方向、渠道场景、目标客群；生成 prompt 全量注入  
4. **灵感骰子**：一键随机填入定位 + 四类筛选项  
5. **批量生成**：同条件串行 3 变体，带进度与变体切换 Tab  
6. **结构化概念卡**：品名、定位、价格带、客群、卖点、材质、渠道、风险、下一步；标签展示筛选项；**同条件再生成** / 变体再生成  
7. **历史与收藏**：`localStorage` key `sc_product_concepts_v1`，搜索 / 删除 / 同条件 / 变体  
8. **生成体验**：加载态、AbortController 中止、空态引导、示例一键填入（7 条覆盖新类型）  
9. **导出**：单条 / 批量 Markdown 或 JSON（含生成条件快照）  
10. **战略看板联动**：`带回战略看板` → 写入 `sc_product_concept_for_strategy` 并 `switch-tab` 到 `10`
11. **一键生图**：概念卡「生成效果图」站内生图；「在 Gemini 中生图」复制视觉描述并打开外链 App

## 一键生图

### 视觉描述

由 `buildConceptVisualPrompt`（`admin/src/utils/conceptImageGen.js`）从品名、定位、价格带、卖点、材质、渠道、筛选项与山海造物 VI（森林绿 + 古董金、标本艺术馆气质）组装中英混合 prompt。

### 站内生图

| 变量 | 说明 |
|------|------|
| `VITE_IMAGE_GEN_ENABLED` | `1` 显式开启（需有 Key）；未设则随 Key 自动启用 |
| `VITE_IMAGE_GEN_PROVIDER` | `gemini` / `openai` / `bailian`，默认选第一个有 Key 的 |
| `VITE_GEMINI_IMAGE_MODEL` | 默认 `imagen-3.0-generate-002` |
| `VITE_OPENAI_IMAGE_MODEL` | 默认 `dall-e-3` |
| `VITE_BAILIAN_IMAGE_MODEL` | 默认 `wanx-v1`（异步任务，本地 dev 走 `/api/bailian-native` 代理） |

- 成功：概念卡内预览 + 压缩缩略图写入历史（`generatedImage.thumbUrl`，JPEG ~512px，控制 localStorage 体积）
- 失败：错误区 +「改用 Gemini 外链」降级
- 未配置 Key：主按钮文案「需配置 Key」，外链方案仍可用

### Gemini 外链

| 变量 | 默认 |
|------|------|
| `VITE_GEMINI_IMAGE_APP_URL` | `https://gemini.google.com/app/e267ab1bf45eed45?hl=zh` |

**限制**：Gemini Web App **不支持**通过 URL query/hash 可靠预填 prompt，因此流程为：

1. `navigator.clipboard.writeText(视觉描述)`
2. `window.open(Gemini App URL)`
3. Toast：「已复制视觉描述，请在 Gemini 粘贴后生成」

可通过「预览 / 编辑描述」弹窗修改后再复制或外链。

## 验证

```bash
cd admin && npx vite build
```

侧栏打开「爆品概念生成器」→ 确认 7 张定位卡与四类下拉可见 → 灵感骰子 / 示例填入 → 生成或「批量 3 变体」（需 AI Key）→ 概念卡标签含筛选项 →「同条件再生成」→ 导出 / 带回战略看板 → **生成效果图**（需 `VITE_IMAGE_GEN_ENABLED` + Imagen/DALL·E/百炼 Key）或 **在 Gemini 中生图**（仅需浏览器，自动复制描述）。

## 已知限制

- 批量生成为串行调用 API，耗时约为单次的 2–3 倍；中止后已完成的变体仍会保留在历史。  
- 旧历史条目可能缺少 `channel` / `audience` 等新字段快照，打开时会用当前默认值补齐。  
- 扩展定位不进入战略看板金字塔三层视觉。
- Gemini 外链无法 auto-fill，依赖剪贴板 + 用户粘贴。
- 站内生图缩略图存 localStorage，大图 blob 仅当前会话；历史条目过多时注意浏览器配额。
