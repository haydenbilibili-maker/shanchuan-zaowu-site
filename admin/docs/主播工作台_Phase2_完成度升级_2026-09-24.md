## 1. 本轮目标（可验收）

1. **入口 / 门禁 / 角色**：欢迎语 + 模式芯片（主播 / 超管预览 / 店长代播）；超管预览不冒充「演示生产」。
2. **主路径完整**：流程条 **建场 → 挂品 → 开播**；下一步提示卡按状态驱动；挂品/话术/公告/历史场次闭环。
3. **空态 / 加载 / 错误 / 配置边界**：统一 workbench-state；未配 `LIVE_*` / 未开 `showLive` / 同事占场 分色提示。
4. **工作台语言**：与采购商/标本师一致（分组头 en/cn、流程条、底栏主 CTA、脚注边界）。
5. **ERP**：监控页空态与「开播在小程序」说明对齐；不重复实现开播。
