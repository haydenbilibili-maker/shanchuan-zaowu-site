# 每日日报 Phase 3 · 可读性与交互升级（工作信息 · 日报）

> 日期：2026-09-26 ｜ 状态：**本轮落地展示层/列表详情交互**（不改口径契约）
> 前置：Phase1 口径 + Phase2 完成度（关键数/未读/失败区分）
> 落点：小程序「工作信息」`digest` 档
> 守卫：`npm run check:daily-digest`（域 `reporting`）

---

## 本轮目标

1. **日期可读**：`dayKey` 附带星期 / 相对日（昨天、前天…），列表标题一眼可辨。
2. **健康态**：`ok / partial / failed` 贯穿列表芯片、顶栏 tip、详情头与分组小计。
3. **口径降噪**：默认只显示集合短名；「显示完整口径」再展开 `集合.字段（时区）`。
4. **空错诚实**：无 payload 的日报标「仅有文字摘要」；详情加载中有态；长按可复制关键摘要。
5. **契约不变**：仍只消费既有 `payload`；不做 ERP 页；不改 COLLECTIONS / 云函数 success 语义。

## 验收

1. 日报档顶栏显示最新一期健康态或空档说明。
2. 列表卡：相对日 + 健康标签 + 关键数；无 payload 时见诚实黄条。
3. 详情：分组小计、默认短口径、可切换完整口径、可复制摘要。
4. 长按日报：复制 / 删除二选一。
