1. **两个入口、两次页面加载**：开完 SKU 单要点「查出货单」跳到另一页，且落在「总览」而不是新单。

5. **弹层嵌 scroll-view** 是既往 bug 源（高度不定 → 滑不动、底栏被顶出）。

### 2.1 开单一屏完成

- **不再用弹层承载录入**：粘贴、预览、问题行、单条表单都在页面里自然滚动（彻底消除「弹层 scroll-view 高度」这一类 bug）；
  仍保留的弹层（选 SKU / 新建 SKU / 选原材料包装 / 详情 / 资料表单）其 scroll-view **一律显式 px 高度**（`sheetBodyPx`，由 `measureSheet()` 按窗口算）。
- dock 主按钮**满宽**：`.sc-cta` `width:100% !important` + 内联 `style="width:100%…"` 双保险（app.wxss 的 inline-flex 会把按钮缩成半宽，既往已踩）。
- 单条补录的低频字段（规格/分类/购买人/客户名/状态/快递/运单/备注）收进「更多字段」折叠。

### 2.2 写入后就地收口

所有写入路径（SKU / 粘贴 / 单条 / 逐行核对返回）统一走 `revealAfterWrite`：
切到「单据」→ 放开会藏单的筛选 → 刷新 → **新单 id 进 `highlightIds`（金边 + 「新」角标）** → 成功条附「再开一单」。
列表刷新失败时仍用写入回执**乐观展示**新单（沿用 2026-09-24 修复，不回退）。
`shipment-edit` 保存后 `navigateBack` 回到本页：`onShow` 检测草稿已被消费 → 自动收口到单据页。

## 5. 原材料 / 包装方式：数据方案

### 5.1 载体（复用，零新增）

| 语义 | 集合 | 读写通道 | 关键字段 |
|---|---|---|---|
| 原材料 | `studio_material_prices` | `manageStudioSettlement` `priceBook.*`（kind=`material`） | `name` `grade` `isDefaultGrade` `unitPrice`(元) `unit` `aliases[]` `category`(标本/耗材/工具) `status`(active/inactive) `sort` `note` `deleted` |
| 包装方式 | `studio_packaging_prices` | 同上（kind=`packaging`） | 同上，`size`/`isDefaultSize` 替代等级 |
| 原材料**库存** | `studio_raw_inventory` | `manageStudioRawInventory`（库存管理 → 原材料 Tab） | 数量/采购价；价目表列表会带「参考采购价」只读对照 |

`shipmentDefaults.js` 里**没有**默认包装一类配置；门店配置亦无。出货单明细的定价快照字段（`material*` / `packaging*` / `unit*Cents`）早已存在。

### 5.2 维护入口（资料页签）

- 列表：`priceBook.list({ kind, status: '' })`（含已停用，已停用置灰）；服务端按 `sort` → 名称排序。
- 新增：`priceBook.create`；编辑 / 停用 / 启用 / 排序：`priceBook.update`。
  ⚠️ `update` 走 `buildRow`（**整行覆盖**，缺省字段会被归一成默认值），所以客户端**始终回送整行**：
  `mapRow` 的 `option`→`grade|size`、`isDefaultOption`→`isDefaultGrade|isDefaultSize`，其余原样。
- 排序：与相邻行**交换 `sort`**（2 次 update）；若相邻 `sort` 相同（历史数据未排过），先把当前列表按显示顺序重编号（10、20、30…），之后都是交换。
- 删除：只走 `priceBook.removeIfUnused`（§10）——有引用即拒并回引用数，页内提示「改为停用」；无引用才软删。ERP「价目表配置」的 `priceBook.remove` 不变。
- 服务端约束原样生效：同名+同等级防重、每个名称至少保留一个默认行（取消唯一默认会被拒）。

### 5.3 在出货单上怎么用

| 路径 | 用法 |
|---|---|
| 选 SKU | SKU = 原材料×等级 × 包装×尺寸，行天然带全部字段（不变） |
| 单条补录 | **新增可选**「原材料」「包装方式」选择（同一选择器）→ 写入 `items[0].material*/packaging*`。算价开启时服务端 `recomputeItemsPricing` 会按价目表核价（显式选择模式）；不选 = 旧行为 |
| 粘贴识别 | 文本只含品名与数量；要逐行选材料/包装走「逐行核对并算价」（`shipment-edit`，既有） |
| 详情展示 | 每行显示「原材料 X（等级）· 包装 Y 尺寸」（有才显示） |
| ERP `StoreShipments.vue` | 详情抽屉明细表加「原材料」「包装方式」两列，**只读** |
| 打印 | 现无打印能力，本轮不新增 |
| 结算计价 | 不变：单据总额 = 材料 + 包装 + 造景 + 手工（四桶，分/件 × qty） |

旧单不含这些字段 → 显示为空，不影响。

## 10. 点名三项实施（2026-09-28 晚，产品负责人拍板 P2–P4 全部「需要」）

### 10.1 资料页签店长只读
- 取证：`manageStudioSettlement` 除 `SUPER_ONLY_ACTIONS` 外全部走 `requireReader`（店长及以上），`priceBook.list` / `searchPriceBook` 店长**本就可读** → 服务端零改动。
- 页面：`visibleTabs()` 无条件含 `library`；`applyTab` 仍校验可见性，但店长深链 `?tab=library` 现在留在资料页（旧「退回单据」逻辑作废）。
- 写入口：「＋ 新增」、每行 ↑↓ / 编辑 / 停用|启用 / 删除、行内确认条与被拒条全部 `wx:if` 在 `isSuper` 之下；`openLibForm / submitLibForm / toggleLibStatus / moveLibRow / askRemoveLib / confirmRemoveLib` 首行拦非超管；店长进资料不拉 `meta`（分类只给表单用）。已停用行照常显示「已停用」标注。

### 10.2 选择器按资料排序
- 云函数：`searchPriceBook` 新增**可选** `orderBy:'sort'`。传了：组内选项按 `sort`（同 sort 默认项在前），组按组内最小 `sort` → 名称；每个选项多带 `sort`。**不传：输出形状与顺序逐字不变**（不加 `sort` 字段，仍是默认项在前、按读取顺序分组）。关键字精确命中置顶在两种模式下都保留。停用项在两种模式下都不进结果（原有 `status !== 'active'` 跳过）。
- 调用方：出货中心选择器（`parts/create.js`）、逐行核对页 `shipment-edit`、资料列表 `priceBook.list`（本就按 sort 排，传参无副作用）都传 `orderBy:'sort'`；ERP `StudioSkus.vue` / `PriceBookManager.vue` 不传 → 不受影响。

### 10.3 未被引用才可删
