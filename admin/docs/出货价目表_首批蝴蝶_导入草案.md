## 1. 为什么不能原样导入

价目表是按**出货单文本**做前缀匹配的：出货单里写 `爱神凤蝶玻璃罩`，系统要找的是以 `爱神凤蝶` 开头的材料。
而表格里写的是 `爱神凤蝶A1/A-`、`大蓝A2整包50只` —— **原样录进去一行都匹配不上**。所以要把「名称」与「等级/品相」拆开：

| 规则 | 例子 |
|---|---|
| 品相/等级后缀从名称剥出，放进「等级」列 | `五斑翠凤蝶A1/A-` → 名称 `五斑翠凤蝶` + 等级 `A1/A-` |
| **采购整包备注丢弃**（`整包25只`/`整包50只` 是进货包装、不是出货属性，且不影响单价） | `海伦闪蝶整包25只` → 名称 `海伦闪蝶` + 等级「默认」 |
| `大蓝` 规范为 `大蓝闪蝶`，别名同时挂 `大蓝闪`、`大蓝` | 出货单写「大蓝闪」或「大蓝」都能命中 |
| `甲、乙` 合并名**拆成两条**，单价相同 | 出货单只会写其中一种，拆两条才匹配得上 |

其余的多数不是蝴蝶（独角仙/锹甲/印尼金锹是甲虫、熊蜂王是蜂、华艳色蟌是蟌、蒲公英是植物），应该会分批给我。

**这是预期，不是 bug**。要跑通完整验收，还需要：`翠蓝眼蛱蝶`、`黄裳眼蛱蝶`、
`独角仙展翅`、`独角仙没展翅`、`华艳色蟌`、`印尼金锹`、`扩头深山锹甲`、`熊蜂王`、`蒲公英`、`杂蝶`，
以及**包装**（玻璃罩/冰箱贴/框/造景）。
