# 供应商 / 采购商工作台 · 技术蓝图（可交付终版 · 2026-09-24）

> **主入口**：小程序「采购商工作台」`subpackages/extra/supplier/`。  
> **硬禁止**：工作室 `ops_*` 与 `purchase-ops` / `shipment-ops` / `studio-bills`。  
> **稳定期**：B2B 支付旁路；禁止改 C 端 `makeOrder`/`payOrder`/`payCallback`。

## 1. 角色

| deskKind | 谁 | Hub |
|----------|-----|-----|
| preview | 超管 | 采购主路径 + 可折叠供货方 + 演示开关 |
| buyer | roles∈buyer/franchisee/channel | 仅采购主路径 |
| supplier | roles∈supplier | 供货方区默认展开 |

## 2. 主路径

```
价目(catalog) → 采购车(buyer-cart) → purchase_orders
    → payB2bPurchase → [wx.requestPayment | 待对公 | 验收标记]
    → b2bPayCallback（仅 PO.paymentStatus）
    → buyer-orders
```
