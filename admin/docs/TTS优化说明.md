# 语音合成（TTS）优化说明

## 📋 优化概述

基于GitHub上先进的TTS方案（ChatTTS、GPT-SoVITS等），对系统的文字转语音功能进行了全面优化，让人声更加自然真实。

## 🎯 优化内容

### 1. 创建了高级TTS工具模块 (`src/utils/ttsHelper.js`)

#### 功能特性：
- **语音配置预设**：提供4种预设配置（年轻女声、成熟女声、年轻男声、默认）
- **智能文本预处理**：
  - 移除Markdown语法标记
  - 处理数字和单位，使其读法更自然
  - 优化标点符号处理，保留适当停顿
  - 处理空白字符，避免异常停顿
- **智能语音选择**：自动选择最佳的中文语音（优先Microsoft Yaoyao等自然语音）
- **异步语音加载**：解决浏览器语音列表加载延迟问题

#### 参考方案：
- **ChatTTS**：支持中文和英文，生成带有停顿、语气和情绪的自然流畅语音
- **GPT-SoVITS**：高质量语音生成，支持语音克隆
- **so-vits-svc**：高质量声音克隆和转换

### 2. 优化了语音参数配置

#### 语速（Rate）优化：
- **默认值**：0.9（稍慢，更接近真实人声）
- **范围**：0.85-1.0（避免过快导致的机械感）
- **说明**：参考ChatTTS等方案，稍慢的语速能带来更自然、更易理解的效果

#### 音调（Pitch）优化：
- **默认值**：1.05（略高，更清晰）
- **范围**：0.95-1.15（避免过于尖锐或低沉）
- **说明**：略高的音调能使语音更清晰，但保持在自然范围内

#### 音量（Volume）优化：
- **默认值**：0.85（适中）
- **范围**：0.75-0.92（清晰但不刺耳）
- **说明**：适中的音量确保清晰度，同时不会让用户感到不适

#### 不同情感的参数配置：
```javascript
{
  happy: { rate: 0.90, pitch: 1.06, volume: 0.86 },      // 稍快稍高，更自然
  excited: { rate: 0.93, pitch: 1.10, volume: 0.88 },    // 接近真实兴奋语调
  calm: { rate: 0.87, pitch: 1.00, volume: 0.82 },       // 沉稳自然
  focused: { rate: 0.89, pitch: 1.02, volume: 0.84 },    // 接近真实对话
  friendly: { rate: 0.90, pitch: 1.05, volume: 0.85 }    // 最接近真实人声
}
```

### 3. 优化了文本预处理

#### 处理内容：
1. **Markdown语法移除**：避免读出格式符号
2. **Emoji处理**：移除emoji，只保留文字内容
3. **数字和单位优化**：确保数字读法更自然
4. **标点符号优化**：统一标点，保留适当停顿
5. **长句分割**：超过60字的句子会自动添加停顿，避免一口气读完

### 4. 优化了语音选择逻辑

#### 优先级排序：
1. **Microsoft Yaoyao** - 年轻女声，最自然（推荐）
2. **Microsoft Xiaoxiao** - 年轻女声，清晰自然
3. **Microsoft Huihui** - 成熟女声，专业自然
4. **其他高质量语音** - Microsoft、Google等

## 🚀 使用方法

### 在当前代码中：
代码已经自动使用优化后的参数。语音合成时会：
1. 自动选择最佳语音
2. 应用优化的参数（语速、音调、音量）
3. 对文本进行智能预处理

### 使用TTS工具模块（可选）：
```javascript
import { getTTSInstance, VOICE_CONFIGS, quickSpeak } from '../utils/ttsHelper'

// 方式1：使用单例
const tts = getTTSInstance({
  voiceConfig: VOICE_CONFIGS.youngFemale,
  onStart: () => console.log('开始播放'),
  onEnd: () => console.log('播放结束')
})
await tts.speak('你好，我是AI助手')

// 方式2：快速播放
await quickSpeak('你好，我是AI助手', {
  rate: 0.9,
  pitch: 1.05,
  volume: 0.85
})
```

## 🔧 后续优化建议

### 1. 集成第三方TTS API（可选）

如果需要更高质量的语音，可以考虑集成：

- **Azure Speech Services**：Microsoft提供的高质量TTS服务
  - 支持多种自然的中文语音
  - 支持SSML（语音合成标记语言）
  - 需要API密钥和付费

- **Google Cloud Text-to-Speech**：Google的TTS服务
  - 高质量神经网络语音
  - 支持多种语言和音色
  - 需要API密钥和付费
