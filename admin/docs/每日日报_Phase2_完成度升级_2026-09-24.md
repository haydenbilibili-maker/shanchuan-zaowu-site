## 1. 本轮目标（可验收）

1. **列表**：日报卡一眼能看出「哪一天 / 角色 / 3 个关键数 / 取数失败提示」；不再只靠纯文本 preview。
2. **详情**：结构化块信息层级清晰（头 → 关键数 → 分组 → 口径脚注）；`取数失败` 与 `未取到` 视觉可分；展示 `generatedAt`。
3. **空态 / 加载 / 错误 / 权限**：日报档专用空文案；非员工进工作信息有明确提示；加载失败可重试。
4. **导航一致**：分档「日报 / 待办 / 审批」可带未读角标；情境条在日报档说明「定时快照 · 可回看」。
5. **契约不变**：继续消费既有 `payload`（`dayKey/roleLabel/sections/metrics/failed/missing/generatedAt`）；不扩写云函数入参出参。

## 4. 验收清单（人眼）

1. 员工：我的 → 工作台 → 工作信息 → 点「日报」档 → 见列表或空态说明。
2. 有日报时：列表卡显示日期与关键数；点开见结构化口径；失败项标「取数失败」非「未取到」。
3. 非员工深链 `?queue=workflow`：提示仅员工可见并回落到顾客信箱。
4. 工作台**没有**独立「日报」瓦片。
