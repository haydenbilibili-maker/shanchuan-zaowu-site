## 1. 本轮目标（可验收）

1. **开单主路径**：选客户 → 选/建 SKU → 数量/费率/造景 → 服务端核价 → 保存 → 结果卡（单号/金额）→ 可再开或跳转出货单。
2. **列表 / 筛选 / 状态**：快捷筛选待发货/已发货/已完成；卡片展示结算、核价、录单路径、物流摘要。
3. **详情与操作**：页内下一状态按钮（`STATUS_FLOW`）；快递/运单 `update`；发货时可一并写入运单；**不臆造**库存扣减或支付动作。
4. **空态 / 错误 / 权限**：开单超管门禁 + 芯片；算价未启用禁提交；列表错误条；ERP 空态与字段对齐。
5. **视觉**：流程条、主次 CTA、结果卡、详情分区。

## 5. 人眼验收

1. 超管 → 出货开单 → 选 SKU → 保存 → 见结果卡单号；非超管深链被拒。
2. 出货单 → 单据 → 快捷「待发货」→ 点详情 → 填运单 → 点「已发货」。
3. 详情展示结算只读；改结算走工作室账单。
4. ERP 出货单：金额/结算/核价/录单路径可见；点行开抽屉；说明主录入在小程序。
5. 供应商工作台无出货开单/出货单入口。
