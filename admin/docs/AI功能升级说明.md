## 🚀 使用指南

### 1. 访问AI智能中心

在左侧菜单"全局概览"下，点击"✨ AI 智能中心"

### 2. 使用AI功能

1. 选择功能分类（门店经营/线上营销/战略决策/运营优化）
2. 点击功能卡片
3. 在弹出的对话框中输入相关信息
4. 点击生成按钮
5. 查看AI生成的结果

### 3. 召开虚拟董事会

1. 选择议题（或自定义）
2. 选择参与成员（至少2位）
3. 点击"召开董事会"
4. 等待AI成员依次发言
5. 查看决策总结

## 🔐 API Key配置

API Key 请通过环境变量或 CloudBase 配置中心管理，**切勿写入仓库或文档**。

- Gemini：在 `.env` 中设置 `VITE_GEMINI_API_KEY`（可多 Key 轮换，见 `admin/.env.example`）
- OpenAI：在 `.env` 中设置 `VITE_OPENAI_API_KEY`

本地开发复制 `admin/.env.example` 为 `admin/.env` 后填入真实 Key。

---

## 📝 注意事项

1. **API Key安全**：所有API Keys存储在客户端代码中，生产环境建议使用环境变量
2. **数据隐私**：AI功能会访问门店数据，确保数据安全
3. **使用频率**：系统已实现请求队列和缓存，但仍需注意API调用频率限制
4. **错误处理**：系统具备完善的错误处理和重试机制，但网络问题可能导致功能暂时不可用
