# 山海造物系统优化与配置能力分析

## 📊 一、系统优化提升建议

### 1. 数据一致性优化 ⭐⭐⭐⭐⭐

**问题**：
- 订单数据来源不统一（部分从云数据库，部分从财务报表）
- 人力排班优化已优化，但其他AI功能仍在使用 `fetchStoreData`

**优化方案**：
1. **统一数据源策略**
   - 订单数据：优先从财务报表（`shanhai_v12`）获取
   - 实时数据：从云数据库获取（用户、收藏、评论等）
   - 建立数据同步机制，确保财务报表数据及时更新

2. **数据获取工具优化**
   - 重构 `fetchStoreData`，增加数据源选择参数
   - 创建 `fetchFinancialData` 专门从财务报表获取
   - 创建 `fetchRealtimeData` 专门从云数据库获取

**优先级**: P0（高优先级）

---

### 2. 首页动态化配置管理 ⭐⭐⭐⭐⭐

**现状**：
- 小程序支持首页模块配置（`home_configs` 集合）
- Web管理后台**缺少**首页配置管理界面

**优化方案**：
1. **新增"首页配置管理"模块**
   - 可视化拖拽排序模块
   - 模块显示/隐藏控制
   - 每个模块的参数配置（数量、排序、算法等）
   - 实时预览效果
   - 支持A/B测试配置

2. **功能点**：
   - 轮播图配置（数量、自动播放、间隔）
   - 分类球配置（显示数量）
   - 专题展览配置（数量、排序）
   - 名师手作配置（数量、排序）
   - 近期活动配置（数量、状态筛选、排序）
   - 为你推荐配置（数量、算法选择）
   - 最新入库配置（数量、排序）

**优先级**: P0（高优先级）

---

### 3. 会员等级权益配置 ⭐⭐⭐⭐

**现状**：
- 小程序端有会员等级硬编码（5个等级）
- Web管理后台有VIP会员卡配置，但**缺少**会员等级成长体系配置

**优化方案**：
1. **新增"会员等级体系"配置**
   - 等级定义（等级、名称、成长值门槛）
   - 折扣配置（每个等级的折扣率）
   - 权益配置（每个等级的特权列表）
   - 等级图标配置
   - 成长值规则配置（消费、签到、分享等）

2. **与现有功能整合**：
   - 与"权益与营销中心"的VIP卡配置整合
   - 与积分系统打通（成长值 = 积分 × 系数）

**优先级**: P1（中高优先级）

---

### 4. 积分规则配置 ⭐⭐⭐⭐

**现状**：
- 积分规则硬编码在云函数 `earnPoints` 中
- Web管理后台**缺少**积分规则配置界面

**优化方案**：
1. **新增"积分规则配置"模块**
   - 签到奖励配置（每日积分、连续签到奖励）
   - 浏览奖励配置（每次积分、每日上限）
   - 消费奖励配置（消费金额与积分比例）
   - 分享奖励配置（分享次数、积分奖励）
   - 评价奖励配置（评价积分）
   - 积分有效期配置
   - 积分兑换规则配置

2. **功能点**：
   - 支持多种动作类型配置
   - 支持每日/每周/每月上限
   - 支持特殊活动积分倍率
   - 积分流水记录查询

**优先级**: P1（中高优先级）

   - 时间段配置（可预约时间段、每个时间段限额）
