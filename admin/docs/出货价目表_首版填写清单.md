## 5. 这批材料/包装将来怎么维护（**唯一维护点：ERP「价目表配置」模块 81**）

> **唯一入口**：ERP 侧栏 → **工作室 / STUDIO → 价目表配置**（模块 id 81）。
> 三个页签：**原材料价 / 包装价 / 费率与规则**。
> 小程序端**只读**（录出货单时搜索选择），不提供编辑 —— 这是产品负责人裁决 9 定的：
> 几十~几百行的结构化数据，ERP 表格录入效率远高于手机。

> ⚠️ **不要**去改「原材料库存」里的单价（`studio_raw_inventory.unitPrice`）来代替本表：
> 那是**采购台账**（飞书「库存管理」同步过来的、你从各平台进货花的钱），
> 本表是**出货结算价**。两者语义不同、同步方向也不同（改库存会被飞书回灌覆盖）。

填完之后，这两张表会进 **ERP 新模块「价目表配置」**（蓝图 §8.1，模块 id `81`），
到时候可以在表格里批量改价、加材料、加别名，不用再改文件。
**已出货的单不会被改价影响**（蓝图 §5.5 快照隔离）—— 你改价只影响之后的新单。

## 7. **可以直接粘贴的填写块**（填完单价 → 整块贴进 ERP）

> **列的摆放**：`名称` `别名` `等级或尺寸` `单价` `单位` —— **单价是第 4 列**，把它填上就行。
> **别名没有就留空**（两个制表符之间什么都不写，别写「无」）。
> `等级或尺寸` 写「默认」表示这是该名称的默认行；要分 A1/A2 就**再加一行**写 A1、A2，
> 并且**把其中一行的「等级或尺寸」改成「默认」**（或把默认列打勾）—— 每个名称必须恰好有一个默认行。

**填完后**：ERP → 工作室 / STUDIO → **价目表配置** → 对应页签 → **批量粘贴导入** →
粘贴 → 先点「试算（不写入）」看能不能认全 → 再点「确认导入」。
