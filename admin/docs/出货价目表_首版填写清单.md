## 0. 怎么用这份清单

1. **先看第 1 节**：我把样本 21 行**逐行拆成了「材料 + 包装」**。请先确认**我拆得对不对** ——
   拆错的话后面全错，这比填价格更重要。
2. **再填第 2 节（材料价）和第 3 节（包装价）**：只填 `单价`，其余列我已尽量预填。
3. 填完发我，我导入价目表集合，然后用这 21 行跑端到端验收。

**三条规则（决定算价对不对）**

| 规则 | 说明 |
|---|---|
| **材料名要含姿态** | `独角仙展翅` 和 `独角仙没展翅` 是**两个材料**（两个价），所以是两行。这正是样本里的写法 |
| **一个材料只能有一个「默认」行** | 文本里没写等级时用「默认」行。要分 `A1/A2` 就在同一材料下**加行**改等级，但**只有一行**标默认 |
| **别名用来兜简称与笔误** | `大蓝闪` 是 `大蓝闪蝶` 的简称 → 挂在别名列。**别名不得跨材料重复**（会报错） |

## 5. 这批材料/包装将来怎么维护

填完之后，这两张表会进 **ERP 新模块「价目表配置」**（蓝图 §8.1，模块 id `81`），
到时候可以在表格里批量改价、加材料、加别名，不用再改文件。
**已出货的单不会被改价影响**（蓝图 §5.5 快照隔离）—— 你改价只影响之后的新单。
