# 原材料价目表 · 飞书交叉核对（第 1 轮 · 修正版）

> 来源：飞书多维表 **库存管理**（标本类 126 条）与 **采购记录**（标本类 223 条），由施工代理**直接调飞书 API 读取**。

## 0. 上一版的两个错（已修正，记在此处免得再犯）

1. **等级不在名称里，在「规格型号」字段里** —— `小蓝闪蝶` 三行是 `A1`¥188 / `A-`¥135 / 空¥150。
   我上一版只从名称剥品相后缀，于是同名同等级撞出「同名不同价」的假冲突。
   现改为：**规格型号若是等级串（A1/A-/B1…）就用它，否则用名称里的品相后缀（通货/全雄/无缺无裂…）**。
2. **子串匹配造成假冲突** —— `雅灰蝶` 被 `优雅灰蝶`、`锡冷雅灰蝶` 命中。这是**三种不同的东西**。
   现改为**规范化后全等匹配**。
